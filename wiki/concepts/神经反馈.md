# 神经反馈

## 定义

> **神经反馈（Neurofeedback）** 是一种通过实时监测和反馈脑波活动来训练大脑自我调节的技术。也称为脑电生物反馈（EEG Biofeedback），属于生物反馈的一种。

## 核心原理

### 工作机制

```
脑波采集 → 实时分析 → 反馈呈现 → 大脑自我调节 → 神经可塑性改变
```

| 步骤 | 说明 |
|------|------|
| **脑波采集** | 使用电极采集头皮脑电信号 |
| **实时分析** | 分析特定频段的脑波活动 |
| **反馈呈现** | 通过视觉/听觉信号反馈脑波状态 |
| **自我调节** | 大脑根据反馈调整自身活动 |
| **长期改变** | 通过神经可塑性形成持久的改变 |

### 训练协议

| 协议 | 目标频段 | 应用 |
|------|----------|------|
| **SMR训练** | 增加12-15Hz [[感觉运动节律]] | 焦虑、注意力 |
| **Alpha训练** | 增加8-12Hz Alpha波 | 放松、压力管理 |
| **Theta训练** | 调节4-8Hz Theta波 | 冥想、创造力 |
| **Beta训练** | 调节15-30Hz Beta波 | 注意力、警觉性 |

### 训练过程

| 阶段 | 说明 | 持续时间 |
|------|------|----------|
| **评估** | 基线脑波测量和目标设定 | 1-2次 |
| **训练** | 定期进行神经反馈训练 | 20-40次 |
| **巩固** | 减少训练频率，巩固效果 | 10-20次 |
| **维持** | 偶尔进行维持训练 | 按需 |

## 应用领域

| 领域 | 应用 | 效果 |
|------|------|------|
| **焦虑** | 降低高频Beta波，增加SMR和Alpha波 | 有效 |
| **ADHD** | 增加SMR，降低Theta波 | 有效 |
| **失眠** | 训练放松性脑波模式 | 有效 |
| **抑郁** | 调节不对称的前额叶活动 | 有前景 |
| **创伤后应激** | 减少过度唤起 | 有前景 |

## 优势与局限

| 优势 | 局限 |
|------|------|
| 非侵入性 | 需要专业设备和训练 |
| 无药物副作用 | 效果因人而异 |
| 针对性训练 | 需要多次训练 |
| 持久效果 | 费用较高 |
