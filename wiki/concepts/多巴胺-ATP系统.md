# 多巴胺-ATP系统

## 定义

> 人体的瞬时能量爆发系统，通过"外来刺激→多巴胺→葡萄糖→ATP"链条产生必须立即消耗的能量。

多巴胺-ATP系统是七层自我模型中的第一层，负责冲动和短期能量爆发。

## 工作链条

```
外来刺激 → 多巴胺分泌 → 葡萄糖水解 → ATP（瞬时能量）→ 爆发式行动
```

## 关键特征

| 特征 | 说明 |
|------|------|
| **无时间感** | 停不下来，持续时间8-20秒 |
| **不在乎结果** | 只求行动，不问后果 |
| **无满足感** | 永远渴求，永远不会安宁 |
| **三次成瘾** | 链条激活三次并强化即形成惯性 |

## 欲望系统 vs 快乐系统

- **多巴胺-ATP系统**只负责欲望，不负责快感
- **快乐中枢**独立运作，满足欲望的快感很弱，欲望的快感强烈得多
- **厌恶系统**由脑岛掌控，解除瘾症的关键是让该系统消停下来

## 成瘾机制

当刺激指向错误（如瘾症、错恋），多巴胺无法降解，能量不断积累，形成更强烈的欲望。"得不到"和"已失去"会持续刺激系统升温。

## 进化意义

在资源短缺的远古环境中，ATP能量是生存基础——看到食物瞬间充满力量，看到配偶瞬间能量爆发，保证了基因延续。
