# 苏格拉底式发问

## 定义

苏格拉底式发问（Socratic Questioning）是一种通过系统性的提问来帮助个体审视自己的想法、信念和假设，从而发现真理、澄清概念、挑战不合理认知的方法。

## 起源

### 苏格拉底
- 古希腊哲学家（公元前470-399年）
- 以提问和对话的方式教学
- "我知道，我一无所知"
- 通过提问引导他人自己发现真理

### 苏格拉底之死
- 被指控败坏青年
- 选择饮毒参而死
- 用生命维护信念
- 成为哲学史上的经典案例

## 核心原则

### 目的
- 澄清思维
- 挑战假设
- 寻找证据
- 探索替代观点
- 发现真理

### 态度
- 好奇而非评判
- 开放而非防御
- 合作而非对抗
- 探索而非说教

## 提问类型

### 1. 澄清问题
- "你的意思是什么？"
- "你能举个例子吗？"
- "这与其他概念有什么区别？"

### 2. 挑战假设
- "你为什么这样认为？"
- "这个假设成立吗？"
- "还有其他可能性吗？"

### 3. 寻找证据
- "你有什么证据支持这个想法？"
- "反对这个想法的证据是什么？"
- "这个证据可靠吗？"

### 4. 探索视角
- "其他人会怎么看？"
- "有没有其他解释？"
- "长期和短期影响有什么不同？"

### 5. 探索后果
- "如果这是真的，意味着什么？"
- "这个想法会导致什么结果？"
- "有没有更好的选择？"

### 6. 质疑问题本身
- "这个问题重要吗？"
- "有没有更好的问题可以问？"
- "我们为什么要讨论这个？"

## 在CBT中的应用

### 识别错误想法
- "支持这个想法的证据是什么？"
- "反对这个想法的证据是什么？"
- "有没有其他解释？"

### 挑战认知扭曲
- "这是全或无的思维吗？"
- "你在灾难化吗？"
- "这是情绪化推理吗？"

### 发展替代想法
- "更平衡的想法是什么？"
- "你会对朋友说什么？"
- "如果情况相反，你会怎么想？"

## 苏格拉底式对话示例

### 关于失败恐惧
```
问：你为什么害怕失败？
答：因为失败很可怕。
问：失败具体会带来什么？
答：别人会看不起我。
问：有证据表明别人会看不起你吗？
答：...
```

### 关于完美主义
```
问：为什么你必须做到完美？
答：否则我就是失败者。
问：不完美就等于失败吗？
答：...
问：你能接受别人的不完美吗？
答：可以。
问：为什么不能接受自己的？
```

## 技巧要点

### 提问者
- 保持好奇和开放
- 避免评判和说教
- 耐心倾听
- 跟随对方的思路

### 回答者
- 诚实面对自己
- 允许不确定性
- 愿意改变观点
- 积极参与探索

## 效果

### 认知效果
- 澄清模糊概念
- 发现逻辑错误
- 拓展思维视野
- 增强批判性思维

### 情绪效果
- 减少情绪困扰
- 增加自我觉察
- 增强控制感
- 促进接受

### 行为效果
- 促进行为改变
- 增强问题解决能力
- 改善决策质量
- 提高沟通效果
