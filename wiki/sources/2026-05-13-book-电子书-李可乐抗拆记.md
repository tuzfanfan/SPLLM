# 李可乐抗拆记

## 概述

《李可乐抗拆记》是李承鹏的长篇小说，以拆迁为题材，用黑色幽默的笔触描绘了中国城市化进程中普通人的抗争故事。

## 核心内容

| 主题 | 内容 |
|------|------|
| 拆迁问题 | 城市化进程中的强制拆迁 |
| 公民权利 | 普通百姓维护自身权益的斗争 |
| 黑色幽默 | 以荒诞对抗荒诞的叙事策略 |
| 社会批判 | 对权力滥用和制度缺陷的揭露 |

## 关键洞察

1. 拆迁是中国城市化进程中最大的社会矛盾之一
2. 黑色幽默是面对荒诞现实的有效武器
3. 普通人的抗争虽然微小但意义重大
4. 文学应该关注社会最底层的声音
