# 不容青史尽成灰——春秋战国卷 - 来源摘要

## 概述

《不容青史尽成灰——春秋战国卷》是张嵚所著的历史随笔集，以独特的视角重新审视春秋战国时期的历史。第一章聚焦被传统"春秋五霸"排名忽略的郑庄公，揭示了他作为"春秋第一霸"如何开启了周王朝分崩离析、诸侯争霸的时代，以及"礼崩乐坏"这一深刻社会变革的起源。

## 核心内容

### 郑庄公的崛起之路

| 事件 | 内容 | 历史意义 |
|------|------|---------|
| 克段于鄢 | 纵容弟弟公叔段谋反后一举歼灭 | 展现政治手腕 |
| 黄泉会母 | 挖地道与被囚禁的母亲相见 | 表面孝顺实则不孝 |
| 联齐灭许 | 联合齐国鲁国吞并许国 | 成为郑齐鲁联盟老大 |
| 周郑交质 | 与周天子互换人质 | 天子权威严重下降 |
| 繻葛之战 | 大败周桓王亲征军，射伤天子肩膀 | 周天子权威彻底崩溃 |

### 郑国兴盛的条件

- **身份高贵**：开国君主郑桓公是周厉王幼子
- **地理位置**：位于天下交通中心的黄金地段
- **经济富庶**：鼓励工商业发展，成为最繁华的"经济开发区"
- **时机有利**：晋国未兴、楚国居南、齐国忙于东夷战争

### "礼崩乐坏"的起源

- 郑庄公"克段于鄢"：对亲弟弟先放纵后反杀——不孝
- "黄泉会母"：囚禁母亲又后悔——违背宗法制核心
- 社会对郑庄公不孝行为的批评"几乎为零"——孝道开始沦丧
- 连基础的孝道都沦丧了，其他制度"不是崩就是坏"

## 关键洞察

1. **"春秋第一霸"的重新发现**：郑庄公虽不在传统五霸之列，却是开启争霸时代的真正第一人
2. **"礼崩乐坏"的起点**：周王朝宗法制以孝道为核心，郑庄公的不孝行为标志着这一体系的瓦解
3. **繻葛之战的历史意义**：天子被诸侯射伤，"万金之躯"的神话彻底破灭
4. **"克段于鄢"的政治智慧**：放纵对手的缺点让其自我毁灭——"如果你恨一个人，最好的办法就是放纵他的缺点"
