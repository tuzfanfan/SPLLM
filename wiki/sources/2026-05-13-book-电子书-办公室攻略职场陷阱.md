# 办公室攻略：中国人不可不知的123个职场陷阱

**作者**: 曹荣

## 概述

一本系统总结中国职场中常见陷阱和应对策略的实用读物。全书列举了123个职场中可能遇到的陷阱，涵盖人际关系、升职加薪、办公室政治等多个方面，为职场人士提供了识别和应对各种职场风险的具体方法。

## 核心内容

| 主题 | 内容 |
|------|------|
| 人际陷阱 | 同事关系、上下级关系中的常见误区 |
| 政治陷阱 | 办公室派系斗争、站队与自保策略 |
| 发展陷阱 | 升职加薪中的误区与正确路径 |
| 沟通陷阱 | 言语失误、信息泄露等风险 |
| 应对策略 | 识别信号、提前预防、巧妙化解 |

## 关键洞察

- 中国职场文化特征
- 办公室政治的运作机制
- 职场沟通与谈判技巧
- 职业发展规划方法
- 劳动法与职场权益保护
