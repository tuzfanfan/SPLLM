# 读心术
| 属性 | 内容 |
|------|------|
| 作者 | 多湖辉（日本） |
| 译者 | 熊振国 |
| 出版信息 | 沈阳出版社，1989年第1版 |
| 类型 | 实用心理学/人际心理 |
| 核心主题 | 通过观察表情、体态、言语等线索探测他人心理活动的科学方法 |
## 核心观点
1. 读心术不是妖术或魔术，而是基于现代心理学的科学方法，人人可以通过学习和训练在日常生活中实践。
2. 探测他人心理的第一步是通过表情为线索，尤其对于不公开表露感情的日本人等群体，更需要敏锐的观察训练。
3. 感情的表现遵循"感情能量守恒定律"——被压抑的感情不会消失，会通过其他途径（手足动作、言语失误、梦境等）表现出来。
4. 人的体型、皮肤、脸型、毛发等外在特征与性格类型（分裂质、躁郁质等）存在关联。
5. 诱导读心术的核心是让对方在自然状态下敞开心扉，通过闲谈、重复对方要点、不打断对方等技巧引出真实想法。
6. 谎言和真心可以通过言语失误、口误、梦境分析等途径被识破。
