# 自信表达评分表

## 定义

> 一种用于记录和评估日常沟通情境的工具，帮助使用者识别自己的沟通风格并练习更有效的自信型回应。

兰迪·帕特森在《自信表达》中提供的核心练习工具。

## 记录要素

| 要素 | 说明 |
|------|------|
| 日期/时间/地点 | 情境背景 |
| 人物/事件 | 具体发生了什么 |
| 你的回应 | 你实际做了什么 |
| 沟通风格判断 | 自信型/被动型/攻击型/被动-攻击型 |
| 结果如何 | 事情的实际结果 |
| 事后感受 | 你的情绪反应 |
| 备选方案 | 更好的自信型回应方式 |

## 使用方法

- 准备20页以上的评分表
- 记录每次遇到的沟通挑战
- 判断自己的沟通风格
- 如果不是自信型，设计备选方案
- 持续练习，逐渐加快反应速度

## 四象限评估

在给予纠正性反馈的舒适度和有效度两个维度上评估自己：
- **象限A**: 舒适且有效（目标）
- **象限B**: 有效但不舒适
- **象限C**: 舒适但无效
- **象限D**: 不舒适且无效
