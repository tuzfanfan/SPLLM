Structured Personal Learning & LLM Management

让知识不只被收藏， 而是继续发生。

SPLLM 是一个持续演化的个人知识与项目操作系统。 它把零散材料组织成知识， 把知识提炼成方法， 再把方法送进真实世界。

01 / The System

一条从信息到行动的生产线

这里不追求把所有东西都塞进知识库，而是让每一层材料都有去处， 让洞察可以被检索、组合、验证，并最终成为项目与作品。

01

捕获

收集文章、书籍、对话、现场观察与热点信号，保留原始上下文和来源。

02

结构化

将材料拆成来源、实体、概念和事实，通过链接形成可导航的知识网络。

03

提炼

把反复出现的判断沉淀成框架、模板、脚本和可被 Agent 调用的技能。

04

落地

让知识进入报告、内容、产品、公益项目和真实合作，在反馈中继续进化。

02 / Working Fields

技术、知识与真实社会场景的交汇处

SPLLM 的价值不在于收集了多少页面，而在于它能否连接不同领域， 发现值得推进的问题，并形成可验证的最小行动。

FIELD / A

AI 知识工程

构建面向 LLM 的知识库、检索路径与技能系统，让信息处理逐步从手工劳动升级为可复用的工作流。

FIELD / B

青年科教文旅

连接粤港澳高校、企业、场馆与城市公共空间，设计兼具学习价值、体验价值与商业可行性的项目。

FIELD / C

公益与科普创新

把社会议题转化为可参与、可传播、可评估的公益方案，让专业知识真正抵达具体的人。

FIELD / D

青年创新创业

围绕真实任务、现场训练与资源协同，帮助青年团队从想法走向产品、合作与持续行动。

不制造内容堆积，尽量制造有效推进。
01 重视洞察，不堆砌废话。每一个结论都要说明它改变了什么。
02 重视结构，不迷失在碎片里。信息只有进入关系，才开始成为知识。
03 重视推进，不沉迷于看起来很忙。任务需要下一步，而不只是漂亮的总结。
04 重视积累，不只做一次性交付。重复出现的工作，应当沉淀成流程与能力。
05 重视真实，不迎合、不表演。允许不确定，但不把猜测包装成结论。
03 / Active Directions

把已有资源组织成可以向前走的项目

当前关注的不是抽象宏大叙事，而是高校、城市空间、青年人才与社会需求之间， 那些能够被连接和验证的具体机会。

Youth × Practice

青年真实项目共创与孵化

通过真实任务、专项人才招募和现场训练，让青年在交付中建立能力与合作关系。

人才网络项目闭环
Public Good × Media

把专业议题转译成公众可理解、可参与的内容和行动，兼顾社会价值与长期运营。

公共价值传播转化
Keep Building

知识库不是仓库。它应该是一套会长出行动的基础设施。

SPLLM 仍在持续构建中。页面、工具和方法会改变， 但方向保持一致：减少混乱，增加连接，让每一次思考都更接近真实世界。
