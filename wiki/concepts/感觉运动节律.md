# 感觉运动节律

## 定义

> **感觉运动节律（Sensorimotor Rhythm, SMR）** 指频率在12-15Hz范围内的脑波活动，属于低频Beta波。SMR与身体静止状态下的注意力集中和运动抑制相关，是[[神经反馈]]训练中的重要目标频段。

## 核心原理

### SMR的特征

| 特征 | 说明 |
|------|------|
| **频率范围** | 12-15Hz |
| **脑波分类** | 低频Beta波（又称Sensorimotor Rhythm） |
| **头皮位置** | 主要在感觉运动皮层（C3, C4, Cz） |
| **生理状态** | 身体静止但大脑清醒、注意力集中 |

### SMR与其他脑波的关系

| 脑波 | 频率 | 状态 | 与SMR的关系 |
|------|------|------|------|
| Theta波 | 4-8Hz | 深度放松、冥想 | SMR训练通常伴随Theta波降低 |
| Alpha波 | 8-12Hz | 放松但清醒 | SMR频率紧接Alpha波 |
| **SMR** | 12-15Hz | 静止专注 | 介于Alpha波和高频Beta波之间 |
| Beta波 | 15-30Hz | 警觉、焦虑 | SMR训练通常伴随高频Beta波降低 |

### SMR训练的原理

```
焦虑状态 → 高频Beta波升高 + SMR降低 → 神经反馈训练 → SMR升高 + 高频Beta降低 → 焦虑减轻
```

| 训练目标 | 说明 |
|------|------|
| **增加SMR** | 提高感觉运动节律活动 |
| **降低高频Beta** | 减少与焦虑相关的脑波活动 |
| **降低Theta** | 减少与分心相关的脑波活动 |

## 应用领域

| 领域 | 应用 |
|------|------|
| **焦虑治疗** | 通过SMR训练减轻焦虑症状 |
| **注意力训练** | 提高注意力和专注力 |
| **ADHD辅助** | 辅助治疗注意力缺陷多动障碍 |
| **运动表现** | 提高运动员的专注力和运动控制 |
| **睡眠改善** | 改善睡眠质量 |
