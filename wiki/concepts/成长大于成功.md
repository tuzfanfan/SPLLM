# 成长大于成功

## 定义

> **成长大于成功（Growth Over Success）** 是李笑来在《把时间当朋友》中提出的人生哲学。强调持续成长的过程比一时的成功结果更重要。真正的成功是持续积累和成长的自然结果，而非刻意追求的目标。

## 核心原理

### 成功 vs 成长

| 维度 | 追求成功 | 追求成长 |
|------|----------|----------|
| **关注点** | 结果 | 过程 |
| **时间观** | 短期 | 长期 |
| **心态** | 焦虑、比较 | 平和、专注 |
| **可持续性** | 不可持续 | 可持续 |
| **基础** | 运气+努力 | 积累+学习 |

### 成长的特征

| 特征 | 说明 |
|------|------|
| **持续性** | 每天进步一点点 |
| **内在驱动** | 由内在动机驱动而非外部奖励 |
| **可积累** | 成长成果可以叠加 |
| **抗挫折** | 将失败视为学习机会 |
| [[心智开启]] | 成长需要心智开启 |

### 成功的陷阱

| 陷阱 | 说明 |
|------|------|
| **一夜成名幻觉** | 忽视成功背后的长期积累 |
| **比较心态** | 与他人比较而非关注自身成长 |
| **固定目标** | 过于执着于特定结果 |
| [[思维陷阱]] | 认知偏差导致错误决策 |
