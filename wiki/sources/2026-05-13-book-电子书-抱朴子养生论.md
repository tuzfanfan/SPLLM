# 抱朴子养生论 - 来源摘要

## 概述

《抱朴子养生论》为晋代葛洪所撰，出自《正统道藏》洞神部方法类。全文以"一人之身，一国之象也"开篇，将人体比作国家，提出系统的养生理论。全文虽短，却浓缩了道家养生学的精髓，主张"治未病"、节制情欲、调和气血。

## 核心内容

### 身国同治理论

| 人体 | 国家 |
|------|------|
| 胸腹 | 宫室 |
| 肢体 | 郊境 |
| 骨节 | 百官 |
| 腠理 | 四衢 |
| 神 | 君 |
| 血 | 臣 |
| 气 | 民 |

### 十二少

少思、少念、少笑、少言、少喜、少怒、少乐、少愁、少好、少恶、少事、少机

### 十二多的危害

- 多思则神散，多念则心劳
- 多笑则脏腑上翻，多言则气海虚脱
- 多喜则膀胱纳客风，多怒则腠理奔血
- 多乐则心神邪荡，多愁则头鬓憔枯
- 多好则志气倾颓，多恶则精爽奔腾
- 多事则筋脉干急，多机则智虑沉迷

### 日常养生原则

- 不饥勿强食，不渴勿强饮
- 体欲常劳，食欲常少
- 劳勿过极，少勿至饥
- 冬朝勿空心，夏夜勿饱食
- 无久坐，无久行，无久视，无久听

## 关键洞察

1. **"施药于未病之前"**：预防胜于治疗，与《黄帝内经》"治未病"思想一脉相承
2. **"六害不除，修养之道徒设"**：不消除名利、声色等六害，一切养生方法都是空谈
3. **"伐人之生甚于斤斧"**：情欲过度对生命的损害比刀斧还厉害
4. **身心并重**：行欺诈则神悲，行善则魂神乐——道德修养也是养生的一部分
