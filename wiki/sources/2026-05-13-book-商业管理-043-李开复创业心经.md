# 李开复创业心经

**作者**: 徐宪江

## 核心观点

本书以李开复的创业经历为代表，分析了创业之路应该怎么走。李开复从学术界明星到IT行业精英，再到创办"创新工场"，展示了创业者应具备的品质和素质。

## 关键内容

### 1. 开复老师的创业六课

| 课程 | 核心内容 |
|------|----------|
| 第一课 | 创业者要野心勃勃：早早做好当老板的打算 |
| 第二课 | 创业者要激情四射：面对打击不气馁 |
| 第三课 | 创业者要厚积薄发：对未知风险有足够预见性 |
| 第四课 | 创业者要有强大的行动力：绝知此事要躬行 |
| 第五课 | 创业者要持之以恒：有喜有悲、有笑有泪 |
| 第六课 | 创业者人品不容打折扣：诚信、宽容、负责 |

### 2. 李开复的职业历程
- 苹果公司普通工程师
- 微软公司高管
- 谷歌全球副总裁、大中华区总裁
- 创办"创新工场"

### 3. 创业准备
- 近二十年的准备
- 财力、物力、人力准备
- 经验和阅历的积累
- 良好的心理素质

### 4. 核心理念
- "follow my heart"（追随我心）
- 帮助有志创业的青年实现梦想
- 义与利是不分家的
- 懂得回报社会
