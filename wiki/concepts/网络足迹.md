# 网络足迹

## 定义

> **网络足迹（Digital Footprint）** 指个人或组织在网络活动中留下的所有数字痕迹和数据记录。包括主动留下的（发帖、注册、购物）和被动留下的（浏览记录、位置数据、Cookie）。

## 核心原理

### 两大类型

| 类型 | 特征 | 示例 |
|------|------|------|
| **主动足迹** | 用户有意发布的信息 | 社交媒体帖子、评论、上传的照片 |
| **被动足迹** | 系统自动记录的数据 | 浏览历史、IP地址、位置信息、Cookie |

### 足迹来源

| 来源 | 数据类型 | 持久性 |
|------|----------|----------|
| **社交媒体** | 帖子、点赞、分享、关系 | 长期 |
| **浏览器** | 历史记录、Cookie、缓存 | 中期 |
| **电商平台** | 购买记录、浏览偏好、支付信息 | 长期 |
| **通信工具** | 聊天记录、通话记录 | 长期 |
| **定位服务** | GPS轨迹、Wi-Fi连接 | 中期 |
| **物联网** | 设备使用数据、传感器数据 | 长期 |

## 风险与影响

| 风险 | 说明 |
|------|------|
| **隐私泄露** | 个人信息被不当收集和使用 |
| **身份盗窃** | 足迹被用于冒充身份 |
| **社会工程** | 足迹被用于精准诈骗 |
| **画像歧视** | 基于足迹的算法歧视 |
| **数字绑架** | 足迹被永久保存无法删除 |

## 管理策略

| 策略 | 说明 |
|------|------|
| **最小化** | 减少不必要的信息发布 |
| **定期清理** | 清除Cookie、浏览记录等 |
| **隐私设置** | 合理配置各平台的隐私选项 |
| **加密通信** | 使用端到端加密的通信工具 |
| **数字素养** | 了解足迹产生机制和影响 |
