# 完美主义拖延

## 定义

> **完美主义拖延（Perfectionist Procrastination）** 指由[[完美主义]]驱动的拖延模式。拖延者因为害怕无法达到完美标准而选择推迟或放弃任务，核心信念是"如果做不到完美，不如不做"。

## 核心原理

### 拖延机制

```
高标准设定 → 完美预期 → 害怕不完美 → 焦虑/恐惧 → 拖延/回避 → 短期缓解 → 长期恶化
```

| 阶段 | 心理状态 | 行为 |
|------|----------|------|
| **标准设定** | 理想化 | 设定不切实际的高标准 |
| **预期形成** | 完美主义 | "必须做到最好" |
| **恐惧产生** | 焦虑 | "如果做不到怎么办" |
| **拖延启动** | 回避 | 推迟开始或完成 |
| **自我合理化** | 合理化 | "我还在准备" |

### 完美主义拖延的类型

| 类型 | 特征 | 表现 |
|------|------|------|
| **质量型** | 追求产出质量 | 无限修改、无法完成 |
| **准备型** | 追求充分准备 | 过度收集信息、不开始 |
| **条件型** | 等待完美条件 | "等我有空/有灵感再做" |
| **全有全无型** | 非黑即白思维 | 要么完美要么不做 |

### 与其他拖延成因的关系

| 关系 | 说明 |
|------|------|
| 与[[拖延的四个成因]] | 完美主义是四大成因之一 |
| 与[[自我妨碍]] | 完美主义拖延是一种自我妨碍 |
| 与恐惧管理 | 完美主义拖延是恐惧失败的表现 |

## 应对策略

| 策略 | 说明 |
|------|------|
| **追求"足够好"** | 降低标准，接受不完美 |
| **时间限制** | 设定严格的完成期限 |
| **分解任务** | 将大任务拆分为可管理的小步骤 |
| **完成优先** | 先完成再完善 |
| **自我关怀** | 接受自己的局限性 |
