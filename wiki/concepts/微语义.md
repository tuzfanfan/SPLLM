# 微语义

## 定义

> **微语义（Micro-semantic）** 指语言表达中微小的语义选择和变化，反映说话者的真实态度、情绪状态和认知过程。微语义是[[微反应]]体系在语言层面的表现。

## 核心原理

### 微语义类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **词汇选择** | 特定词汇的使用偏好 | 用"那个"代替具体名称 |
| **时态变化** | 时态的不一致使用 | 用过去时描述正在发生的事 |
| **人称转换** | 人称代词的异常使用 | 频繁使用"我们"或避免使用"我" |
| **语序变化** | 正常语序的偏离 | 将重要信息放在句末 |
| **重复模式** | 特定词汇或短语的重复 | 重复问题而非回答 |
| **省略模式** | 关键信息的省略 | 回避使用情绪词汇 |

### 分析方法

```
基线语言模式 → 偏离检测 → 微语义提取 → 心理状态推断
```

| 步骤 | 说明 |
|------|------|
| **基线建立** | 确定个体正常的语言表达模式 |
| **偏离检测** | 发现偏离基线的语言特征 |
| **微语义提取** | 分析偏离的语言特征含义 |
| **综合判断** | 结合面部和身体微反应综合判断 |
