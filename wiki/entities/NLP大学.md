# NLP大学
## 概述
NLP大学（NLP University）是由NLP联合创始人罗伯特·迪尔茨（Robert Dilts）和朱迪思·德洛齐耶（Judith DeLozier）创办的NLP培训机构，是全球NLP领域最权威的培训和认证机构之一。

## 关键属性
| 属性 | 内容 |
|------|------|
| 创始人 | 罗伯特·迪尔茨、朱迪思·德洛齐耶 |
| 性质 | NLP培训和认证机构 |
| 核心课程 | NLP及格执行师文凭、NLP高级文凭课程 |
| 与李中莹关系 | 承认李中莹设计的文凭课程 |

## 详细描述
NLP大学提供从入门到高级的完整NLP培训体系。李中莹设计的NLP及格执行师文凭课程获得NLP大学的承认，毕业学员可以直接报读其高级文凭课程。李中莹本人也于1998年在NLP大学参加了NLP及格执行师的高级文凭课程。
