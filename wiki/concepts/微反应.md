# 微反应

## 定义

> **微反应（Micro-reaction）** 指人在受到[[有效刺激]]后产生的短暂、不自主的反应，包括面部微表情和身体微反应。微反应持续时间极短（通常1/25秒到1/5秒），不受意识控制，能反映人的真实情绪和心理状态。

## 核心原理

### 微反应体系

| 类型 | 说明 | 持续时间 |
|------|------|----------|
| **微表情** | 面部肌肉的快速不自主运动 | 1/25-1/5秒 |
| **身体微反应** | 身体姿态、手势的微小变化 | 稍长于微表情 |
| [[微语义]] | 语言表达中微小的语义变化 | 即时 |

### 触发条件

```
有效刺激 → 情绪激活 → 微反应产生 → 快速抑制 → 恢复控制
```

| 条件 | 说明 |
|------|------|
| [[有效刺激]] | 刺激必须真正触发情绪反应 |
| **情绪激活** | 刺激强度足以激活情绪系统 |
| **快速抑制** | 意识试图控制情绪表达 |
| **泄漏** | 控制不完全，产生微反应泄漏 |

### 分析方法

| 方法 | 说明 |
|------|------|
| **情境分析** | 理解刺激源和背景 |
| **基线建立** | 确定个体的正常反应模式 |
| **变化捕捉** | 观察偏离基线的反应 |
| **多通道验证** | 综合面部、身体、语言信息 |
