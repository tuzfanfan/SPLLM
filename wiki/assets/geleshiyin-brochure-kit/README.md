# 《歌乐拾音》文化宣传册可编辑设计稿

## 文件说明

- `overview-board.svg`
  - 宣传册系统总览板，适合提案、汇报、定风格。
- `cover.svg`
  - 封面样板页。
- `genre-feature.svg`
  - 单一乐种介绍内页样板，以“汕尾渔歌”为示例。
- `lineage-atlas.svg`
  - 文献、图版、地图、谱系结合的信息页样板。

## 可编辑方式

- 可直接用 `Figma` 导入并继续拆层编辑。
- 可用 `Adobe Illustrator`、`Inkscape`、`Affinity Designer` 打开。
- 所有文字、分隔线、色块、版式框架都保留为矢量对象，方便继续替换内容。

## 当前设定

- 方向：岭南音乐文博、馆藏传播、学术普及
- 配色：米白、墨黑、旧书棕、黛绿、暗朱砂
- 语气：克制、温雅、展陈导览感

## 建议下一步
