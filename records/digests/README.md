# Digest 目录说明

本目录用于存放中间摘要产物。

Digest 的定位：

- 不是原始抓取
- 不是最终 wiki 知识页
- 是从“已命中的候选信息”到“正式知识沉淀”之间的过渡层

建议子目录：

- `daily/`
- `weekly/`
- `event/`

适合承载：

- 某个 intent 的日报
- 某个主题的周摘要
- 某次事件触发后的快速情报总结

参考模板：

- `../templates/digest-template.md`
- `../../wiki/intent-digest-state-schema.md`
