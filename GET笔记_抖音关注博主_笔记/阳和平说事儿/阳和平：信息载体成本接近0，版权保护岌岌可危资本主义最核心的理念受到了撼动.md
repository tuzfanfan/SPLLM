# 阳和平：信息载体成本接近0，版权保护岌岌可危资本主义最核心的理念受到了撼动

## 摘要

📚 **传统知识产权的载体**
- 过去知识产权有物质载体，如书、电影胶卷等。
- 以书为例，有版权方可以限制印数、定价，根据销售情况再版。

💻 **互联网对知识产权载体的改变**
- 互联网基本消灭了知识产权的物质载体，其载体存在于网络上。
- 如制作的软件可复制无穷次，复制成本几乎为0 。

📉 **互联网产品的边际成本**
- 互联网产品边际成本极低，如开源软件发展起来就是因为边际成本几乎是0 。
- 相比过去复印书籍有成本且被视为损害版权，在信息时代软件、电影复制边际成本近乎零。

👣 **版权保护面临的困境**
- 在边际成本为零的条件下，继续垄断显得荒谬，导致盗版现象普遍，如八九十年代中国Windows多为盗版。
- 信息时代信息传播边际成本几乎为0，版权保护越来越难。
