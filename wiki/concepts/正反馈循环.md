# 正反馈循环

## 定义

> **正反馈循环（Positive Feedback Loop）** 在习惯形成和行为改变中，指每次完成目标行为后产生的正面强化效应，使行为更有可能被重复。[[微习惯]]策略的成功很大程度上依赖于正反馈循环的建立。

## 核心原理

### 循环机制

```
完成微习惯 → 小成功感 → 自我效能感提升 → 多巴胺释放 → 动力增加 → 更可能执行 → 习惯强化
```

| 阶段 | 心理效应 | 生理效应 |
|------|----------|----------|
| **完成行为** | 成就感 | [[多巴胺]]释放 |
| **自我肯定** | 自我效能感提升 | 内啡肽释放 |
| **动力增加** | 更有动力执行 | 奖赏系统激活 |
| **习惯强化** | 行为更自动化 | 神经通路强化 |

### 正反馈 vs 负反馈

| 类型 | 效果 | 示例 |
|------|------|------|
| **正反馈循环** | 行为被强化，越来越强 | 完成微习惯 → 感觉好 → 继续做 |
| **负反馈循环** | 行为被削弱，越来越弱 | 拖延 → 自责 → 更不想做 |

### 微习惯中的正反馈

| 特征 | 说明 |
|------|------|
| **低门槛** | 容易完成，确保正反馈的产生 |
| **高频次** | 每天执行，频繁产生正反馈 |
| **累积效应** | 小成功积累成大改变 |
| [[自我效能感]] | 逐步提升自我效能感 |
