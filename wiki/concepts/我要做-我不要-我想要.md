# 我要做/我不要/我想要

## 定义

> **"我要做/我不要/我想要"（I Will / I Won't / I Want）** 是凯利-麦格尼格尔在《自控力》中提出的意志力三面向模型。这三个力量分别对应前额叶皮层的不同区域，共同构成完整的意志力系统。

## 核心原理

### 三大力量

| 力量 | 功能 | 脑区 | 示例 |
|------|------|------|------|
| **我要做（I Will）** | 推动自己去做需要但不想做的事 | 前额叶皮层左侧 | 起床锻炼、开始工作 |
| **我不要（I Won't）** | 抑制冲动和诱惑 | 前额叶皮层右侧下方 | 不吃甜食、不刷手机 |
| **我想要（I Want）** | 记住长期目标和真正欲望 | 前额叶皮层中部 | 记住减肥目标、职业理想 |

### 三者的关系

```
"我想要"（长期目标）→ 指导"我要做"和"我不要"的具体行为
"我要做" → 主动推进目标相关行为
"我不要" → 抑制偏离目标的行为
```

| 关系 | 说明 |
|------|------|
| **"我想要"是核心** | 提供方向和动力 |
| **"我要做"是推进** | 克服惰性，采取行动 |
| **"我不要"是刹车** | 抑制冲动，保持方向 |

### 神经科学基础

| 脑区 | 功能 | 损伤后果 |
|------|------|----------|
| 前额叶皮层左侧 | "我要做"力量 | 缺乏动力、拖延 |
| 前额叶皮层右侧 | "我不要"力量 | 冲动、成瘾 |
| 前额叶皮层中部 | "我想要"力量 | 缺乏方向感、短视 |

## 训练方法

| 力量 | 训练方法 |
|------|----------|
| **我要做** | 设定微目标、[[实施意图]]、建立习惯 |
| **我不要** | 暴露疗法、环境设计、延迟满足训练 |
| **我想要** | 明确价值观、可视化目标、定期反思 |

## 常见失败模式

| 失败模式 | 说明 | 应对 |
|------|------|------|
| **只靠"我不要"** | 过度依赖抑制，消耗意志力 | 结合"我要做"和"我想要" |
| **"我想要"模糊** | 长期目标不清晰 | 明确具体的目标和价值观 |
| **三者冲突** | 短期欲望与长期目标冲突 | 强化"我想要"的连接 |
