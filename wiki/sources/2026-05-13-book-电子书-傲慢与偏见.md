# 傲慢与偏见 - 来源摘要

## 概述

《傲慢与偏见》（Pride and Prejudice）是英国女作家简·奥斯丁（Jane Austen）发表于1813年的经典小说。小说以英国乡绅班纳特一家五个女儿的婚姻问题为主线，通过伊丽莎白·班纳特与达西先生从误解到相知相爱的故事，深刻揭示了19世纪初英国社会的阶层偏见、婚姻观念和人性弱点。开篇名句"凡是有钱的单身汉，总想娶位太太，这已经成了一条举世公认的真理"成为文学经典。

## 核心内容

### 主要人物

| 人物 | 身份 | 性格特征 |
|------|------|---------|
| 伊丽莎白·班纳特 | 二女儿 | 聪明、独立、有主见，但容易形成偏见 |
| 达西先生 | 富有绅士 | 高傲、内敛、善良，但给人傲慢印象 |
| 班纳特太太 | 母亲 | 急于嫁女儿，缺乏教养 |
| 班纳特先生 | 父亲 | 冷幽默，对家庭事务漠不关心 |
| 简·班纳特 | 大女儿 | 温柔善良，但过于含蓄 |
| 宾利先生 | 达西之友 | 和蔼可亲，但缺乏主见 |
| 韦克翰 | 军官 | 表面迷人，实则虚伪 |
| 柯林斯牧师 | 班纳特财产继承人 | 谄媚、愚蠢 |

### 婚姻观的层次

- **经济婚姻**：夏洛特嫁给柯林斯——"纯粹为了经济安全"
- **情欲婚姻**：莉迪亚与韦克翰——"只有激情没有理性"
- **理想婚姻**：伊丽莎白与达西——"爱情与尊重并重"

### 社会阶层与财富

- 达西先生年入一万英镑（当时顶级富豪）
- 宾利先生年入四五千英镑
- 班纳特家年入两千英镑
- 柯林斯与夏洛特：经济上勉强自足

## 关键洞察

1. **"傲慢让别人无法来爱我，偏见让我无法去爱别人"**：标题精准概括了两个主角的性格缺陷
2. **奥斯丁的社会批判**：通过婚姻这一"窗口"透视整个英国乡绅社会的阶层固化与价值观扭曲
3. **女性经济困境**：班纳特家财产限定继承给男性，五个女儿必须通过婚姻获得经济保障
4. **讽刺与幽默**：奥斯丁以"自由间接引语"创造了一种既讽刺又温和的叙事风格
