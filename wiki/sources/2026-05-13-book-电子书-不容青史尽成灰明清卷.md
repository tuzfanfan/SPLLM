# 不容青史尽成灰——明清卷 - 来源摘要

## 概述

《不容青史尽成灰——明清卷》是张嵚所著的历史随笔集，以独特的视角重新解读明清两朝的重大历史事件和人物。第一章以朱元璋的成功为切入点，通过刘基的"义军九恶论"这一被历史遗忘的"盲点"，深刻揭示了朱元璋问鼎天下的真正原因，以及中国历代农民起义重复失败的深层规律。

## 核心内容

### 刘基"义军九恶论"

| 九恶 | 内容 | 历史印证 |
|------|------|---------|
| 一恶 | 不敬孔孟，亵渎圣人之道 | 红巾军焚烧学堂、拆毁宗庙 |
| 二恶 | 攻伐无度，形同流寇 | 刘福通三路北伐毫无战略目的 |
| 三恶 | 时降时反，相互猜疑 | 郭子兴与孙德崖明争暗斗 |
| 四恶 | 粮饷不能自足，不知兵法 | 多数义军未受正规训练 |
| 五恶 | 掠人妻女财产，取之于民 | 山东"赤地千里" |
| 六恶 | 为将者心胸狭隘 | 郭子兴欲治死朱元璋 |
| 七恶 | 为士者缺乏训练，形同群殴 | 遇元朝名将即连连败绩 |
| 八恶 | 胜时聚集，败时作鸟兽散 | 西路军败后一路溃散 |
| 九恶 | 义军之间相互猜疑攻伐 | 相互征伐次数远超对元作战 |

### 朱元璋的"九不恶"实践

- 设"礼贤馆"招纳知识分子
- 采用"高筑墙广积粮缓称王"之策
- 推行屯田制度保障粮饷
- 拥有徐达、常遇春、李文忠等名将

### 历代对朱元璋成功的评价

- 董伦（明初）："天命所属，时运眷顾"
- 张居正："太祖得天下，因不拘成法也"
- 赵翼（清）："圣贤，豪杰，盗贼之性，实兼而有之"
- 李光涛（近现代）："用贤，善学，敢战"

## 关键洞察

1. **"千古名骂，万载相传"**：朱元璋闻"九恶"先怒后笑，体现了其超越农民起义局限性的政治智慧
2. **农民起义的宿命**：汤因比所言"农民起义之所以重复相同的失败，只因为他们是农民起义"
3. **"九恶"的普适性**：不仅预言了元末群雄的失败，也适用于明末起义和太平天国运动
4. **战胜自我的勇气**：化"九恶"为"九不恶"需要与自身出身勇敢决裂
