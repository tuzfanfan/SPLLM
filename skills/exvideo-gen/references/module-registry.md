## Routing

If no module matches:

1. Use the core workflow without a module.
2. Record the missing domain-specific fields encountered.
3. Complete 3-10 real examples before proposing a reusable module.
4. Add the module only after user approval.

If several modules match, select one primary module and at most one supporting module. Core inheritance and IDs remain shared.
