## 核心观点（深度提炼）

### 1. 成瘾的神经机制

**核心命题**：成瘾是大脑奖赏系统被劫持的结果，多巴胺在其中起关键作用。

```
成瘾回路：
  药物/行为 → 多巴胺激增 → 奖赏系统激活 → 强化行为 → 耐受性 → 依赖
```

| 脑区 | 功能 | 成瘾中的作用 |
|------|------|------------|
| **腹侧被盖区（VTA）** | 多巴胺神经元集中区 | 成瘾的核心启动区 |
| **伏隔核** | 奖赏中心 | 多巴胺释放的主要靶点 |
| **前额叶皮层** | 决策、冲动控制 | 成瘾后功能受损 |
| **杏仁核** | 情绪处理 | 戒断时焦虑和渴求 |

### 2. 多巴胺：双刃剑

| 作用 | 正常功能 | 成瘾状态 |
|------|----------|----------|
| **动机** | 驱动追求奖励 | 过度追求药物/行为 |
| **愉悦** | 感受快乐 | 快感迟钝，需要更多药物 |
| **学习** | 强化有益行为 | 强化成瘾行为 |
| **预测** | 预测奖励信号 | 线索诱发强烈渴求 |

### 3. 成瘾的四大特征

| 特征 | 说明 |
|------|------|
| **强迫性寻求** | 无法控制地寻找药物/行为 |
| **失控** | 使用剂量越来越大 |
| **渴求** | 强烈欲望，即使知道有害 |
| **复发** | 戒断后极易复吸 |
