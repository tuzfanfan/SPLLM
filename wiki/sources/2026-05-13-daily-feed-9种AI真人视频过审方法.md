## 二、9种AI真人视频过审方法

### 思路一：角色多视图设定卡（信息轰炸）

#### 方法① 角色面部特写+全身三视图+6肖像 21:9
- **推荐度**：⭐⭐⭐⭐⭐
- **优点**：角色一致性控制好
- **缺点**：Seedance 2.0理解难，可能生成多个人物
- **布局**：左区25%面部特写 + 中区45%三视图 + 右区30%六宫格肖像

#### 方法② 全身视图+6肖像 16:9
- **推荐度**：⭐⭐⭐⭐
- **用途**：当方法①的21:9面部特写不通过时使用
- **布局**：左区40%全身双视图 + 右区60%六宫格肖像

#### 方法③ 全身视图+局部特写 2:3
- **推荐度**：⭐⭐⭐⭐
- **用途**：当方法①②都不通过时使用
- **布局**：九宫格，含面部特写、侧脸、眼部/嘴部/手部局部特写

#### 方法④ 多角度九宫格拼贴
- **推荐度**：⭐⭐⭐
- **特点**：适合不需要过多服装要求的短片，让Seedance 2.0自己补全细节

### 思路二：风格转绘、人脸和服装分离

#### 方法⑤ 素描线稿头部+无面部白模人台三视图
- **推荐度**：⭐⭐⭐⭐
- **核心**：彻底规避人脸识别
- **布局**：左栏头部素描线稿 + 右栏无脸白模人台三视图

#### 方法⑥ 彩铅风格肖像+人脸面部特征移除的三视图
- **推荐度**：⭐⭐⭐⭐
- **核心**：白模化仅限面部，其余全身维持真实摄影质感
- **布局**：左栏彩铅面部特写 + 右栏写实全身白模三视图

### 思路三：Seedance 2.0 提示词内容设定

#### 方法⑦ 结合意图用文案绕过限制
- **推荐度**：⭐⭐⭐
- **核心策略**：
  1. 明确告诉即梦你是用AI生成的人物
  2. 给真实语境、创作环境
  3. 在图片上打上"此人物由AI生成"水印
  4. 用拖动到对话框的方式，少用上传

**推荐文案模板**：
```
现代霸道总裁实拍短剧，9:16，电影级写实质感，适配抖音、红果短剧平台。
```

#### 方法⑧ 降低画质模糊法
- **推荐度**：⭐⭐⭐
- **核心**：4K图片不行时试试2K、1K，太高清反而影响过审
- **处理要点**：分辨率降低至1K、轻微动态模糊、自然手持拍摄抖动感

### 思路四：搭载Seedance 2.0的其他平台审核机制

#### 方法⑨ 用Seedance 2.0真人合规校验
- **推荐度**：⭐⭐⭐⭐
- **推荐平台**：小云雀、libtv、tapnow（审核机制相对宽松）
- **流程**：在第三方平台生成 → 用四种叙事方法拼接优化

## 三、关键提示词模板

### 角色设定卡通用结构
```
[画幅与背景] 比例 + 纯白棚拍背景 + 统一柔光
[角色锚点] 以参考图为唯一身份锚点，严格保持一致性
[整体构图] 分区布局说明
[各区域内容] 详细描述每个区域的内容
[画质与质感] 高端写实棚拍/电影级人像质感，8K超清
[强约束] 禁止文字/logo/水印/二次元/多人物/畸形
```

### 画质降级提示词
```
[主体一致性] 构图/角度/姿态/服装/光比/色调一致
[画质降级处理] 分辨率降低至1K，轻微动态模糊，
自然手持拍摄抖动感，轻度噪点与胶片颗粒，
轻微景深虚化，非超高清，非锐利
```
