# 音画一体

## 定义

音画一体是指AI视频生成模型在生成视频画面的同时，自动或按提示词指令生成与画面内容高度匹配的音频（环境音效、人声对白、音乐配乐），实现视频与音频的一体化创作体验。该能力由 [[Seedance 1.5 Pro]] 首次引入。

## 三大音频能力

### 1. 环境音效（环境/声景）

模型能自动识别场景并生成匹配的环境音，也可通过提示词精细控制。

**能力要点**：
- 自动识别场景生成匹配环境音（海浪声、雨声、街道车流、人群嘈杂等）
- 支持通过提示词控制环境音种类、出现时机、方位
- 支持动态声场（远近变化、左右位置感）及静音留白
- 支持多音源混合（如施工声+挖掘机声、锣鼓声+鞭炮声+欢呼声）

**提示词示例**：
```
固定镜头，风吹书页翻页声，远处若隐若现的海浪声以及海鸥的声音
```

```
邮轮发出轰鸣声在海上航行，周围响起浪花激起的声音和海鸟的叫声
```

### 2. 人声对白

模型能自动生成自然、真实、口型同步的人声对白。

**能力要点**：
- 支持单人独白与多人对白，自动生成符合人物身份和场景的语音
- 支持多语言与口音多样性（中文、英文、粤语、四川方言等）
- 支持提示词精控对白内容（指定关键词、完整台词、说话顺序、语速与停顿）
- 支持丰富情绪表达（喜悦、悲伤、生气、惊讶、恐惧、平静等）
- 实现精准口型同步（正脸、侧脸、遮挡、快速运动镜头均可）
- 支持非语言人声（笑声、叹息、喘息等）
- 支持特殊音色（机械音、不同年龄音色）

**注意事项**：
- 提示过多角色或台词时，可能出现表达顺序或语调不准确
- 复杂停顿、打断、长对白、重叠语音的稳定性仍在优化
- 暂不支持唱歌内容的完整控制

### 3. 音乐配乐

模型可自动为视频生成背景配乐，风格与画面氛围匹配。

**能力要点**：
- 自动匹配视频情绪氛围（温暖、紧张、浪漫、神秘等）
- 支持指定风格的音乐背景
- 支持多种音乐风格（史诗级、科技感、圣诞主题、中式婚礼、古风等）

**注意事项**：
- 暂不支持生成指定旋律或具体歌曲
- 复杂场景下可能与画面节奏契合不够

## 适用场景

| 场景 | 说明 | 音频能力组合 |
|------|------|-------------|
| 影视场景 | 多角色对白、音画同步、情绪演绎 | 人声对白 + 环境音效 + 音乐配乐 |
| 广告场景 | 产品讲解、卖点表达、配乐烘托 | 人声对白 + 音乐配乐 |
| 宣传场景 | 场景声+旁白+配乐组合 | 人声对白 + 环境音效 + 音乐配乐 |
| 知识科普 | 自然口播配画面 | 人声对白 + 音乐配乐 |
| 娱乐场景 | 沉浸式音效体验（ASMR） | 环境音效 |
| 音乐表演 | 乐器演奏、音乐表演 | 环境音效 + 音乐配乐 |

## 使用要点

- 即使不写音频相关提示词，模型也会自动生成合适的音效
- 有明确声音需求时，建议写入提示词以获得更可控效果
- 可通过"耳麦式收音效果"等关键词实现沉浸式声音
