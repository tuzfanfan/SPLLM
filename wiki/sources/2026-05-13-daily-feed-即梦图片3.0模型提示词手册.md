# 即梦图片3.0模型提示词手册

## 概述

即梦图片3.0模型核心亮点：**真实、高清、专业、文字准确**

---

## 一、模型亮点详解

### 1. 真实：去AI味、以假乱真

#### a. 质感真实
- 去除磨皮感、假脸感、AI油腻感
- 画面质感接近真实摄影与专业设计

#### b. 情绪真实
- 去僵硬感、摆拍感、AI眼神空洞感
- 情绪细腻有感染力
- 支持"剑拔弩张"、"沮丧落泪"等复杂情绪

### 2. 高清：默认1K、可支持2K

- 图像清晰度和结构准确性显著提升
- 2K时画面结构更准确
- 支持1.5K、3.0K等多种分辨率

### 3. 专业：专业级的画面效果

#### a. 影像场景
更准确的电影类型片、镜头语言响应

| 电影类型片 | 镜头语言 |
|------------|----------|
| CG概念 | 大特写 |
| 电影剧照 | 特写 |
| 恐怖片 | 近景 |
| 纪录片 | 中景 |
| 爱情片 | 全景 |
| 公路片 | 大远景 |
| 武侠片 | 背面 |
| 香港电影 | 浅景深 |
| 悬疑片 | 动态模糊 |
| DC电影宇宙风格 | 柔焦镜头 |
| War film | 猫眼镜头 |
| Romance film | 鱼眼镜头 |
| Western Film | 俯视视角 |
| 情景喜剧风格 | 仰视视角 |

#### b. 动漫场景
- 风格更多元、细节更丰富、色调更统一
- 不再有2.1的"抠图感"

### 4. 文字：更准确的字体响应、专业的设计排版

#### a. 多字体与多字重支持
- 大字小字都能响应
- 解锁更多有设计感的艺术字体
- 细致区分了不同字重（细体、适中、粗体、特粗体）

#### b. 图文排版专业
支持以下排版组合：
- 手写字体 + 手绘插画
- 创意字体 + 矢量插画
- 常规字体 + 写实摄影

---

## 二、提示词秘籍

### 核心要点一：用简单直接的语言表达
- 短提示词也能发挥惊艳的效果
- 长提示词并不一定代表好的生图效果
- 自己输入的提示词可能会比AI生成的更有效

### 核心要点二：用连贯的自然语言 + 短词语描述
- 用连贯的自然语言描述画面内容（主体 + 行为 + 环境等）
- 用短词语描述画面美学（风格、色彩、光影、构图等）

### 核心要点三：文字内容用引号标注
把想要生成的文字内容插入""引号中，可以提升文字准确率

### 额外建议
- 专业词汇推荐尝试词源语言/英文（如"微距镜头"用 macro lens）
- 推荐写出图像用途和类型

## 三、响应词典分类

涵盖六大分类：
1. 热门词
2. 美学词
3. 潮流风格
4. 艺术风格
5. 影像风格
6. 设计风格

### 美学词分类

| 色调 | 光线 | 构图与视角 |
|------|------|------------|
| 暖色调 | 自然光 | 俯视视角 |
| 冷色调 | 侧光 | 仰视视角 |
| 复古色调 | 逆光 | 平视视角 |
| 高饱和度 | 柔光 | 广角构图 |
| 低饱和度 | 硬光 | 特写构图 |

## 四、字体效果与排版

### 4.1 艺术字体类型

| 字体名称 | 风格描述 |
|----------|----------|
| 哥特体 | 哥特风格，适合暗黑、神秘主题 |
| 英文花体 | 优雅的英文装饰字体 |
| 黑体标题字 | 醒目的黑体大标题 |
| 创意手写体 | 手绘风格，线条跳跃，色彩渐变，趣味童真 |
| 毛笔字 | 大字报，秀丽笔，笔锋有力，线条奔放 |
| 金属质感黑体 | 科技感，有机械棱角，有霓虹光和不规则几何块 |
| 文艺手写体 | 白色秀丽笔风格字体，明显的毛笔书写质感 |

### 4.2 构图方式

| 构图类型 | 适用场景 |
|----------|----------|
| 模块化构图 | 信息展示、品牌海报 |
| 对称构图 | 正式场景、产品展示 |
| 分割构图 | 对比展示、创意海报 |
| 上下构图 | 图文分层、标题海报 |
| 左右构图 | 图文并列、宣传物料 |
| 居中构图 | 突出主体、极简设计 |
