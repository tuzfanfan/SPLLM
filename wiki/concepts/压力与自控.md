# 压力与自控

## 定义

> **压力与自控（Stress and Self-Control）** 描述了压力对自控力的双重影响。适度压力可以增强自控力（挑战反应），但慢性压力会削弱前额叶皮层功能，导致自控力下降（威胁反应）。

## 核心原理

### 压力的双重效应

| 压力类型 | 生理反应 | 自控力影响 |
|------|------|------|
| **适度压力（挑战反应）** | 适度皮质醇和肾上腺素释放 | 自控力短期增强 |
| **慢性压力（威胁反应）** | 持续高皮质醇 | 自控力长期下降 |
| **极端压力** | 前额叶皮层功能关闭 | 完全失去自控 |

### 生理机制

```
压力刺激 → 杏仁核激活 → HPA轴激活 → 皮质醇释放
适度：前额叶皮层功能增强 → 自控力提升
过度：前额叶皮层功能抑制 → 自控力下降
```

| 脑区 | 适度压力 | 过度压力 |
|------|----------|----------|
| 前额叶皮层 | 功能增强 | 功能抑制 |
| 杏仁核 | 适度激活 | 过度激活 |
| 海马体 | 正常 | 萎缩 |

### 压力-自控循环

| 循环类型 | 说明 |
|------|------|
| **良性循环** | 压力 → 有效应对 → 自控力增强 → 更好应对压力 |
| **恶性循环** | 压力 → 应对失败 → 自控力下降 → 更难应对压力 |
