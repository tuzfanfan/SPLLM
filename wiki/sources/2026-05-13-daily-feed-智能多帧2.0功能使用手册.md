# 智能多帧2.0功能使用手册

## 概述

智能多帧2.0是即梦智能多帧功能的全面升级版本，在各个维度的效果上都有所提升，在使用灵活性与创作深度上有显著增强。

### 基础参数

| 参数项 | 说明 |
|--------|------|
| 支持帧数 | 20帧 |
| 帧间时长 | 0-8s自己选择，视频总共最长可达到160s（颗粒度精确到0.5s） |
| 输入类型 | 图片 / 视频（限制8s以内） |
| 分辨率 | 720p / 1080p |
| 提示词 | 针对两帧中间过渡写提示词 |

---

## 2.0版本核心升级

### 1. 支持视频素材输入

用户现在不仅可以上传图片生成视频，还支持上传视频段落，进行"视频 + 视频"或"视频 + 图片"的拼接创作。

**场景支持**：
- 对已有视频进行续写或转场生成
- 多素材混合与拼接（创意视频、短视频内容）
- 多镜头视频制作（广告和短片创作）

### 2. 新增"仅尾帧"模式

打通"从无到有"的起点生成能力。现在支持"第一帧之前"直接写入提示词，模型会以提示词为依据生成起始画面。

### 3. 片段编辑功能

用户可对智能多帧的段落进行局部reroll、加减帧或重新生成，保留其他内容不变。

**功能说明**：
- **局部编辑**：用户锁定其它段落，仅对目标段落重新生成新版本
- **解锁/上锁机制**：点击加锁可保护不动帧段，未锁部分为本轮编辑对象
- **加帧/减帧**：在局部位置添加或删减帧，使转场更自然或节奏更合适

**后编辑流程**：
1. 视频生成之后，选择左下角的「片段编辑」
2. 对满意的片段可选择「锁定该运镜」
3. 「锁定片段」延续原先内容，不额外消耗积分
4. 「解锁片段」会重新生成，消耗积分

### 4. 更自由的时间控制

- 新增对更小单位的时间支持，精确到0.5s
- 支持0s硬切拼接

## 适用场景

### 1. 空间运镜类（空间穿梭）

**提示词编写结构**：
```
【镜头运动方式】+【下一张图片的空间元素】+【环境氛围】+（可选情绪/动作）
```

**基础运镜词**：
- 镜头拉近 / 镜头拉远 / 固定镜头
- 镜头水平向右/左平移
- 镜头垂直向上/下移动
- 镜头俯视拍摄 / 镜头仰视拍摄
- 镜头旋转进入下一场景
- 镜头高速穿越 / 镜头360度环绕
- 镜头俯冲 / 镜头拔升 / 镜头穿梭 / 镜头贴地飞行

**有主体时的运镜**：
- 镜头跟随主体向+方向运动
- 镜头360度环绕主体
- 镜头从主体背后穿越到正面
- 镜头缓慢推进并聚焦主体细节

### 2. 角色动态类（复杂主体动态）

**提示词编写结构**：
```
【角色身份/外观】+【关键动作】+【环境元素】+【镜头运动方式】+（可选情绪/氛围）
```

### 3. 产品展示类（商业产品广告）

**提示词编写结构**：
```
【镜头运动方式】+【产品部位/特征】+【展示细节/功能】+【环境氛围/质感】
```

### 4. 节奏驱动类（卡点视频）

**提示词编写结构**：
```
【镜头运动方式/画面变化方式】+【变化元素/主体动作】+【节奏感修饰词】+【环境氛围】
```

### 5. 叙事类

**提示词编写结构**：
```
【镜头运动方式】+【当前画面内容】+【过渡方式/动作】+【下一画面内容】+【氛围/情绪】
```

### 6. 循环动画

首帧和尾帧保证图片一样即可，可以成为循环壁纸。

---

## 提示词编写关键要素

1. **明确镜头运动方式**：始终明确镜头的运动方式
2. **简洁且有针对性的描述**：重点描述关键元素
3. **注重情感和动作的衔接**：精确描写人物的动作与情感
4. **根据场景类型调整提示词**：不同场景类型有不同的提示词要求

**重要提醒**：不建议不写提示词。关键帧越好视频效果就越好，如果没有足够的信息，一定要写精准的提示词。

---

## 2.0版本使用建议

- 智能多帧2.0需要在3.0fast模型上使用
- 利用"仅尾帧"功能可以从无到有生成起始画面
- 使用片段编辑功能可以灵活修正长视频中的不满意部分
- 利用0s硬切拼接可以实现快速转场效果
