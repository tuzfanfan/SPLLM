# 精通Spring 2.x Java Web开发 - 来源摘要

## 概述

### Spring框架核心概念

- **IoC（控制反转）**：将对象的创建和依赖关系管理交给容器
- **AOP（面向切面编程）**：将横切关注点从业务逻辑中分离
- **MVC（模型-视图-控制器）**：Web层的架构模式
- **Spring 2.x新特性**：相比1.x版本的增强功能
