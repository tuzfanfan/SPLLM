# 1分钟摄影诊所：数码摄影曝光秘笈 - 来源摘要

## 概述

《1分钟摄影诊所：快速掌握数码摄影的曝光秘笈》由尚品工作室编著，是一部数码摄影曝光技术教程。全书采用案例分析的结构形式，通过上百张案例图片（人物、风光、景物等），从错误案例中讲解不合理之处并进行改正，涵盖外界因素对曝光的影响和各种特殊曝光技法的应用。

## 核心内容

### 曝光基本原理

> "曝光就是摄影！控制光的能力是拍出好照片的根本。"

| 概念 | 说明 |
|------|------|
| **曝光定义** | 光线强度乘以光线作用时间，即相机进入光线的多少 |
| **光圈** | 控制进光量和景深 |
| **快门** | 控制进光时间和动体清晰度 |
| **曝光补偿** | EV值调整，如+0.3EV |

### 曝光选择的艺术

- 小光圈→深远景深（风景摄影）
- 高快门→凝固动体（运动摄影）
- 短景深→虚化背景突出主体（人像摄影）
- 慢快门→增强动感（流水、车流）

### 数码摄影的优势

- 相机内置测光模式与白平衡控制
- 大量后期图像制作软件
- 即时预览和调整

## 关键洞察

1. **"自动曝光"vs"选择曝光"**：自动相机无思维能力，人的主动选择才是摄影创作的核心
2. **曝光的感性色彩**：不像数学公式有固定答案，需要根据不同情况不断实践积累
3. **胶片时代的严谨性**：胶片时代不容有失的曝光要求，造就了一批优秀摄影先贤
4. **案例教学的有效性**：从错误案例中学习比纯理论教材更实用
