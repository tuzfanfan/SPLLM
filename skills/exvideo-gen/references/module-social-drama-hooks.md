# Social Drama Hooks

`module.id: social-drama-hooks`

Use this module when the user wants short-form drama built for high retention, strong emotional readability, and episode-end conversion pressure. Typical requests include:

- short vertical drama structure
- episode hook design
- emotional cliffhanger rhythm
- female-audience drama beat planning
- how to build a paid-point ending

Treat this module as a retention-first narrative layer. The goal is not generic screenwriting quality in the abstract; it is to produce a repeatable beat engine with strong hook density and escalating emotional payoff.

## What This Module Changes

This module mainly modifies:
- Stage 1: Story and Script
- Stage 4: Storyboard
- Stage 6: Prompt Compilation

## Core Principle

Keep beat names reusable and plot specifics replaceable.

## Beat Engine

Common reusable beat families:

- opening visual hit
- extreme humiliation
- hidden setup clue
- small face-slap reversal
- ally reveal
- betrayal proof
- public comeback
- life-and-death crisis
- impossible moral dilemma
- episode-end cliffhanger

Each episode should lock:
- dominant emotional target
- 3-5 beat names
- end-hook type
