# 心理谋略

| 属性 | 内容 |
|------|------|
| 作者 | 多湖辉（日本） |
| 出版信息 | 广西民族出版社 1991年 |
| 类型 | 心理学通俗读物 |
| 核心主题 | 揭示操纵人的思想与行为的心理法则，涵盖知己心、知彼心、控制大局三个方面 |

## 核心观点

1. 操纵人的思想与行为的动力，除了命运伟力之外，还有一种深藏于我们所有人心中的心理活力。
2. 人往往是稀里糊涂地做了自己的心的俘虏，在尚未警觉之前就已受自己的心灵所指使。
3. 全书分为三大部分：知己心18诀（自我认知与控制）、知彼心54诀（了解和影响他人）、控制大局26诀（大众心理与消费心理）。
4. 心理谋略可应用于自我提升、人际交往、管理领导、商业营销和大众控制等多个领域。
5. "害人之心不可有，防人之心不可无"，心理技巧首先应作为防卫手段，认破他人意图，不入他人圈套。
