# 3分钟识别人才：善用面试的20种方法

**作者**: 李桂虹,吴利霞

## 概述

一本面向HR和管理者的面试实用指南，介绍了20种有效识别人才的方法。全书从面试前的准备到面试中的技巧，再到面试后的评估，提供了系统的人才选拔方案。强调在短时间内（3分钟内）快速判断候选人是否适合岗位需求的能力。

## 核心内容

| 主题 | 内容 |
|------|------|
| 面试准备 | 岗位分析、面试问题设计、评估标准制定 |
| 识别方法 | 行为面试、情景模拟、压力面试等20种方法 |
| 快速判断 | 3分钟内捕捉关键信息的能力 |
| 评估体系 | 多维度评估候选人综合素质 |
| 常见误区 | 面试中的主观偏差及其纠正方法 |

## 关键洞察

- 现代人力资源招聘体系
- 行为面试法（STAR原则）
| 面试中的认知偏差与纠正
- 胜任力模型与人才评估
- 劳动法与招聘合规要求
