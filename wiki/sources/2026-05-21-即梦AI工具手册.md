# 即梦AI工具手册

> 即梦（Jimeng）是强大的AI视频/图片生成工具，支持文生视频、图生视频、音画一体等多种创作模式。

## 核心功能（深度提炼）

### 1. 音画一体（Seedance 1.5 Pro）

**三大音频能力**：

| 能力 | 说明 | 案例 |
|------|------|------|
| **环境音效** | 自动识别场景，生成匹配环境声（海浪、雨声、街道车流） | 海浪声、鸟鸣、风声 |
| **人声对白** | 支持多语言、多角色、多种情绪（喜悦、悲伤、生气、惊讶） | 单人独白、多人对话、非语言声音（笑声、叹息） |
| **音乐配乐** | 自动匹配视频情绪氛围（温暖、紧张、浪漫、神秘） | 抒情、紧张、激昂、宁静 |

**技术亮点**：
- **口型同步**：无论正脸、侧脸、遮挡或快速运动，音画一致
- **多语言支持**：中英双语切换流畅，支持部分小语种和方言
- **情绪演绎**：喜悦、悲伤、生气、惊讶、恐惧、平静等
- **动态声场**：远近变化、左右位置感、静音留白

### 2. 视频生成（Seedance 系列）

| 版本 | 核心能力 | 适用场景 |
|------|----------|----------|
| **3.0** | 基础视频生成 | 短视频、社交媒体内容 |
| **3.5 Pro** | 音画一体、多模态 | 影视制作、广告、宣传片 |
| **4.0** | 提升画质、稳定性 | 专业视频制作 |
| **4.5** | 更强真实性、细节 | 影视级作品 |
| **2.0** | 全新多模态体验 | 跨模态创作 |

**提示词构成要素**：
```
主体（人物/动物/物体）+ 运动（静止/运动）+ 场景（前景/背景）+ 镜头语言（特写/长焦/航拍）+ 光影（晨光/夕阳/灯光）+ 氛围（热闹/温馨/电影级调色）
```

**运镜控制**：
- 超大远景、特写、长焦拍摄、地面拍摄、顶部拍摄、航拍
- 镜头切换、景深、镜头晃动、固定镜头

### 3. 图片生成

| 版本 | 核心能力 | 提示词重点 |
|------|----------|----------|
| **3.0** | 基础图片生成 | 主体+动作+背景+光影+氛围 |
| **4.0** | 提升真实感、细节 | 更准确的文字渲染、材质表现 |
| **4.5** | 电影级质感 | 更强的光影、氛围、艺术风格 |

**提示词公式**：
```
主体（详细描述）+ 动作（姿态/表情）+ 场景（室内/室外/自然）+ 镜头（角度/景别）+ 光影（氛围光/丁达尔效应/灯光）+ 风格（写实/动漫/电影级）+ 负面词（不希望出现的内容）
```

### 4. 数字人（OmniHuman 1.5）

- **功能**：生成逼真数字人，支持动作、表情、语音同步
- **应用**：虚拟主播、数字客服、影视替身
- **特点**：自然动作、真实表情、口型同步
