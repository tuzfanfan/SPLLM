# 竞争优势情绪 — 回款周期与业务价值

## 概述

商业是环境函数，是资本的一种跨周期配置。评估一项业务是否是好业务，需回到最底层看资本的**时间价值、风险定价、现金流贴现**。

---

## 现金流贴现公式

```
NPV = 未来现金流 × (1 - 违约概率) ÷ (1 + 贴现率)^时间
```

**关键洞察**：回款周期越长，时间变量t越大，分母指数级增长，NPV就会减小。在其他条件相同的情况下，回款周期越长，业务价值越低。

---

## 长回款周期的成功案例：电梯行业

### 商用电梯企业（迅达、OTIS等）特点

| 阶段 | 说明 |
|------|------|
| 签合同到收款 | 1-3年 |
| 预付款 | 发货前收取高额预付款，覆盖制造成本 |
| 上游账期 | 对零部件供应商实行长账期 |
| 违约成本 | 开发商拖欠尾款→拒绝移交特种设备合格证和主板密码 |
| 后续收益 | 锁定未来十几年的维保服务现金流 |

### 成功三要素

| 要素 | 说明 |
|------|------|
| **占上游资金** | 或有能力拿到低成本融资 |
| **绑定客户** | 通过技术或业务让客户不敢违约 |
| **高毛利** | 足以覆盖跨周期的资金成本 |

**本质**：长周期健康业务让企业变成了拥有产业垄断地位的**类金融机构**。

---

## 长回款周期的失败案例

| 类型 | 问题 |
|------|------|
| 办公室租赁设备公司 | 被迫用短期高息债务支持长期营收 |
| 定制化注塑模具 | 客户产品销量惨淡时，放弃沉没成本远小于继续下单成本 |
| 市政园林绿化工程 | 5年付款周期，用10%毛利中标，贴现现金流在合同签订时已是负数 |

---

## 关键洞察

1. **回款周期长不是毒药**：可能变成资本壁垒，天然排斥缺乏低成本融资能力的中小竞争者

2. **巨头策略**：拥有极低资本成本的巨头企业可能故意进入长回款周期行业，用资本优势对竞争对手做降维打击

3. **小公司出路**：如果提供的是深度嵌入客户物理或数学基础设施的关键节点，长周期就变成了锁定客户、排挤竞争对手的商业杠杆
