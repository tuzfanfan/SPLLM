# 礼仪金说

## 概述

本书是著名礼仪专家金正昆教授的礼仪经典著作，系统介绍了商务、社交、职场、国际交往等各个领域的礼仪规范。

## 核心内容

| 领域 | 核心内容 |
|------|----------|
| 个人礼仪 | 着装、仪容、举止、表情 |
| 社交礼仪 | 介绍、握手、名片、宴请 |
| 商务礼仪 | 会议、谈判、接待、拜访 |
| 国际礼仪 | 各国文化差异与交往禁忌 |

## 关键洞察

1. 礼仪的本质是尊重——尊重自己和尊重他人
2. 细节决定成败，礼仪体现在每一个微小行为中
3. 不同的文化背景有不同的礼仪规范
4. 良好的礼仪修养是职业竞争力的重要组成部分
