# 现实法则

## 定义

> **现实法则（Reality Principles）** 是李笑来在《把时间当朋友》中总结的一系列关于现实的基本规律。接受这些法则是心智开启和持续成长的前提。

## 核心原理

### 主要法则

| 法则 | 说明 | 启示 |
|------|------|------|
| **速成不可能** | 任何有价值的事情都需要时间 | 接受积累的必要性 |
| **交换是本质** | 一切有价值的东西都需要付出 | 没有免费的午餐 |
| **完美不存在** | 追求完美是徒劳的 | 追求"足够好" |
| **未知永远存在** | 我们永远无法知道一切 | 保持谦逊和学习 |
| **现状无法马上摆脱** | 改变需要时间和过程 | 接受现实，逐步改变 |
| **与时间做朋友** | 时间不可管理，只能与之合作 | [[时间不可管理]] |

### 法则之间的关系

```
速成不可能 → 需要积累 → 积累需要时间 → 与时间做朋友
交换是本质 → 需要付出 → 付出需要坚持 → 持续成长
完美不存在 → 接受不完美 → 专注于进步 → [[成长大于成功]]
```

### 违反法则的后果

| 违反法则 | 后果 |
|------|------|
| 追求速成 | 被骗、失望、放弃 |
| 不愿交换 | 停滞不前 |
| 追求完美 | 拖延、焦虑 |
| 自以为全知 | 停止学习、犯大错 |

## 应用策略

| 策略 | 说明 |
|------|------|
| **接受现实** | 不抱怨，不幻想 |
| **专注于可控** | 管理自己而非外部环境 |
| **长期视角** | 用长期视角看待问题 |
| 积累 | 通过持续积累实现目标 |
| 自学能力 | 持续学习应对未知 |
