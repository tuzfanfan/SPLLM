# UML基础、建模与设计实战 - 来源摘要

## 概述

《UML基础、建模与设计实战》由杨弘平、吕海华、李波、史江萍编著，是一部系统讲解统一建模语言（UML）的教材。全书共13章，涵盖UML的各种图形（用例图、类图、对象图、顺序图、协作图、状态图、活动图、组件图、部署图）以及RUP过程开发模型，配有4个实战案例。

## 核心内容

### 全书结构

| 部分 | 章节 | 内容 |
|------|------|------|
| 入门基础 | 第1-3章 | 面向对象概述、UML概述、UML开发工具 |
| 图 | 第4-8章 | 用例图、类图、对象图、序列图、协作图、状态图、活动图、组件图、部署图 |
| RUP | 第9章 | 统一软件过程RUP |
| 案例 | 第10-13章 | 汽车租赁系统、BBS系统、新闻管理系统、数码录音机系统 |

### UML发展历程

| 时间 | 事件 |
|------|------|
| 1994年10月 | Booch、Rumbaugh、Jacobson开始创建UML |
| 1996年 | 发布UML 0.9 |
| 1997年11月 | OMG采纳UML为标准建模语言 |
| 2000年后 | 推出UML 2.0版本 |

### 面向对象技术

- 软件发展近60年，面向对象技术应用近40年
- UML是最重要的面向对象建模技术成果
- 面向对象已成为软件开发的主流方法

## 关键洞察

1. **UML的标准化**：从个人方法到国际标准，UML统一了软件建模的语言
2. **理论与实践结合**：通过4个实战案例将理论知识转化为实际技能
3. **面向对象的主流地位**：40年来面向对象技术已成为软件开发分析、设计、实现的主流方法
4. **RUP过程框架**：UML与RUP的结合提供了完整的软件开发方法论
