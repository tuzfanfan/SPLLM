# FBI教你10秒钟读懂面部微表情

**作者**: 霍晨昕

## 概述

一本关于面部微表情识别的心理学读物，借鉴FBI的行为分析技术，教导读者如何通过观察他人的面部微表情来判断其真实想法。全书系统介绍了人类七种基本情绪（快乐、悲伤、愤怒、恐惧、惊讶、厌恶、轻蔑）在面部表情中的表现特征，以及如何通过微表情线索进行有效的心理洞察。

## 核心内容

| 主题 | 内容 |
|------|------|
| 七种基本情绪 | 快乐、悲伤、愤怒、恐惧、惊讶、厌恶、轻蔑 |
| 微表情特征 | 每种情绪对应的面部肌肉反应 |
| 观察技巧 | 如何在10秒内捕捉关键面部线索 |
| 实际应用 | 商务谈判、人际交往中的微表情分析 |
| 科学基础 | 保罗·艾克曼的面部动作编码系统(FACS) |

## 关键洞察

- 保罗·艾克曼的面部动作编码系统
- 微表情的神经科学基础
- 情绪的跨文化一致性研究
- 行为分析与心理洞察方法
- 谎言识别的科学方法
