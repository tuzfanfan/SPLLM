# 可灵O1 — 图片O1使用指南

## 概述

图片O1是可灵推出的全新一代全能型图像创作模型，突破性优化全流程创作体验——无需在多个工具或功能间反复切换，即可实现从基础图像生成到高阶细节编辑全链路无缝衔接。

**核心交互**：以"自然语言 + 图像"的多模态描述作为核心交互入口，依托强大的世界知识与视觉推理能力，精准解析综合意图。

---

## 模型亮点

### 1. 特征高度保持

支持最多**10张参考图**的特征提取，可精准锁定各图的主体轮廓、核心元素与色调基调。

**适用场景**：
- IP角色系列设计
- 漫画分镜创作
- 品牌周边统一风格设计

### 2. 细节修改精准响应

无需专业修图技能，仅凭文字指令即可实现图片中物品与人物的精准增、删、改操作。

**核心优势**：
- 保持原图风格、光影、质感等核心特征
- 生成效果自然协调
- 显著减少操作步骤

### 3. 风格调性准确把控

深度解构参考图的风格内核，精准捕捉笔触肌理、色彩搭配与构图逻辑。

**支持风格类型**：
- 全身手办、鱼眼亲亲、JOJO、漆画、柯南、辛普森
- 手办、恶搞之家、chibi动漫3D、小马宝莉、素描
- 吉卜力、新海诚、儿童绘本、珠宝盒、蒸汽朋克
- 废土科幻风、英雄联盟、魂系游戏、未来科幻、机甲风
- 棉花娃娃、漫威漫画、月份牌、瑞克和莫蒂、芭比娃娃
- 老版宣传画、蜡笔画等

### 4. 超丰富想象力

具备强大的创意想象力，支持复杂指令理解，融合多图特征完成创意再创作。

## 使用场景

### 1. 影视类创作

#### 人物角色多视图
上传角色参考图，生成同一角色的多种视角图。

**支持视角类型**：正视、侧视、背面、特写、大特写、左斜侧、右斜侧、顶视等

#### 拍摄角度/高度修改
- 角度修改：过肩镜头、前侧斜打镜头等
- 高度修改：平视、俯视、仰视

#### 景别修改
全景、中景、近景、特写等

#### 表情修改
支持微笑、怒视、惊恐、大笑、调皮、悲伤、高傲、嫌弃等

#### 光影修改
支持侧光、柔光、逆光、光影斑斓、舞台光、面光、冷调光等

#### 色调修改
对图片的色调风格进行调整

### 2. 人像处理与风格化

- **证件/肖像照**：生成多种风格的专业肖像照
- **人物写真照**：生成不同风格、不同场景的人物写真
- **多人/角色合影**：融合生成多人合影效果
- **头像风格化**：将人像转换为多种风格的头像

### 3. 电商内容生产

#### 商品展示
通过文字指令生成专业级商品展示图片，适用于护肤品、饮品、酒类等

#### 虚拟试穿
将服装、鞋子、配饰等穿戴到模特身上进行虚拟试穿展示

## 提示词手册

### 图片编辑提示词技巧

**基本公式**：
```
保持其他不变，将【编辑对象】修改为【变化效果】
```

**正确示例**：
- 保持图中其他不变，将【杯子材质】改成【玻璃材质】
- 把图中男孩整体掉个个儿，让他头朝下

**错误示例**：
- 男生的头和脚换个方向（指令不够明确，抽卡率高）

### 人脸参考提示词技巧

**公式**：
```
保持【参考图人物】的长相，人物是【发型】，人物穿着【服装】，【动作】，背景是【背景描述】，【光影效果】的光影效果，【氛围】的氛围感。
```

**示例**：
```
保持【图1中女生】的长相，人物是【侧麻花辫发型，头上别着一朵浅蓝色的花】发型，人物穿着【孔雀蓝的旗袍，白色复古皮鞋】，【手梳理着头发，微微歪头】动作，背景是【室内背景，欧式复古家具】，【阳光从侧面窗户照进来】的光影效果，【温暖复古】的氛围感。
```

## 编辑功能分类

### 人像编辑

| 编辑类型 | 指令模板 | 可选项 |
|----------|----------|--------|
| 美颜 | 给图片中的人【】 | 磨皮、祛斑、美白、大眼、去掉唇纹、整体美化 |
| 发型 | 将发型改为【】 | 短发、卷发、丸子头、长直发、高马尾、低马尾、麻花辫 |
| 动作 | 将动作改为【】 | 摸头发、看向镜头、跪在地上、站着双手交叉等 |
| 服装 | 将服装改为【】 | 复古美式、旗袍、辣妹风、黑色婚纱、JK |

### 元素编辑

| 编辑类型 | 指令模板 |
|----------|----------|
| 增加元素 | 在图片中添加【元素描述】 |
| 删除元素 | 删除图片中的【元素描述】 |

### 箭头/框选/涂鸦编辑

| 编辑方式 | 使用方法 | 示例指令 |
|----------|----------|----------|
| 箭头编辑 | 在图片上绘制箭头指示 | 删除箭头指向的人物；箭头视角拍摄；按照箭头颜色和方向打光 |
| 框选编辑 | 在图片上框选指定区域 | 删除框选的物体；框选部分的服装改成红色 |
| 涂鸦编辑 | 在图片上涂鸦指定区域 | 涂鸦后提交编辑指令 |

### 材质修改

支持材质类型：
- 刺绣风格、毛线材质、软糖材质、纸雕材质、毛绒材质
- 超轻粘土材质、亚麻布材质、玻璃材质、牛仔布材质
- 木质材质、棉花材质、积木材质、竹编风格、油画风格
- 珍珠贝壳材质、蕾丝材质、丝绸材质、气球材质、陶瓷材质

### 信息图生成

**指令模板**：
```
根据这个图生成：【深度图/线稿图/轮廓图/热成像/x光图】
```

### 其他修改

- 黑白照片上色
- 做旧效果
- 去水印
- 添加涂鸦
- 体型变化
- 超清修复
