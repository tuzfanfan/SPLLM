# FBI教你10秒钟读懂面部微表情

## 概述

《FBI教你10秒钟读懂面部微表情》是霍晨昕所著的心理学普及读物，以保罗·艾克曼（Paul Ekman）的微表情理论为基础，系统介绍了如何通过观察面部微表情来辨别他人的真实情绪。微表情最短持续1/25秒，最长不超过1/4秒，却能出卖被刻意掩饰的真实情绪。

全书从面部肌肉解剖入手，详细分析了额肌、皱眉肌、眼轮匝肌、口轮匝肌等关键肌肉群与情绪的对应关系，为读者提供了一套科学的"读脸"方法。

## 核心内容

### 微表情的科学基础

| 概念 | 内容 |
|------|------|
| 微表情定义 | 持续1/25秒到1/4秒的短暂面部表情变化 |
| 发现者 | 保罗·艾克曼，20世纪80年代末 |
| FBI应用 | 20世纪90年代初被FBI采用并沿用至今 |
| 核心原理 | 有些面部肌肉（含平滑肌）无法被意识控制 |

### 七种基础情绪

| 情绪 | 眉毛表现 | 眼睛表现 | 嘴部表现 |
|------|----------|----------|----------|
| 快乐 | 舒展 | 眼角出现鱼尾纹（真笑标志） | 嘴角上扬 |
| 愤怒 | 眉头向眉心集中下压 | 眼睑半闭合、眼球轻微向上 | 唇紧闭、下巴后缩 |
| 悲伤 | 眉梢下压、眉头上扬 | 眼睑下垂、目光呆滞 | 嘴角下垂 |
| 厌恶 | 皱眉 | 眼睛眯起 | 上唇外翻、鼻子皱起 |
| 惊讶 | 眉毛上扬 | 眼睛睁大 | 嘴巴张开 |
| 恐惧 | 眉毛上扬并聚拢 | 上眼睑提升、下眼睑紧张 | 嘴唇紧张微张 |
| 轻蔑 | 单侧眉毛上扬 | — | 单侧嘴角上扬 |

### 关键面部肌肉

- **额肌**：眉毛上方，影响眉毛和眼睛变化
- **皱眉肌**：眉毛内侧，愤怒时形成眉间垂直褶皱
- **上睑提肌**：含平滑肌（不随意肌），无法被意识控制，是识别真实情绪的关键
- **眼轮匝肌**：眼睛周围，真笑时会出现鱼尾纹
- **口轮匝肌**：环绕嘴巴，控制闭唇、撅嘴等动作

### 真假表情的辨别

- **真表情**：无意识反应，不受控制
- **假表情**：刻意伪装，有意识反应
- **不对称表情**：一边大一边小，是戳穿谎言的重要手段
- **表现准则**：社交中人人学会控制表情和掩饰真实情绪

## 关键洞察

1. **上睑提肌是"诚实肌肉"**：含有平滑肌，无法被意识控制，真实情绪必然通过它暴露
2. **真笑的标志**：杜兴微笑（眼角出现鱼尾纹）vs 社交微笑（只有嘴动），前者才是真笑
3. **微表情需要训练**：通常练习者看过几百张脸之后，就能捕捉微表情和辨别表情真假
4. **情境综合判断**：不能仅凭单一表情判断，需要结合背景信息和多种线索
5. **微表情的伦理边界**：用途不是恶作剧、卖弄才能和伤害他人，使用前需准备一个善良的念头
