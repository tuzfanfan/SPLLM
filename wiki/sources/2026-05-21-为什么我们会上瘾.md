## 核心观点（深度提炼）

### 1. 成瘾的神经机制

**核心发现**：成瘾物质劫持大脑的奖赏系统（多巴胺系统）。

```
使用成瘾物质 → 多巴胺激增 → 大脑适应（受体减少）→ 耐受性增加 → 需要更多物质 → 成瘾
```

### 2. 常见成瘾类型

| 类型 | 成瘾物质/行为 | 神经机制 |
|------|-----------------|----------|
| **物质成瘾** | 尼古丁、酒精、海洛因、可卡因 | 多巴胺系统劫持 |
| **行为成瘾** | 赌博、游戏、色情、购物 | 同样的奖赏回路 |
| **现代成瘾** | 手机、社交媒体、短视频 | 间歇性奖励，更强成瘾性 |

### 3. 成瘾的恶性循环

```
使用 → 快感 → 耐受 → 需要更多 → 失控 → 戒断症状 → 复吸 → 循环
```

### 4. 为什么难以戒断？

| 原因 | 说明 |
|------|------|
| **神经适应** | 大脑结构已改变，需要长时间恢复 |
| **戒断症状** | 焦虑、抑郁、失眠、疼痛 |
| **环境线索** | 看到相关场景就触发渴求 |
| **情绪触发** | 压力、无聊、社交场合容易复吸 |

## 关键概念提取

| 概念 | 定义 | 应用 |
|------|------|----------|
| **成瘾** | 失控的、强迫性的物质使用或行为 | 临床诊断、治疗规划 |
