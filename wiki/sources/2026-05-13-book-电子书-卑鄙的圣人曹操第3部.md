# 卑鄙的圣人：曹操（第3部）- 来源摘要

## 概述

《卑鄙的圣人：曹操》第3部由王晓磊著，聚焦中平六年（公元189年）汉灵帝驾崩后的政治大变局。小说详细描绘了何进被杀、宦官覆灭、董卓进京独霸大权的历史进程，以及曹操在这场巨变中的处境和应对。

## 核心内容

### 历史事件时间线

| 事件 | 经过 |
|------|------|
| 汉灵帝驾崩 | 中平六年（189年），刘辩继位 |
| 何进被杀 | 何进调四方兵马进京，被张让等宦官抢先杀死 |
| 宫廷大乱 | 曹操、袁术、袁绍兴兵攻入宫殿，外戚与宦官两败俱伤 |
| 董卓进京 | 螳螂捕蝉黄雀在后，董卓率西凉兵以护驾为名控制洛阳 |

### 洛阳之乱

- 凉州军和并州军瓜分京城防务，牛皮帐搭到平阳大街
- 何进心腹部队变成无人管辖的匪类
- 西园校尉（曹操等五人）兵马损失过半，都亭驿被并州兵占据
- 夏牟被吴匡所杀，赵融被张璋和董旻骚扰

### 曹操的应对

- 一剑刺死并州斥候兵长，救下鲍信、鲍韬兄弟
- 与袁绍商议集结兵马对抗董卓势力
- 意识到"只要兵权在手就有挽回的希望"

## 关键洞察

1. **"螳螂捕蝉黄雀在后"**：何进、宦官、董卓三方博弈，最终武夫董卓成为最大赢家
2. **洛阳的沦陷**：羌人、匈奴人、屠格人充斥京城，"仿佛一群强盗闯进了富庶人家的宅院"
3. **曹操的政治觉醒**：在混乱中意识到兵权的重要性，开始从"问题青年"向"政治家"转变
4. **并凉军事集团的蛮横**：丁原、董卓的军队不受朝廷节制，标志着东汉中央权威的彻底崩溃
