# 贵州人民出版社

## 概述
> 贵州省综合性地方出版社，出版地址位于贵州省贵阳市观山湖区。

## 关键属性

| 属性 | 值 |
|------|-----|
| 类型 | 出版社 |
| 所属领域 | 图书出版 |
| 成立时间 | 1951年 |
| 地址 | 贵州省贵阳市观山湖区会展东路SOHO办公区A座 |
| 关键特征 | 贵州省综合性地方出版机构 |

## 详细描述

### 背景
贵州人民出版社是贵州省重要的综合性出版机构，出版范围涵盖社科、文学、教育、生活等多个领域。

### 核心特点
- 出版了大量地方文化类图书
- 在心理学通俗读物领域有相关出版记录
- 出版物以大众读物为主
