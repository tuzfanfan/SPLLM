# Facebook之父马克·扎克伯格 - 来源摘要

## 概述

《Facebook之父马克·扎克伯格：后乔布斯时代的传奇》由林志共、王静合著，是一部全面介绍Facebook创始人马克·扎克伯格创业历程的传记作品。全书从Facebook的商业价值、社交广告模式、开放平台战略等角度，深入分析了Facebook如何从一个哈佛宿舍项目成长为估值千亿美元的互联网巨头，以及扎克伯格如何成为"硅谷创新精神的最好接班人"。

## 核心内容

### Facebook的商业价值

| 维度 | 数据/描述 |
|------|----------|
| 月活跃用户 | 超过8亿（2011年） |
| 日均信息上传 | 近75亿张图片、2000万个视频 |
| 用户停留时间 | 超过53分钟/天 |
| 2011年营收 | 37.1亿美元 |
| 2011年净利润 | 10亿美元 |
| IPO估值 | 约1000亿美元 |

### Facebook vs Google 广告模式

| 维度 | Google | Facebook |
|------|--------|----------|
| 广告触发 | 用户主动搜索关键词 | 基于用户资料精准推送 |
| 说服能力 | 无法说服用户购买 | 53分钟停留时间足以说服 |
| 前瞻性 | 只有用户想买时才搜索 | 捕捉潜在需求提前投放 |
| 社交传播 | 无 | 可影响用户的好友圈 |

### 开放平台战略

- 2007年开放Facebook平台
- 超过52000个应用程序
- 来自180个国家的超过100万注册开发人员
- 每月300亿次点击率
- 50多家年收入超500万美元的软件公司

## 关键洞察

1. **"史上命中率最高的媒介"**：基于真实用户信息的精准广告投放远超传统媒体
2. **"硅谷创新精神的最好接班人"**：乔布斯对扎克伯格的高度评价
3. **"广告变成内容"**：Facebook让广告以互动活动的形式出现，不引起用户反感
4. **"蝴蝶效应"**：Facebook上市影响了中国社交网站股价（人人网暴涨60%）
