# 2010注册会计师全国统一考试教材：经济法

## 概述

本书是2010年度注册会计师全国统一考试的经济法科目官方教材，由中国注册会计师协会组织编写。内容涵盖民法通则、公司法、证券法、合同法、票据法、税法等经济法律制度，是CPA考试备考的权威参考资料。

## 核心内容

| 法律领域 | 核心内容 |
|----------|----------|
| 民法基础 | 民事法律行为、代理、诉讼时效 |
| 公司法 | 公司的设立、组织机构、股权转让 |
| 证券法 | 证券发行、上市、交易制度 |
| 合同法 | 合同的订立、履行、违约责任 |
| 票据法 | 汇票、本票、支票的法律规定 |
| 税法 | 增值税、企业所得税等税种 |

## 关键洞察

1. 经济法是注册会计师必备的专业知识；2. 公司法和证券法是经济法的核心内容；3. 合同法是市场经济活动的基础法律；4. 税法知识对会计实务至关重要；5. 系统学习经济法有助于提升职业素养。
