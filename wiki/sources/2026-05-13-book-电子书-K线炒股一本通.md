# K线炒股一本通 - 来源摘要

## 概述

《K线炒股一本通》由古应荣著，是一部面向新老股民的K线技术分析入门读物。全书从K线的基础知识讲起，涵盖经典技术分析理论和实战买卖点把握，所有实例均取材于国内A股市场。书中强调"能看懂K线不代表能真正使用K线"，关键在于透过K线解读出重要的市场信息。

## 核心内容

### K线的基础知识

| 要素 | 说明 |
|------|------|
| 起源 | 300多年前的日本德川幕府时代，用于记录米价 |
| 引入西方 | 1990年美国人史蒂夫·尼森以《阴线阳线》引进 |
| 四个价位 | 开盘价、收盘价、最高价、最低价 |
| 阳线 | 开盘价低于收盘价（红色），表示上涨 |
| 阴线 | 开盘价高于收盘价（绿色），表示下跌 |
| 构成 | 上影线、实体、下影线三部分 |

### K线的市场含义

- **实体长短**：表明多方或空方取得的战果
- **上影线**：反映价格在盘中的上冲情况
- **下影线**：反映价格在盘中的下探情况
- **时间单位**：日K线最常用，其次为周K线

### 全书结构

- 第1-4章：K线基础知识、股市获利之道、经典技术分析理论
- 第5-8章：实战部分，通过K线形态结合实盘案例讲解买卖点

## 关键洞察

1. **"K线具有东方人独特的具像思维方式"**：不仅呈现价格轨迹，更蕴含丰富的市场信息
2. **"资金裂变效应"**：股市的最大魅力在于本金可以在短时间内成倍增长
3. **"能看懂不代表能使用"**：识别K线形态容易，准确理解和运用才是关键
4. **"博弈竞技场"**：股市中一方盈利建立在另一方亏损之上，需要掌握生存技巧
