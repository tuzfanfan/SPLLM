# MAOA基因

## 定义

> **MAOA基因（Monoamine Oxidase A Gene）** 编码单胺氧化酶A，该酶负责分解大脑中的神经递质（如血清素、多巴胺、去甲肾上腺素）。MAOA基因的特定变异（低活性型）与攻击性行为和心理变态倾向有关，被称为"战士基因"。

## 核心原理

### 基因功能

```
MAOA酶 → 分解神经递质 → 调节情绪和行为
MAOA低活性 → 神经递质积累 → 情绪调节障碍 → 攻击性增加
```

| 神经递质 | 正常功能 | MAOA低活性的影响 |
|------|------|------|
| 血清素 | 情绪稳定、冲动控制 | 情绪不稳定、冲动性增加 |
| 多巴胺 | 奖赏、动机 | 奖赏寻求行为增加 |
| 去甲肾上腺素 | 应激反应 | 应激反应过度 |

### "战士基因"假说

| 要素 | 说明 |
|------|------|
| **发现** | 1993年荷兰研究团队发现MAOA基因突变与攻击行为 |
| **机制** | 低活性MAOA导致神经递质代谢异常 |
| **争议** | 基因决定论 vs 基因-环境交互 |

### 基因-环境交互

```
MAOA低活性 + 不良童年环境 → 高攻击性风险
MAOA低活性 + 良好童年环境 → 正常或低攻击性
MAOA高活性 + 不良童年环境 → 中等攻击性风险
MAOA高活性 + 良好童年环境 → 低攻击性
```

| 环境因素 | 影响 |
|------|------|
| **童年虐待** | 显著增加MAOA低活性者的攻击性 |
| **良好教养** | 可以缓冲MAOA低活性的负面影响 |
| **社会支持** | 有助于降低基因风险的表达 |
