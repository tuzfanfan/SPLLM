# 李鸿章全传

## 概述

本书是晚清重臣李鸿章的全面传记，从其早年科举入仕到主导洋务运动、从甲午战争到签订不平等条约，完整呈现了李鸿章复杂而矛盾的一生。

## 核心内容

| 时期 | 主要活动 |
|------|----------|
| 早年 | 科举入仕，投奔曾国藩幕府 |
| 洋务运动 | 创办淮军、江南制造总局、轮船招商局 |
| 外交舞台 | 处理中法战争、甲午战争等重大外交事件 |
| 晚年 | 签订《马关条约》，周旋列强之间 |

## 关键洞察

1. 李鸿章是中国近代化的重要推动者，但受限于时代和体制
2. 洋务运动'中体西用'的路线有其历史必然性
3. 李鸿章的外交困境反映了晚清中国的国际处境
4. 对李鸿章的评价需要放在具体历史语境中
