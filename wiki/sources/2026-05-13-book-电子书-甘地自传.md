# 甘地自传

## 概述

本书是甘地的自传，副标题为'我体验真理的故事'。甘地以坦诚的态度回顾了自己从童年到中年的人生历程，包括在伦敦求学、在南非发展非暴力理念、以及回到印度领导独立运动等经历。

## 核心内容

| 人生阶段 | 关键经历 |
|------|----------|
| 童年 | 印度古吉拉特邦的虔诚家庭 |
| 求学伦敦 | 学习法律，接触西方文明 |
| 南非时期 | 面对种族歧视，发展非暴力理念 |
| 回到印度 | 领导独立运动，推行非暴力不合作 |

## 关键洞察

1. 非暴力不是软弱，而是需要更大勇气的力量
2. 真理的追求需要持续的自律和自我反省
3. 个人行为的改变是社会变革的基础
4. 简朴生活是精神自由的前提
