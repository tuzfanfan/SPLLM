# 心理和脑：脑与心智历程100项

| 属性 | 内容 |
|------|------|
| 作者 | Tom Stafford, Matt Webb |
| 出版信息 | 科学出版社 2007（O'Reilly出版） |
| 类型 | 科普读物/认知神经科学 |
| 核心主题 | 通过100个实验和窍门探索大脑如何工作，从脑部地理、视觉、注意力、听觉语言、整合、运动、推理、组合、记忆到他人理解 |

## 核心观点

1. 大脑更像一个生态系统而非电脑，"人脑如电脑"的譬喻已经过时。
2. 视觉系统存在诸多"骗术"和"捷径"，我们看到的并非世界的真实面貌，而是大脑构建的模型。
3. 注意力在信息到达意识层之前就已经完成了过滤，存在注意力的"漏洞"（变化盲视、非注意盲视）。
4. 大脑并非总是服从主人的意志，它有自己的"自治能力"，揭示这一点是"娱乐神经科学"的方向。
5. 感觉整合是多通道的，McGurk效应等证明了视觉和听觉的深层交互。
6. 人类的理性是有限的，容易被数字误导，但在检测社会契约（如作弊）时逻辑技能会高度活跃。
7. 记忆是可塑的，可以制造错误记忆，也可以通过情境改善记忆。
8. 我们对他人的理解有特殊的神经机制，包括面孔识别、情绪信号解读和镜像神经元系统。
