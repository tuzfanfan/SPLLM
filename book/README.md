# book 文件夹

> 精品书籍素材专用文件夹

## 用途

存放平时阅读的精品书籍素材，用于：
- 书籍内容整理与笔记
- 配合 `book2skill` 技能进行书籍蒸馏
- 构建个人知识库

## 文件类型

- `.pdf` / `.epub` / `.txt` — 书籍原文
- `.md` — 读书笔记、书摘、整理后的内容
- `.docx` — 整理后的文档（可选）

## 与 book2skill 的配合

当需要拆书/蒸馏书籍时：
1. 将书籍文件放入此文件夹
2. 告知 AI "我要拆这本书"
3. AI 会调用 `book2skill` 技能执行 RIA-TV++ 六阶段流水线

## 命名规范

建议格式：`书名_作者_出版年.扩展名`

示例：
- `反脆弱_塔勒布_2014.pdf`
- `思考快与慢_卡尼曼_2011.epub`
- `深度工作_纽波特_2016.md`
