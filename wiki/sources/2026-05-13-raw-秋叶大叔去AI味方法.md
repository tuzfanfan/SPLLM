## 概述

本文由秋叶大叔分享，系统解析AI写作的"AI味"特征及去除方法。核心观点：AI味主要源于逻辑过于外显、表达空洞模板化、正确的废话。针对网文小说、书稿、自媒体文章三种文体，提供精准的提示词公式去除AI味。

## 核心内容

### 一、AI味重的8个特征

| 特征 | 示例 |
|-----|-----|
| 不是A，而是B | 成功的秘诀不是勤奋，而是选择正确的方向 |
| If...then... | 如果说奋斗是青春的底色，那么坚持就是它的印记 |
| 事实上/实际上 | 很多人认为AI会取代人类，实际上，它是人类的工具 |
| 滥用比喻和固定结构 | 恰似一面棱镜，折射出XXX的深层博弈 |
| 过度使用逻辑连接词 | 此外，更重要的是，我们必须认识到这一点的关键性 |
| 句尾的"现在分词尾巴" | 这次会议是一个关键时刻，凸显了该领域的持续相关性 |
| 空洞的夸大形容词 | 这个公园提供令人惊叹的景色和现代的设施 |
| 对数字的刻意罗列 | 在凌晨4点二十七分听见自己第11次呼吸 |

### 二、AI味的三大根源

1. **逻辑过于外显与规整**："不是...而是..."、"如果说...那么..."等句式将逻辑关系直接摆在台面上
2. **表达空洞与模板化**："变革性的"、"培养"等宏大或抽象的词汇，缺乏具体细节和事实支撑
3. **正确的废话**：看似完美但信息密度低，听起来正确却无实际内容

### 三、三种文体的去AI味公式

| 文体类型 | 核心提示词公式 | 解决的关键痛点 |
|---------|--------------|---------------|
| 网文小说 | 角色人设×矛盾场景×感官细节 | 角色模板化、剧情平淡、缺乏沉浸感 |
| 写书稿 | 真实案例×具体数据×特色亮点 | 内容空洞说教、缺乏实证和作者视角 |
| 自媒体文章 | 目标人群×写作情绪×网络热梗 | 语气说教、互动性弱、无法引发共鸣 |

### 四、深度优化技巧

**网文小说**：
- 钩子前置：开篇用短冲突抓人眼球
- 口语化旁白：把"他表示同意"改为"他嗤笑一声：现在知道求我了？"

**写书稿**：
- 视角代入：让内容更具亲和力和真实性
- 结构化呈现：核心心法→实操步骤→案例参考

**自媒体文章**：
- 反套路公式：常规观点→但转折→意外细节
- 五感锚定：视觉、听觉、嗅觉等多种感官元素

## 关键洞察

1. **AI味本质**：逻辑外显、表达空洞、正确废话
2. **口语化是基础**：书面化表达天然缺乏活人感
3. **感官细节是灵魂**：视觉、听觉、嗅觉等感官元素增强沉浸感
4. **情绪共鸣是目标**：让读者感到"这是在跟我聊天"
