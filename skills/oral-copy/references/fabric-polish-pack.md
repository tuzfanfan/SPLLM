# Fabric Polish Pack

## 何时使用

- 用户已经有初稿，只想“更自然、更像人”
- 一篇长文写完后，需要顺手做摘要版、简报版、标签版
- 内容要同时进入公众号、wiki、归档系统

## 模块 1：Humanize Pass

目标：去掉 AI 味，不破坏作者声音。

重点检查：
- 过度平均的句长
- 套话式转折
- 过度圆润、过度稳妥的表达
- 没有“人”的视角和判断

允许动作：
- 调整节奏
- 改写套话
- 补一层自然过渡

禁止动作：
- 新增未经确认的事实
- 把原本锋利的判断改成无害废话

## 模块 2：Newsletter Entry Pass

目标：从长文派生 80 到 180 字的简报条目。

结构：
- 发生了什么
- 为什么值得看
- 读者能得到什么

适用：
- 周报
- 目录页
- 内容分发摘要

## 模块 3：Tag Pass

目标：给成稿补检索标签。

标签来源：
- 主题
- 对象
- 方法
- 场景
- 情绪或叙事类型

规则：
- 优先短标签
- 控制在 5 到 12 个
- 能直接用于 wiki、公众号或内容库检索
