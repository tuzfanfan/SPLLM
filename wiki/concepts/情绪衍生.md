# 情绪衍生

## 定义

> **情绪衍生（Emotion Derivation）** 指由6种基本情绪通过复合、变异和混合产生更复杂情绪的过程。衍生情绪具有更复杂的面部特征和行为表现，分析难度更高。

## 核心原理

### 衍生机制

| 机制 | 说明 | 示例 |
|------|------|------|
| **情绪复合** | 两种以上基本情绪同时出现 | 悲伤+愤怒 = 悲愤 |
| **情绪变异** | 基本情绪的强度或方向变化 | 微弱的厌恶 = 不屑 |
| **情绪混合** | 基本情绪的渐进式融合 | 惊讶+恐惧 = 震惊 |
| **情绪抑制** | 基本情绪被部分抑制后的表现 | 压抑的愤怒 = 冷笑 |

### 常见衍生情绪

| 衍生情绪 | 组成 | 面部特征 |
|------|------|------|
| **轻蔑** | 厌恶+愤怒 | 单侧嘴角上扬 |
| **嫉妒** | 愤怒+悲伤 | 眉头紧锁+嘴角下垂 |
| **愧疚** | 悲伤+恐惧 | 眼神回避+低头 |
| **羞耻** | 恐惧+厌恶 | 面红+回避目光 |
| **骄傲** | 快乐+惊讶 | 微笑+挺胸 |
| **愤慨** | 愤怒+厌恶 | 皱眉+上唇上抬 |

### 分析方法

```
观察面部特征 → 识别基本情绪成分 → 分析混合比例 → 推断衍生情绪
```
