# Reference Extractor

## 用途

把一段材料里的外部引用对象抽出来，为知识网络和后续深挖做准备。

## 输出结构

- `人物`
- `书籍`
- `论文`
- `组织`
- `案例`
- `概念`
- `值得建页的候选`

## 提取原则

- 只抽文本里明确出现或被清楚指涉的对象
- 如果只是模糊提到“某研究”“有本书说”，标注为待确认
- 同一对象反复出现时，合并并保留使用语境
- 尽量记录它为什么被提到，而不仅仅是名字

## 推荐输出模板

- `人物`
- `书籍`
- `论文`
- `组织`
- `案例`
- `概念`
- `值得建页的候选`
- `待确认引用`

## 邻近边界

- 如果用户要的是“抽观点”，不是本 skill，应该转向 `book2skill` 或写作类 skill
- 如果用户要的是“做知识图谱式梳理”，本 skill 负责先抽对象，不负责完整建网
- 如果只是论文参考文献格式化，也不优先用本 skill

## 规则

- 尽量按对象类型归类
- 如果同一个对象被重复提到，合并并记录上下文用途
- 不确定的对象标注“待确认”
- 如果能判断对象的重要程度，补一个“核心引用 / 次级引用”层级更好
