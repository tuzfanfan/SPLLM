# 匹配法

## 定义
> **匹配法（Matching Method）** 是实验心理学中控制额外变量的一种方法，指通过使实验组和对照组在被试特征或条件上相互匹配（对等），来控制额外变量对实验结果的干扰。

## 核心原理

匹配法的核心思路是：如果某个被试变量（如年龄、性别、智力水平等）可能影响因变量，则通过匹配使各实验组在该变量上具有相同或相似的分布，从而消除组间差异。

常见匹配方式：
- **被试匹配**：根据关键特征将相似的被试配对，分别分配到不同实验组
- **特征匹配**：使各组在某些关键特征上的平均值和分布相匹配
- **倾向分数匹配**：基于多个变量的综合倾向分数进行匹配

## 优缺点

| 优点 | 缺点 |
|------|------|
| 有效控制已知额外变量 | 难以同时匹配多个变量 |
| 提高组间可比性 | 匹配变量的选择依赖研究者判断 |
| 增强内部效度 | 可能限制可用被试数量 |
| | 无法控制未知额外变量 |

## 与其他控制方法的比较

- [[排除法]]：消除变量 vs 使变量对等
- [[恒定法]]：保持变量不变 vs 使各组在变量上对等
- 随机化法：概率平衡 vs 刻意匹配
- [[抵消平衡法]]：顺序抵消 vs 被试匹配
- [[统计控制法]]：事后统计控制 vs 事前匹配

## 应用场景
- 被试间设计的实验
- 需要控制个体差异的研究
- 准实验设计中的对照组选择
