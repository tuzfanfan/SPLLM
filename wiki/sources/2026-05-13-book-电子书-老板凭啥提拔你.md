# 老板凭啥提拔你

## 概述

本书从老板的视角分析了员工获得提拔的关键因素。

## 核心内容

| 晋升要素 | 内容 |
|------|------|
| 核心能力 | 专业能力过硬，能解决关键问题 |
| 领导潜力 | 展现管理能力和团队影响力 |
| 战略思维 | 站在更高角度思考问题 |
| 可靠性 | 让领导放心地把重要任务交给你 |

## 关键洞察

1. 晋升的本质是领导对你承担更大责任的信任
2. 能力是基础，但曝光度和人际关系同样重要
3. 要让领导看到你的价值
4. 持续提升自己的不可替代性
