# 拖延的四个成因

## 定义

> **拖延的四个成因** 是简-博克和莱诺拉-袁在《拖延心理学》中提出的拖延根源分类：恐惧失败、恐惧成功、完美主义和自我价值感低。这四个成因并非互斥，多数拖延者同时受到多个因素影响。

## 核心原理

### 四大成因

| 成因 | 核心信念 | 拖延机制 | 应对策略 |
|------|----------|----------|----------|
| **恐惧失败** | "如果我尽力了还是失败，说明我能力不行" | 通过拖延保护自尊 | 重新定义失败，关注过程 |
| **恐惧成功** | "成功会带来更多责任和期望" | 通过拖延避免成功 | 重新定义成功，设定边界 |
| [[完美主义]] | "如果做不到完美，不如不做" | 通过拖延避免不完美的结果 | 追求"足够好" |
| 自我价值感低 | "我的价值取决于我的表现" | 通过拖延避免暴露真实能力 | 分离价值与表现 |

### 成因之间的关系

```
自我价值感低 → 完美主义 → 恐惧失败/成功 → 拖延
```

| 关系 | 说明 |
|------|------|
| **自我价值感是基础** | 低自我价值感是其他成因的根源 |
| **完美主义是中介** | 完美主义连接自我价值感和恐惧 |
| **恐惧是表现** | 恐惧失败/成功是拖延的直接触发因素 |

### 识别方法

| 成因 | 典型想法 | 典型行为 |
|------|----------|----------|
| 恐惧失败 | "别人会发现我不够好" | 过度准备、最后一刻才提交 |
| 恐惧成功 | "做好了会有更多事等着我" | 在接近成功时自我破坏 |
| 完美主义 | "这个方案还不够完美" | 无限修改、无法完成 |
| 低价值感 | "我不配得到好的结果" | 自我设限、回避挑战 |

## 应对策略

| 成因 | 策略 |
|------|------|
| 恐惧失败 | 成长型思维、关注学习而非结果 |
| 恐惧成功 | 设定合理期望、学会拒绝 |
| 完美主义 | 追求"足够好"、设定时间限制 |
| 低价值感 | 无条件自我接纳、内在价值确认 |
