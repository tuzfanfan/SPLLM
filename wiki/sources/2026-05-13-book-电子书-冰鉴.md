# 冰鉴 - 来源摘要

## 概述

《冰鉴》为清代曾国藩所著，是一部系统论述识人鉴人的经典著作。"冰鉴"一词取"以冰为镜，明察秋毫，知面知心"之意。全书分为七篇——神骨、刚柔、容貌、情态、须眉、声音、气色，从七个维度深度分析鉴别人才的方法。蒋介石的相人之法得自曾国藩学说甚多，蒋纬国在三军大学任校长期间将此书指定为重要参考书。

## 核心内容

### 七篇结构

| 篇次 | 主题 | 核心内容 |
|------|------|----------|
| 第一篇 | 神骨 | 一身精神具乎两目，一身骨相具乎面部 |
| 第二篇 | 刚柔 | 刚柔总论、五行识人、论内刚柔 |
| 第三篇 | 容貌 | 姿容贵整、貌有四别、五官识人 |
| 第四篇 | 情态 | 情之恒态、情之时态 |
| 第五篇 | 须眉 | 眉相之辨、须相之辨 |
| 第六篇 | 声音 | 辨声之法、辨音之法 |
| 第七篇 | 气色 | 气色分类、文人之色、色忌青白 |

### 神骨总论（开篇）

> "语云：'脱谷为糠，其髓斯存'，神之谓也。'山骞不崩，唯石为镇'，骨之谓也。一身精神，具乎两目；一身骨相，具乎面部。他家兼论形骸，文人先观神骨。开门见山，此为第一。"

### 曾国藩识人四字诀

**广揽、慎用、勤教、严绳**

### 核心理念

- **重神兼之以形**：不只看外表，更看内在精神
- **重常而辨之以奇**：在常态中辨别特殊才能
- **重礼而导之以术**：以礼仪引导，以方法鉴别
- **就相论人，就神取人**：从静态中把握本质，从动态中识人

## 关键洞察

1. **"国家之强，以得人为强"**：曾国藩认为人才是国家强盛的根本
2. **"用人失误乃是最大的失误"**：在所有决策失误中，用人失误最为致命
3. **七维度识人体系**：从精神、骨骼、刚柔、容貌、情态、须眉、声音、气色全面考察
4. **身兼诸家智慧**：曾国藩融合儒、道、佛、法、阴阳等思想，形成独特的识人体系
