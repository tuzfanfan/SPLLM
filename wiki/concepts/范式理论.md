# 范式理论

## 定义

> **范式理论（Paradigm Theory）** 由托马斯·库恩提出，指科学共同体共享的模型、标准、方法和信念。科学通过"范式转换"实现革命性进步。

## 核心理论（库恩）

### 科学发展的五阶段

```
常规科学 → 反常积累 → 危机 → 科学革命 → 新范式 → 常规科学...
```

| 阶段 | 说明 | 特征 |
|------|------|------|
| **常规科学** | 在现有范式内进行解谜活动 | 积累知识、解决小问题 |
| **反常积累** | 出现范式无法解释的现象 | 越来越多反常 |
| **危机** | 反常太多，范式受到质疑 | 信任危机、寻求新理论 |
| **革命** | 新范式取代旧范式 | 激烈争论、范式竞争 |
| **范式转换** | 世界观彻底改变 | 不可通约性、格式塔转换 |

## 关键概念

### 1. 范式（Paradigm）

| 要素 | 说明 |
|------|------|
| **符号概括** | 公式、定律（如F=ma） |
| **模型** | 类比、图像（如太阳系模型） |
| **范例** | 标准解法、典型问题 |
| **价值观** | 简单性、一致性、广泛性 |

### 2. 不可通约性（Incommensurability）

**核心观点**：不同范式的支持者生活在不同的世界。

| 方面 | 说明 |
|------|------|
| **语言不通** | 术语含义在范式间变化 |
| **世界不同** | 看到的是不同的事实和关系 |
| **无法完全翻译** | 不能把旧范式完全翻译成新范式 |

### 3. 常规科学 vs 革命科学

| 维度 | 常规科学 | 革命科学 |
|------|------------|------------|
| **目标** | 解谜、积累知识 | 推翻旧范式、建立新范式 |
| **态度** | 保守、护教 | 激进、创新 |
| **方法** | 在范式内求解 | 寻找新范式 |
| **结果** | 渐进进步 | 革命性突破 |

## 经典案例

### 地心说 → 日心说

| 方面 | 地心说范式 | 日心说范式 |
|------|------------|------------|
| **中心** | 地球 | 太阳 |
| **行星轨道** | 本轮-均轮 | 椭圆轨道 |
| **观测事实** | 行星逆行 | 地球公转导致逆行 |
| **世界观** | 人类中心 | 太阳中心 |

### 牛顿力学 → 相对论

| 方面 | 牛顿范式 | 相对论范式 |
|------|----------|------------|
| **时空观** | 绝对时空 | 相对时空 |
| **引力** | 超距作用 | 时空弯曲 |
| **速度** | 无上限 | 光速极限 |
| **世界观** | 机械宇宙 | 动态时空 |

## 工具主义 vs 实在论

| 立场 | 对范式的看法 | 代表人物 |
|------|----------------|----------|
| **工具主义** | 范式是工具，不关心真假 | 实用主义者 |
| **实在论** | 范式是对真实世界的描述 | 大多数科学家 |
| **精致的实在论** | 范式是近似真理的 | 普特南 |

## 实践意义

### 科研指导
1. **识别范式**：了解自己所在的研究范式
2. **容忍反常**：反常可能预示新范式
3. **开放心态**：不盲目护教旧范式
4. **范式比较**：比较不同范式的优劣

### 商业应用
- **颠覆性创新**：新范式取代旧范式
- **商业模式**：从产品销售到订阅服务
- **技术革命**：从机械到电子到数字
