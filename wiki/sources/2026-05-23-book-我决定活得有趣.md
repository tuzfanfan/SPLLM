# 我决定活得有趣（原文件名为"思维简史"）

## 基本信息
- **作者**: 蔡澜
- **出版社**: 北京时代华文书局
- **出版年份**: 2017年4月
- **ISBN**: 978-7-5699-1443-6
- **页数**: 约276页

## 核心内容

本书是蔡澜的随笔集，以轻松幽默的笔调探讨人生哲学、生活态度、饮食文化、友情和人生感悟。金庸在序言中称蔡澜为"真正潇洒的人"。全书分为多个主题板块，涵盖生活态度、美食、茶酒、衣着品味、老友回忆等。

### 主要内容板块

1. **人生态度** - 活得有趣才能活得精彩、勇敢面对死亡、乐观与运气
2. **饮食文化** - 大吃大喝也是对生命的尊重、吃是一种学问、茶酒文化
3. **衣着品味** - 穿衣服要穿得快活逍遥、品味与个性
4. **老友回忆** - 金庸、黄霑、古龙、三毛、倪匡等
5. **人生感悟** - 专注与热爱、努力向前、过自己想过的生活

## 核心观点

1. **活得有趣是人生追求**: "平稳的人生，一定闷。我受不了闷，我决定活得有趣。"
2. **乐观带来好运**: "乐观的人，运气好。兴之所致地活，才算精彩。"
3. **尊重生命的方式**: "活着，大吃大喝也是对生命的一种尊重。"
4. **潇洒的真谛**: 率真潇洒而能以轻松活泼的心态对待人生中的失落或不愉快
