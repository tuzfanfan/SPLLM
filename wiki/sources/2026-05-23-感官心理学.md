# 感官心理学
| 属性 | 内容 |
|------|------|
| 作者 | 塞尔玛·洛贝尔（美国） |
| 译者 | 靳婷婷 |
| 出版信息 | 重庆出版社/果麦文化 |
| 类型 | 认知心理学/消费者行为 |
| 核心主题 | 身体感知（温度、材质、重量、声音、颜色、气味等）如何潜意识地影响人类行为和决策 |
## 核心观点
1. 我们自认为理性和自主的决策，实际上无时无刻不受温度、材质、重量、声音、味道、气味、颜色等身体感觉的潜意识影响。
2. 具身认知理论认为思维的运作离不开客观世界，感官知觉在潜意识和显意识思维之间搭建了桥梁。
3. 温暖的物理感受能让人变得更友善、慷慨、信任他人；寒冷则与孤独、排斥感紧密相连。
4. 触摸坚硬物体使人态度更强硬，柔软物体使人更妥协；粗糙材质使人判断更敌对，光滑材质使人更友善。
5. 重量感知影响判断——厚重的简历被认为更专业，重要决定让人感觉"沉重"。
6. 这些感官影响虽然转瞬即逝，但在商务谈判、考试、面试、约会等关键时刻可能产生重大影响。
