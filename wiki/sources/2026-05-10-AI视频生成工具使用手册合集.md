### 3. 提示词编写核心原则

#### 即梦提示词结构
```

```

**示例**：
> "镜头从侧面缓慢推进到正面中景。年轻女子坐在窗边，心情平静，轻轻端起咖啡杯，微笑着对镜头说话。旁边的男孩悄悄看着她，时不时转向镜头笑笑。"

#### 可灵提示词结构
```
提示词 = 主体 + 运动 + 背景 + 镜头语言 + 光影 + 氛围
```

> "镜头中景拍摄，背景虚化，氛围光照，一只大熊猫戴着黑框眼镜在咖啡厅看书，书本放在桌子上，桌子上还有一杯咖啡，冒着热气，旁边是咖啡厅的窗户，电影级调色"

## 洞察和启示

### 1. 技术趋势洞察

**多模态融合成为标配**
- Seedance 2.0 支持文本、图片、视频、音频四种模态的自由组合输入
- 用户可以通过"@素材名"的方式指定各素材的用途
- 标志着AI视频生成从"单模态"向"多模态"的范式转变

**音频驱动能力突破**
- OmniHuman 1.5 能够理解音频语义，让角色做出与音频内容和情绪相关的动作
- Seedance 1.5 Pro 支持自动生成环境音效和人声对白
- 口型同步技术达到影视级水准

**提示词工程专业化**
- 两家平台都提供了结构化的提示词编写指南
- 即梦强调"把编写提示词当成讲故事"，使用连贯自然语言
- 可灵提供"主体+运动+背景+镜头+光影+氛围"的公式化结构

### 2. 产品差异化洞察

**即梦：影视级创作工具**
- 定位：专业视频创作者、影视制作人员
- 核心优势：多模态参考、音频驱动、数字人、复杂动作控制
- 使用门槛：较高，需要学习提示词编写规范

**可灵：大众创作工具**
- 定位：普通用户、短视频创作者
- 核心优势：简单易用、生成速度快、基础功能完善
- 使用门槛：较低，提示词要求相对宽松

### 3. 应用场景洞察

| 场景 | 推荐工具 | 原因 |
|------|----------|------|
| **短视频创作** | 可灵 AI | 快速生成，操作简单 |
| **影视级制作** | 即梦 Seedance 2.0 | 多模态控制，质量更高 |
| **数字人/口播** | 即梦 OmniHuman 1.5 | 口型同步，动作自然 |
| **广告创意** | 即梦 Seedance 1.5 Pro | 环境音效，人声对白 |
| **老照片复活** | 可灵图生视频 | 操作简单，效果稳定 |
| **复杂剧情演绎** | 即梦 OmniHuman 1.5 | 角色走位，镜头运动 |

### 4. 使用建议

**提示词编写最佳实践**：
1. 使用简单词语和句子结构，避免过于复杂的语言
2. 画面内容尽可能简单，符合视频时长内可完成的动作
3. 运动符合物理规律，避免复杂物理运动（如球类弹跳）
4. 用"东方意境、中国、亚洲"等词更容易生成中国风内容
5. 分屏场景可使用"4个机位，春夏秋冬"等提示词

**注意事项**：
- 即梦暂不支持上传写实真人脸部素材（合规要求）
- 可灵对数字不敏感，"10个小狗"数量难保持一致
- 两家平台现阶段都难生成复杂物理运动
