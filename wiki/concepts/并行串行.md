# 并行串行

## 定义

> **并行串行（Parallel and Serial）** 指任务执行方式的两种基本模式。并行指同时执行多个任务，串行指按顺序逐个执行任务。理解任务的并行和串行关系是有效任务管理的基础。

## 核心原理

### 两种模式

| 模式 | 特征 | 适用场景 | 风险 |
|------|------|----------|------|
| **串行** | 一次只做一个任务 | 需要深度专注的任务 | 效率可能较低 |
| **并行** | 同时做多个任务 | 简单、不相关的任务 | 注意力分散、质量下降 |

### 任务分类

| 类型 | 特征 | 执行方式 |
|------|------|----------|
| **CPU密集型** | 需要深度思考和专注 | 串行 |
| **IO等待型** | 有等待时间 | 可并行 |
| **自动化型** | 已形成习惯的任务 | 可并行 |

### 常见误区

| 误区 | 真相 |
|------|------|
| "多任务处理更高效" | 人脑不擅长真正的多任务处理 |
| "我可以同时做两件需要专注的事" | 切换成本很高 |
| "并行就是同时做" | 实际上是快速切换 |

### 切换成本

```
任务A → 切换 → 任务B → 切换 → 任务A
每次切换都有时间和认知成本
```

| 成本类型 | 说明 |
|------|------|
| **时间成本** | 切换需要时间 |
| **认知成本** | 重新加载任务上下文 |
| **错误成本** | 切换中容易出错 |
| **疲劳成本** | 频繁切换增加心理疲劳 |
