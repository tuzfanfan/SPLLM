# 典型形态特征

## 定义

> **典型形态特征（Typical Morphological Feature）** 指某种特定情绪经常出现但不必然出现的面部特征。典型形态特征可以作为情绪判断的辅助线索，但不能作为确认依据。

## 核心原理

### 与必要形态特征的区别

| 特征类型 | 性质 | 缺失时的判断 |
|------|------|------|
| [[必要形态特征]] | 必然出现 | 缺失则该情绪未发生 |
| 典型形态特征 | 经常出现 | 缺失不能排除该情绪 |

### 典型形态特征示例

| 情绪 | 典型形态特征 | 说明 |
|------|------|------|
| **快乐** | 嘴角上扬 | 可能是礼貌性微笑 |
| **悲伤** | 泪水 | 严重悲伤时出现 |
| **愤怒** | 咬牙 | 愤怒的常见伴随行为 |
| **恐惧** | 面色苍白 | 恐惧的生理反应 |
| **惊讶** | 张嘴 | 惊讶的常见表现 |
| **厌恶** | 皱鼻 | 厌恶的常见面部表现 |

### 识别原则

```
观察到典型形态特征 → 情绪可能存在
未观察到典型形态特征 → 不能排除该情绪
```

## 应用价值

| 应用 | 说明 |
|------|------|
| **辅助判断** | 与必要形态特征结合提高判断准确性 |
| **情绪强度评估** | 典型特征越多，情绪可能越强烈 |
| **个体差异分析** | 不同个体的典型特征表现可能不同 |
