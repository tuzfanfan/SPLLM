# 异化

## 定义

> **异化（Alienation）** 是马克思提出的概念，指人失去主体性，变成商品的奴隶，与自己的本质疏远。

## 核心原理（马克思）

### 四种异化形式

| 类型 | 说明 | 现代表现 |
|------|------|----------|
| **产品异化** | 产品与劳动者分离 | 工人不拥有产品，只为工资工作 |
| **过程异化** | 劳动过程被控制 | 流水线、失去主动权 |
| **人的异化** | 人失去主体性 | 把自己当商品出售（市场取向） |
| **人际异化** | 人与人关系物化 | 社交变成交易，失去真诚 |

### 异化的根源

```
资本主义生产方式 → 劳动力成为商品 → 人失去主体性 → 异化
```

## 弗洛姆的阐释与发展

### 异化与人道主义伦理学

| 联系 | 说明 |
|------|------|
| **异化 = 非生产性** | 异化就是市场取向的生活 |
| **全面发展 = 生产性** | 马克思的"全面人" = 生产性性格 |
| **心理 + 社会** | 既需要心理革命，也需要社会革命 |

### 现代异化的加剧

| 表现 | 说明 |
|------|------|
| **消费异化** | 用消费定义自己 |
| **休闲异化** | 休闲变成被动消费 |
| **政治异化** | 公民变成被动选民 |
| **心理异化** | 失去内在价值感 |
