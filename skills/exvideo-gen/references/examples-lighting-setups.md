# Lighting Setup Examples

Use this file as the archive for practical lighting logic that can be reused inside canonical shot language.

## Example 01: Three-Point Base With Narrative Variants

### Status

- Type: source-method example
- Purpose: preserve a reusable lighting control model for dialogue, portrait, and dramatic scene work
- Default inheritance: partial
- Replace before reuse: equipment specifics, classroom-demo staging, and one-size-fits-all light positions

### What This Example Covers

- key, fill, and rim role separation
- fill-to-key ratio discipline
- hard versus soft rim selection
- side light and side-back light for tension
- rembrandt-light for structured dramatic portraiture
- practical-light motivation in narrative shots

### What To Preserve

- lighting should be described as a system with one dominant source
- fill repairs readability rather than flattening the image
- rim choice should respond to profile, hair, and stylization needs
- visible subject light should usually have an in-world explanation when realism matters

### What To Replace Before Reuse

- classroom-demo subject
- exact brand references
- any claim that one ratio or one light position is universal
