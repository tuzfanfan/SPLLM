# 音画一体

## 定义

> **音画一体** 是指在AI视频生成过程中，同步生成与画面内容、情绪、节奏相匹配的音频（包括背景音乐、音效、环境声等），实现视听内容的统一创作，避免后期单独添加音频的割裂感。

## 核心原理

### 传统流程 vs 音画一体流程

**传统流程（分离式）**：
```
文本提示词 → 视频生成 → 后期添加音频（音乐、音效、配音）
问题：音频与画面容易情绪不一致、节奏不匹配
```

**音画一体流程（统一式）**：
```
文本提示词（含音频描述） → AI模型同时生成视频+音频 → 音画同步的最终视频
优势：音频与画面情绪统一、节奏自然、沉浸感强
```

### 音频的组成要素

| 音频类型 | 说明 | 提示词示例 |
|----------|------|----------|
| **背景音乐** | 营造整体氛围 | "忧伤的钢琴曲，慢板，渐强" |
| **环境音效** | 增强场景真实感 | "雨滴声、远处雷声、脚步声" |
| **动作音效** | 配合画面动作 | "剑出鞘的声音、衣服摩擦声" |
| **人声配音** | 旁白或对话 | "低沉的男声旁白，语速缓慢" |
| **情绪音效** | 强化情绪表达 | "心跳声、呼吸声、紧张的音乐" |

- **纪录片**：环境音增强真实感和沉浸感

## 音画质量优化

### 音频描述的关键要素

| 要素 | 说明 | 示例 |
|------|------|------|
| **音频类型** | 明确需要什么音频 | "背景音乐"、"环境音效"、"人声配音" |
| **情绪风格** | 音频的情绪基调 | "忧伤"、"欢快"、"紧张"、"史诗" |
| **乐器/音色** | 具体的声音特征 | "钢琴"、"尺八"、"弦乐"、"电子合成器" |
| **节奏速度** | 快慢和节拍 | "慢板"、"快节奏"、"渐强"、"渐弱" |
| **音量层次** | 不同音频的音量关系 | "背景音乐轻声，脚步声清晰" |

### 常见错误

| 错误 | 原因 | 解决方案 |
|------|------|----------|
| **忽略音频** | 只描述画面不描述声音 | 补充【音频描述】部分 |
| **情绪冲突** | 画面欢快但音乐忧伤 | 确保音画情绪一致 |
| **过于复杂** | 描述太多音频层次 | 聚焦1-2个核心音频元素 |
| **音量失衡** | 背景音乐盖过环境音 | 明确标注各音频的音量层次 |
