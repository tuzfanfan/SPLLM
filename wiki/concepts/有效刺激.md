# 有效刺激

## 定义

> **有效刺激（Effective Stimulus）** 指能够真正触发情绪反应并产生可观察的[[微反应]]的刺激条件。并非所有刺激都能引发微反应，只有当刺激与个体的认知评估和情绪系统产生交互时，才会产生有效的微反应。

## 核心原理

### 有效刺激的条件

| 条件 | 说明 |
|------|------|
| **相关性** | 刺激内容与个体相关 |
| **新颖性** | 刺激包含意外或新异元素 |
| **强度** | 刺激达到足够的情绪激活阈值 |
| **时机** | 刺激出现在情绪敏感的时机 |

### 刺激-反应过程

```
刺激呈现 → 认知评估 → 情绪激活 → 微反应产生 → 意识抑制 → 反应泄漏
```

| 阶段 | 说明 |
|------|------|
| **认知评估** | 个体对刺激的意义进行快速评估 |
| **情绪激活** | 评估结果激活对应的情绪系统 |
| **微反应产生** | 情绪激活引发不自主的反应 |
| **意识抑制** | 意识试图控制情绪表达 |
| **反应泄漏** | 控制不完全导致微反应泄漏 |

### 无效刺激的特征

| 特征 | 说明 |
|------|------|
| **无关刺激** | 与个体无关的刺激 |
| **预期内刺激** | 完全在预期内的刺激 |
| **弱刺激** | 强度不足以激活情绪 |
| **习惯化刺激** | 反复出现已产生习惯化的刺激 |
