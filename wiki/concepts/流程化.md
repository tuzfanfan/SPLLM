# 流程化

## 定义

> **流程化（Systematization）** 指将重复性任务转化为标准化、可重复执行的流程。通过流程化，可以减少决策消耗、提高执行效率、降低错误率。

## 核心原理

### 流程化的价值

| 价值 | 说明 |
|------|------|
| **减少决策** | 不需要每次都重新思考怎么做 |
| **提高效率** | 标准化流程执行更快 |
| **降低错误** | 减少因疏忽导致的错误 |
| **可委托** | 流程化的任务更容易委托他人 |
| **可积累** | 流程可以持续优化和改进 |

### 流程化步骤

```
识别重复任务 → 分析步骤 → 标准化 → 文档化 → 执行 → 优化
```

| 步骤 | 说明 |
|------|------|
| **识别** | 找出重复执行的任务 |
| **分析** | 分解任务为具体步骤 |
| **标准化** | 确定最佳执行方式 |
| **文档化** | 写下流程文档或检查清单 |
| **执行** | 按流程执行 |
| **优化** | 根据执行结果持续优化 |

### 适用范围

| 适用 | 不适用 |
|------|------|
| 重复性任务 | 高度创造性任务 |
| 多步骤任务 | 一次性任务 |
| 可标准化任务 | 需要灵活应变的任务 |
| 团队协作任务 | 高度个人化的任务 |
