# 把话说到领导心坎里 - 来源摘要

## 概述

《把话说到领导心坎里——一分钟打动领导的说话术》由郑建斌著，是一本职场沟通技巧指南。全书围绕如何与领导有效沟通展开，涵盖面对面交流、电话沟通、邮件沟通、饭局沟通等多种场景，教导下属掌握"说领导愿意听的话"的艺术，从而获得领导信任和提拔。

## 核心内容

### 沟通工具运用

| 沟通方式 | 关键技巧 |
|----------|----------|
| **电话沟通** | 选择最佳时间、端正态度、注意礼仪、先问后说 |
| **邮件沟通** | 必须有主题、正确抄送、礼貌用语、签名落款、发送前检查 |
| **饭局沟通** | 清楚座次、谨慎点菜、察言观色、斟酒倒茶有学问 |

### 电话沟通五要点

1. 选择最佳通话时间（避开周一上午、周五下午）
2. 打电话不能太随便（坐姿端正影响声音）
3. 通话过程中要交流互动
4. 通话态度要端正（自报家门）
5. 注意通话结束后的礼仪（等领导先挂电话）

### 邮件沟通五要点

1. 邮件一定要有主题
2. 正确"抄送"（不要遗漏主管上级）
3. 礼貌用语不可省
4. 邮件一定要有自己的落款
5. 发送前应仔细检查

### 饭局四大禁忌

- 不要在饭局上畅所欲言提意见（领导可能在试探忠诚度）
- 入座要清楚自己的位置（直对门口为主宾位）
- 点菜要先问他人忌口
- 斟茶不可太满（茶满不敬）

## 关键洞察

1. **"伴君如伴虎"的现代版**：领导掌握着下属"生杀予夺"的大权，沟通不当可能影响职业前途
2. **说领导爱听的话 ≠ 拍马屁**：是用真诚、委婉、自信、低调的语言让领导更快喜欢你
3. **饭局不只是"饭"更是"局"**：领导的饭局是试探忠诚度和为人处世能力的场合
4. **沟通工具的选择**：聪明下属会在合适时间选择合适沟通工具
