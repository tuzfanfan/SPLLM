# 裸奔的钱

## 概述

本书以'裸奔的钱'为隐喻，探讨了在通货膨胀环境下货币贬值的现实和应对策略。

## 核心内容

| 主题 | 内容 |
|------|------|
| 通胀成因 | 货币超发是通货膨胀的根本原因 |
| 贬值现实 | 钱放在银行里实际在'裸奔'——不断贬值 |
| 投资对策 | 通过投资优质资产抵御通胀 |

## 关键洞察

1. 通货膨胀是隐形税，悄悄侵蚀每个人的财富
2. 现金是最危险的资产，因为它必然贬值
3. 投资不是选择，而是必须
4. 财富保值需要主动管理
