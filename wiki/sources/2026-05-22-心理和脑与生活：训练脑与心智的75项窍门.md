# 心理和脑与生活：训练脑与心智的75项窍门

| 属性 | 内容 |
|------|------|
| 作者 | Ron Hale-Evans |
| 出版信息 | 科学出版社 2007（O'Reilly出版） |
| 类型 | 实用科普/思维训练 |
| 核心主题 | 提供实用的思维训练方法，涵盖记忆、信息加工、创造性、数学、决策、沟通、洞察力和心理健康八个方面 |

## 核心观点

1. 本书是《心理和脑》（Mind Hacks）的"续集"，但侧重于实用方法而非理论探索，如同武术中自我防卫的技巧。
2. 记忆可以通过系统的方法大幅提升，包括行程记忆法、数字字形系统、多米尼克体系等记忆术。
3. 创造力可以通过结构化的方法培养，如强制关联、SCAMPER、创造力纸牌、类比思维等。
4. 心算能力可以通过特定训练获得，包括手指计算、整除检验、心算校验和等。
5. 决策可以借助博弈论工具优化，如优势策略、剔除劣策略、混合策略均衡等概念。
6. 情绪ABC模型和认知歪曲的识别是获得洞察力的基础，冥想和自我催眠是有效的心理工具。
7. 心理健康需要日常维护：良好的睡眠、营养、锻炼习惯是大脑高性能运转的基础。
