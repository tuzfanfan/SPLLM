# 智能多帧与一镜到底

## 定义

智能多帧是 [[即梦]] 平台推出的多图/多视频驱动视频生成能力。用户上传多张关键帧图像或视频素材，模型自动识别内容，结合提示词和设定的停留时长，生成空间连续、运镜流畅、节奏合理的一镜到底长视频。2.0版本在输入模态、编辑灵活性和时间精度上进行了全面升级。

## 版本对比

| 参数 | 智能多帧 1.0 | 智能多帧 2.0 |
|------|-------------|-------------|
| 支持帧数 | 最多10帧 | 最多20帧 |
| 帧间时长 | 1-6s | 0-8s（精确到0.5s） |
| 输入类型 | 仅图片 | 图片 + 视频（<=8s） |
| 分辨率 | 720p | 720p / 1080p |
| 最长视频 | 54s | 160s |
| 仅尾帧模式 | 不支持 | 支持 |
| 片段编辑 | 不支持 | 支持（锁定/解锁） |
| 0s硬切 | 不支持 | 支持 |

## 2.0新增功能

### 1. 视频素材输入
- 支持"视频+视频"或"视频+图片"的拼接创作
- 可对已有视频进行续写或转场生成
- 支持多素材混合与拼接

### 2. 仅尾帧模式
- 支持在"第一帧之前"直接写入提示词
- 模型以提示词为依据生成起始画面
- 打通"从无到有"的起点生成能力

### 3. 片段编辑
- 对不满意片段可选择"锁定该运镜"或"解锁重新生成"
- 锁定片段延续原内容，不额外消耗积分
- 支持加帧/减帧，使转场更自然或节奏更合适

### 4. 更自由的时间控制
- 精确到0.5s的时间颗粒度
- 支持0s硬切拼接

## 两类核心场景

### 空间运镜类（空间穿梭）

通过镜头的平移、推进、拉远、环绕、跟随等连续运镜方式，实现自然衔接与无缝穿梭。

**提示词结构**：
```
【镜头运动方式】+【下一张图片的空间元素】+【环境氛围】+（可选情绪/动作）
```

**基础运镜词汇**：
镜头拉近 / 镜头拉远 / 固定镜头 / 镜头水平向右平移 / 镜头水平向左平移 / 镜头垂直向上移动 / 镜头垂直向下移动 / 镜头俯视拍摄 / 镜头仰视拍摄 / 镜头旋转进入下一场景 / 镜头高速穿越 / 镜头360度环绕 / 镜头俯冲 / 镜头拔升 / 镜头穿梭 / 镜头贴地飞行

**注意事项**：
- 必须有镜头动作：用"镜头+动作"开头，不要只描述场景
- 动作与秒数匹配：大幅运动4-6s，小幅运动1-3s
- 一条提示词1-2种镜头动作即可
- 氛围词适量：简洁直观，不堆砌形容词

**示例**：
```
镜头缓慢推进，穿过雾气笼罩的走廊，环绕一圈后向上抬升至屋顶俯瞰城市
```

### 角色动态类（复杂主体动态）

以角色的连续动作为核心，通过多帧展现动作变化，强调主体明确、动作连贯、与环境互动。

**提示词结构**：
```
【角色身份/外观】+【关键动作】+【环境元素】+【镜头运动方式】+（可选情绪/氛围）
```

**注意事项**：
- 动作连贯：相邻帧动作应有延续性（奔跑-跃起-落地）
- 与环境互动：让角色动作与背景元素产生关联
- 动作和镜头匹配：快节奏配快速运镜，慢节奏配缓慢推进
- 主体清晰：确保角色是画面视觉中心

**示例**：
```
身披黑袍的剑客猛然拔剑，镜头低角度跟随疾冲穿过昏暗长廊
```

## 其他场景类型

### 产品展示类
**结构**：【镜头运动方式】+【产品部位/特征】+【展示细节/功能】+【环境氛围/质感】

### 节奏驱动类（卡点视频）
**结构**：【镜头运动方式/画面变化方式】+【变化元素/主体动作】+【节奏感修饰词】+【环境氛围】

### 叙事类
将空间运镜、角色动态、节奏变化等多种镜头语言融合，以长镜头推动情节发展。
**结构**：【镜头运动方式】+【当前画面内容】+【过渡方式/动作】+【下一画面内容】+【氛围/情绪】

### 循环动画
首帧和尾帧使用相同图片，可生成循环壁纸。

## 提示词编写关键要素

1. **明确镜头运动方式**：镜头运动是智能多帧生成的基础
2. **简洁且有针对性的描述**：重点描述关键元素，避免过度细化
3. **注重情感和动作的衔接**：精确描写动作与情感，确保视觉连贯
4. **根据场景类型调整**：不同场景有不同的提示词要求
5. **不建议不写提示词**：除非图片信息连续足够，否则一定要写精准提示词
