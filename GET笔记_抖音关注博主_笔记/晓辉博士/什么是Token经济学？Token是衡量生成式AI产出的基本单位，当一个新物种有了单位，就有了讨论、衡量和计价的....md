## 摘要

📝 **Token基本定义**
- Token是生成式AI进行下一个词预测（next token prediction）的基本单位
- 国家定调中文名称为"词源"
- 通常对应一到两个汉字

🏗️ **Token经济学五层框架**
- 由黄仁勋在英伟达大会提出，涵盖能源、芯片、基础设施、模型、应用五层
- 底层为"AI工厂"（生产智力），中间层为大模型（承载智力），顶层为应用（消费智力）
- Token作为衡量标准，类似电力的千瓦时、石油的桶，为交易提供计量基础

💰 **Token成本差异**
- 模型参数规模越大，生成Token消耗的能量越大
- 慢思考模型因思维链长，消耗更多Token
- 不同模型价格差异显著：Claude 3 Opus（Miso）为最贵模型，中国模型因工程优化更便宜且在开源市场有竞争力
- Token成本呈每年5-10倍下降趋势，符合杰文斯悖论（成本下降导致使用量激增）

💎 **Token价值特性**
- 可编程属性使其在不同场景（代码编写、客服、法律顾问等）产生不同价值
- 5%的Token产生80%的价值，关键场景（如AI for Science、编程、短剧创作）价值更高
- 计费方式多样：按量计费（API模式）、包月服务（如OpenAI）、按效果付费（如AI客服解决问题才收费）

📈 **Token增长趋势**
- Agent使用AI消耗Token远高于人类对话
- 英伟达为工程师提供相当于工资一半的Token配额，推动Agent小队协作
- 全球算力紧张，存储和芯片成为瓶颈，三星等企业因需求暴涨获利

🌐 **Token出海与挑战**
- 中国模型通过海外数据中心出海，本质是算法出海而非电力出海
- 存在数据安全、跨境统计、劳动力替代等新挑战
- 腾讯研究院将持续关注相关动态
