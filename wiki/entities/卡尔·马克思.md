## 核心理论

### 1. 异化理论

| 类型 | 说明 |
|------|------|
| **产品异化** | 产品与劳动者分离 |
| **过程异化** | 劳动过程被控制 |
| **人的异化** | 人失去主体性 |
| **人际异化** | 人与人关系物化 |

### 2. 人的本质

**核心命题**：人的本质不是抽象的，而是**一切社会关系的总和**。

| 维度 | 说明 |
|------|------|
| **社会性** | 人在社会中生产自己 |
| **历史性** | 人是历史的产物 |
| **实践性** | 人是自己实践活动的产物 |

### 3. 全面发展

**共产主义 = 人的全面解放**：

| 要素 | 说明 |
|------|------|
| **潜能实现** | 每个人都能充分发挥才能 |
| **消除分工** | 不再被固定职业限制 |
| **自由时间** | 从必要劳动中解放 |

- 创立马克思主义，影响全球政治运动
