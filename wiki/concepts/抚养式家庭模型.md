# 抚养式家庭模型

## 定义

> **抚养式家庭模型（Nurturant Parent Model）** 是乔治·莱考夫提出的道德政治框架之一，认为世界可以变得更好，孩子天生善良，通过共情、责任和开放的沟通帮助孩子成长。

## 核心特征

| 维度 | 内容 |
|------|------|
| **世界观** | 世界可以变得更好 |
| **人性观** | 孩子天生善良，能变得更好 |
| **养育方式** | 共情+责任，理解与呵护 |
| **道德核心** | 共情、公平、自由、开放的沟通 |
| **财富观** | 公平分配，机会平等 |
| **政府职能** | 保护公民，监管企业，社会福利 |
| **外交政策** | 合作、外交、多边主义 |

## 道德体系

### 核心道德
1. **共情（Empathy）**：感受他人的感受
2. **公平（Fairness）**：追求机会平等和公正
3. **自由（Freedom）**：开放的沟通和选择
4. **责任（Responsibility）**：对社区和社会的责任

### 衍生道德
- **社会福利**：帮助需要帮助的人
- **环境保护**：为后代保护地球
- **多元包容**：尊重不同文化和生活方式

## 政治表现（进步派）

### 经济政策
- **累进税制**：富人多交税，实现公平
- **社会福利**：保障弱势群体
- **政府监管**：防止企业滥用权力

### 社会政策
- **支持选择权**：女性对自己身体的决定权
- **支持同性婚姻**：平等对待所有公民
- **环境保护**：积极应对气候变化

### 外交政策
- **多边主义**：通过国际合作解决问题
- **外交优先**：对话而非对抗
- **外援项目**：帮助发展中国家

## 进步派的三个迷思（需要打破）

| 迷思 | 内容 | 为什么错误 |
|------|------|----------|
| **真相必叫我们自由** | 只要告诉人们事实，他们会得出正确结论 | 人通过框架思考，事实不符合框架就会被弹开 |
| **人总是从自身利益思考** | 选民会根据利益投票 | 人根据身份认同和价值观投票，不是根据利益 |
| **政治竞选就是营销** | 候选人是产品，民意调查决定立场 | 必须激活支持者的框架，而非向右移 |
