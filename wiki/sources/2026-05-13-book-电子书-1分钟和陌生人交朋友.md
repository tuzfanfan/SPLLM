# 1分钟和陌生人交朋友

**作者**: 宇琦

## 概述

一本关于快速建立人际关系的实用社交指南。全书围绕'1分钟和陌生人交朋友'的核心理念，提供了在各种社交场合中快速打破僵局、建立联系的具体方法和技巧。内容涵盖自我介绍、话题选择、肢体语言、后续跟进等多个环节。

## 核心内容

| 主题 | 内容 |
|------|------|
| 破冰技巧 | 在各种场合快速打开话题的方法 |
| 自我介绍 | 简洁有力的自我介绍技巧 |
| 话题选择 | 找到对方感兴趣的话题，保持对话流畅 |
| 肢体语言 | 通过肢体语言传递友好和自信 |
| 后续跟进 | 将初次见面转化为长期关系的方法 |

## 关键洞察

- 社交心理学基础
- 沟通技巧与话术方法
- 社交恐惧的认知行为疗法
- 人际吸引力法则
- 社交网络的建立与维护
