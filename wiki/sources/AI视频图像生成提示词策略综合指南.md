## 一、核心方法论对比

### 1.1 两大平台定位差异

| 维度 | 即梦（字节跳动） | 可灵（快手） |
|------|------------------|--------------|
| **产品定位** | 影视级专业创作工具 | 大众AI创作工具 |
| **目标用户** | 专业视频创作者、影视制作人员 | 普通用户、短视频创作者 |
| **提示词风格** | "讲故事"式自然语言 | 公式化结构化描述 |
| **核心优势** | 多模态融合、音频驱动、数字人 | 简单易用、生成速度快 |
| **使用门槛** | 较高，需要学习规范 | 较低，上手即用 |

### 1.2 提示词哲学差异

**即梦：把编写提示词当成讲故事**
- 强调连贯的自然语言叙述
- 注重镜头语言、情绪表达、动作编排
- 适合复杂场景和精细控制

**可灵：公式化的结构化描述**
- 提供明确的提示词公式
- 强调主体、运动、背景、镜头、光影、氛围六大要素
- 适合快速生成和标准化创作

## 二、提示词基础结构

### 2.1 即梦提示词结构（视频/数字人）

```
提示词 = 镜头运动 + 说话角色情绪 + 说话状态 + 具体动作 + 背景事件/其他角色动作
```

**完整示例**：
> "镜头从侧面缓慢推进到正面中景。年轻女子坐在窗边，心情平静，轻轻端起咖啡杯，微笑着对镜头说话。旁边的男孩悄悄看着她，时不时转向镜头笑笑。背景中灯光柔和地闪烁。"

**结构拆解**：
| 要素 | 示例 | 说明 |
|------|------|------|
| 镜头运动 | 镜头从侧面缓慢推进到正面中景 | 指定镜头起始和结束状态 |
| 角色情绪 | 心情平静 | 描述角色内心状态 |
| 说话状态 | 微笑着 | 描述说话时的表情 |
| 具体动作 | 轻轻端起咖啡杯 | 详细描述动作细节 |
| 背景事件 | 旁边的男孩悄悄看着她 | 描述场景中其他元素 |

### 2.2 可灵提示词结构（视频/图像）

```
提示词 = 主体 + 运动 + 背景 + 镜头语言 + 光影 + 氛围
```

**完整示例**：
> "镜头中景拍摄，背景虚化，氛围光照，一只大熊猫戴着黑框眼镜在咖啡厅看书，书本放在桌子上，桌子上还有一杯咖啡，冒着热气，旁边是咖啡厅的窗户，电影级调色"

**结构拆解**：
| 要素 | 示例 | 说明 |
|------|------|------|
| 主体 | 一只大熊猫戴着黑框眼镜 | 主要人物/动物/物体 |
| 运动 | 在咖啡厅看书 | 主体的运动状态 |
| 背景 | 咖啡厅的窗户 | 主体所处的环境 |
| 镜头语言 | 镜头中景拍摄，背景虚化 | 镜头应用和切换 |
| 光影 | 氛围光照 | 光线和阴影效果 |
| 氛围 | 电影级调色 | 视频画面的整体氛围 |

### 2.3 图像生成通用结构

**即梦图片3.0/4.0/4.5**：
```
提示词 = 用途/类型 + 主体描述 + 行为/状态 + 环境/背景 + 美学风格 + 技术参数
```

**可灵可图2.1**：
```
提示词 = 主体（细节描述）+ 运动/动作 + 场景环境 + 画风/质感 + 光影/色调
```

## 三、图像生成提示词策略

### 3.1 即梦图片模型核心要点

#### 核心要点一：用简单直接的语言表达
- 短提示词也能发挥惊艳效果
- 长提示词不一定代表好的生图效果
- 自己输入的提示词可能比AI生成的更有效

**示例**：
- 复古风格的公路电影海报
- 水墨笔触风格的宠物电影海报
- 炸鸡美食海报

#### 核心要点二：连贯自然语言 + 短词语描述
- 用连贯的自然语言描述画面内容（主体 + 行为 + 环境等）
- 用短词语描述画面美学（风格、色彩、光影、构图等）

#### 核心要点三：文字内容用引号标注
- 把想要生成的文字内容插入""引号中
- 可以提升文字准确率

**示例**：
> 广告海报设计，卡通Q版风格，文字为"呼伦贝尔肉业集团春季推广"，位于左下角，还有日期和地点信息，字体为小号。

### 3.2 可灵可图模型提示词策略

#### 基础版 vs 精细版对比

**基础版**：
> 一个亚洲女生奔跑在傍晚的住宅区街道。

**增加细节**：
> 一个穿着校服的亚洲女生奔跑在傍晚的住宅区街道，右手提着便利店塑料袋，书包侧斜着，路边樱花盛开。

**增加美学**：
> 一个穿着校服的亚洲女生奔跑在傍晚的住宅区街道，右手提着便利店塑料袋，露出草莓牛奶包装，书包侧斜着，路边樱花盛开，日系青春电影质感，真人风格照片。

#### 文生图驯服经验

1. **多次尝试**：生图模型效果像抽卡，一次不成功可多次调整prompt
2. **电影质感**：强调"电影质感"、"电影氛围"等词
3. **重要词前置**：重要的词放最前面，响应不佳的词可反复强调
4. **使用场景**：写出图片使用场景（公众号配图、海报、背景、贴纸、Logo、纪实摄影）
5. **字数控制**：一般几十字~300字为宜，简洁语言也能出惊艳效果

## 四、视频生成提示词策略

### 4.1 即梦视频生成（Seedance）

#### 提示词编写原则

**原则1：用"讲故事"的方式编写**
- 把编写提示词当成讲故事
- 使用连贯的自然语言描述画面
- 包含时间顺序（先...然后...最后...）

**原则2：详细描述动作和情绪**
- 具体动作：轻轻端起、快步追上、转身看向
- 情绪状态：心情平静、神情惊愕、不屑一顾
- 微表情：翻白眼、眉头紧皱、眯眼微笑

**原则3：精确控制镜头语言**
- 镜头运动：推进、拉远、环绕、跟随
- 镜头速度：缓慢、快速、迅速
- 镜头焦点：聚焦到、对焦到、移焦

#### 多模态输入策略（Seedance 2.0）

**@素材引用格式**：
```
@图片1 @图片2 @视频1 中的内容...
```

**多模态组合方式**：
| 组合类型 | 示例 |
|---------|------|
| 图片+文本 | @图片1 中的角色在森林里奔跑 |
| 视频+文本 | @视频1 的节奏，@图片1 的角色换装 |
| 音频+文本 | 背景音乐为@音频1 的风格 |
| 多图组合 | @图片1 @图片2 @图片3 根据@视频1 的节奏卡点 |

#### 复杂动作编排示例

**连续动作控制**：
> "男人先向前走，然后停下脚步双手叉腰说话。随后他转身看向身后的爆炸，露出了后背，他后背的衣服已被炸烂"

**多角色互动**：
> "跟随镜头，男孩先向前快步追上女孩，然后开始对女孩说话。女孩用不耐烦的神情，停下脚步转身看向男孩。"

**情绪层次控制**：
> "男人先是神情淡定，对着镜头说话。随后突然变得紧张惊慌，眉头紧皱"

### 4.2 可灵视频生成提示词策略

#### 文生视频公式

```
提示词 = 主体 + 运动 + 背景 + 镜头语言 + 光影 + 氛围
```

**要素详解**：

| 要素 | 撰写建议 | 示例 |
|------|----------|------|
| **主体** | 加入细节描写：外貌、动作、表情；形状、颜色；姿态、花色 | 一位20岁戴眼镜的男生；一只灰色的、体型健硕的狼 |
| **运动** | 增加动作细节描写 | 举起手臂；向前奔跑；蹦蹦跳跳；缓慢漂浮 |
| **背景** | 背景信息详细描述 | 日落时的夕阳洒进教室；水流湍急的瀑布 |
| **镜头语言** | 镜头应用和切换 | 镜头中景拍摄，背景虚化；跟随镜头 |
| **光影** | 光线和阴影效果 | 氛围光照；晨光；暖色调 |
| **氛围** | 视频画面氛围 | 电影级调色；温馨美好；紧张刺激 |

#### 图生视频策略

**单主体提示词公式**：
```
提示词 = 单主体（主体细节描述）+ 主体运动 + 背景 + 其他信息（服饰、画风、运镜等）
```

**多主体提示词公式**：
```
提示词 = 多主体（每个主体的细节描述）+ 主体间互动 + 背景 + 其他信息
```

#### 运镜控制

可灵支持的运镜类型：

| 运镜类型 | 说明 |
|---------|------|
| 推进/拉远 | 镜头向主体推进或远离主体 |
| 垂直摇镜 | 镜头在垂直方向上运动 |
| 旋转运镜 | 镜头围绕主体旋转拍摄 |
| 水平摇镜 | 镜头在水平方向上运动 |
| 大师运镜：左旋推进 | 组合运镜，向左旋转同时推进 |
| 大师运镜：右旋推进 | 组合运镜，向右旋转同时推进 |
| 大师运镜：推进上移 | 组合运镜，推进同时向上移动 |
| 大师运镜：下移拉远 | 组合运镜，向下移动同时拉远 |

#### 首尾帧策略

**使用建议**：
- 尽量选择两张相同主题且近似的图，模型容易在5s内流畅衔接
- 如果两张图片相差较大，可能会触发镜头切换

**适用场景**：
- 车辆行驶过渡（不同角度的同一辆车）
- 城市风光过渡（同一地点不同时间/角度）
- 互动过渡（从人手特写到人与动物互动）

## 五、数字人/口型同步提示词策略

### 5.1 OmniHuman 1.5 提示词结构

```
提示词 = 镜头运动 + 角色动作顺序 + 说话/唱歌标记 + 情绪变化 + 环境互动
```

**完整示例**：
> "镜头从侧面缓慢推进到正面中景。年轻女子坐在窗边，心情平静，轻轻端起咖啡杯，微笑着对镜头说话。旁边的男孩悄悄看着她，时不时转向镜头笑笑。"

### 5.2 动作编排技巧

#### 连续动作及走位控制

通过"先"、"然后"等词描述动作顺序：

> "男人先向前走，然后停下脚步双手叉腰说话。随后他转身看向身后的爆炸"

> "镜头跟随，男人转过身看向镜头向前走，陶醉地唱歌。他先用双手摸领口，然后双手张开抬起头"

#### 先说话再做动作 / 先做动作再说话

**先动作后说话**：
> "男人迅速摘下口中的香烟，然后对着镜头开口说话"

**先说话后动作**：
> "镜头推进，女人对着镜头说话，说完后快速转过身向身后跑去"

#### 多角色动作控制

着重描述角色间的互动方式：

> "跟随镜头，男孩先向前快步追上女孩，然后开始对女孩说话。女孩用不耐烦的神情，停下脚步转身看向男孩。"

### 5.3 镜头运动控制

**技巧**：通过描述运镜结束时的镜头状态，精准控制运镜快慢与结束位置

> "镜头向右环绕，聚焦到男人的脸正面。男人快速摘下眼镜，面朝正前方说话。"

> "镜头向右环绕，角色正对前方说话。随后镜头再快速推进，聚焦到角色正面正脸。"

**提示**：使用"迅速"这样的词汇，能提高运镜响应率

### 5.4 情绪层次与微表情控制

**情绪变化描述**：
> "男人先是神情淡定，对着镜头说话。随后突然变得紧张惊慌，眉头紧皱"

**微表情控制**：
> "女人先是不屑地翻了个白眼，用轻视的神情说话。随后一只手用食指扶了扶下巴。最后用高傲的情绪，用手把玩桌上的盒子。"

### 5.5 特效与无中生有

参考图里没有出现的元素，可以用提示词添加：

> "父子俩神情惊愕地望向镜头方向，儿子说话。随后镜头开始缓缓推进，空气中出现扭曲波动，父子如尘烟般被抽入画面深处，瞬间消失。"

> "小鸡戴上墨镜，手持双枪，邪恶地说话"

### 5.6 镜头焦点控制

对于前后景分别存在不同角色的场景：

> "记者对着镜头报道，同时身后的国王突然倒地，镜头对焦到记者身后倒地的国王。记者不可思议地快速转过头看着身后说话"

> "女人回头看着身后的士兵说话，同时镜头对焦到身后士兵身上。然后女人回头对着镜头继续说"

## 六、高级技巧与进阶策略

### 6.1 智能多帧策略

#### 多帧提示词编写原则

**时间轴式描述**：
```
[时间点1]：画面状态1，动作1
[时间点2]：画面状态2，动作2
[时间点3]：画面状态3，动作3
```

**示例**：
> "0-5秒：主体靠近水盆好奇试探（情绪：好奇、放松）。6-11秒：洗澡时涂抹沐浴露，被温水冲洗（情绪：惬意、享受），穿插眯眼、蹭洗澡工具的特写。12-15秒：洗完澡后甩毛、舔毛的舒适画面（情绪：满足、慵懒）。"

#### 分镜式描述

> "8秒智性博弈式战斗动漫片段，贴合复仇主题。0-3秒：分镜图1中女主转身坐下，转镜头，女主下了一步棋子，并说'你输了'。3-4秒：快速摇镜头，转向对面男人面部特写，男人咬牙切齿。4-6秒：切镜头，俯拍，女人下了一步棋，对面的人们惊叹。6-8秒：镜头迅速向下摇，画面黑屏转场，后画面渐亮，女人看着窗外月色静静地说'我们走着瞧'。"

### 6.2 音乐卡点策略

**节奏控制**：
> "@图片1@图片2@图片3@图片4@图片5@图片6@图片7中的图片根据@视频中的画面关键帧的位置和整体节奏进行卡点，画面中的人物更有动感，整体画面风格更梦幻"

**转场配合**：
> "@图片1@图片2@图片3@图片4@图片5@图片6的风光场景图，参考@视频中的画面节奏，转场间画面风格及音乐节奏进行卡点"

### 6.3 参考图使用策略

#### 可灵多图参考

**多主体示例**：
| 参考图组合 | 文字描述 |
|-----------|----------|
| 穿白裙的女性 + 草地里的独角兽 + 森林场景 | 一个女生在森林里面骑着独角兽，电影写实风格 |
| 戴白帽子的卡通小人 + 棕色小熊 | 带着白色帽子的卡通小人，和棕色小熊，并排坐在一起向镜头打招呼 |
| 红衣古风女生 + 赛博朋克风街道 | 一个身穿中国古代红色服饰的女生，在一个未来世界的街道上行走 |

#### 即梦多模态参考

**角色一致性保持**：
> "将视频@视频1中的小猫作为主体1，将@视频1中给小猫洗澡的主人作为主体2。主体2给主体1洗澡，主体1对洗澡从适应到主动喜欢..."

**换装与场景变换**：
> "海报中的女生在不停的换装，服装参考@图片1@图片2的样式，手中提着@图片3的包，视频节奏参考@视频"

### 6.4 风格转绘策略

**可灵风格转绘**：
- 上传图片，prompt框输入想要变成的风格
- 示例："转换为复古美少女风格"、"变为3D卡通风"

**即梦风格控制**：
- 在提示词中明确指定风格关键词
- 示例："日系青春电影质感"、"皮克斯动画风格"、"中式婚礼伴奏"

## 七、平台专属特性

### 7.1 即梦专属能力

#### 环境音效生成

**能力说明**：自动生成与画面氛围匹配的环境音效

**示例**：
> "背景音为暴雨声以及雷电声伴奏为较为紧张的音乐"
> "背景音为若隐若现的汽车驶过的声音"
> "耳麦式收音效果，沉浸式声音；将物体（类似太阳）切开露出岩浆（禁止背景音乐）"

#### 人声对白与口型同步

**能力说明**：生成与画面匹配的口型同步人声对白

**示例**：
> "图中远处的人物以愤怒且夹杂着雨声的声音说道：'跑啊，你怎么不跑了？'"
> "女子一脸幸福的说到：'The sycamore tree on the street corner had fallen leaves...'"

#### 音乐配乐生成

**能力说明**：自动为视频生成背景配乐，风格与画面氛围匹配

**示例**：
> "孤独感，萧瑟感的音乐背景，镜头跟随主体，远处有车驶来"
> "背景音乐为圣诞主题，欢快感；圣诞老人坐着车架向天空驶去"
> "背景音乐为：中式婚礼伴奏，二者结婚时的场景，画面喜庆"

### 7.2 可灵专属能力

#### 运动笔刷

**功能说明**：通过涂抹指定区域并添加运动轨迹，控制特定主体的运动

**使用建议**：
- 单个动态笔刷只选中类别一致的单个物体
- 单个动态笔刷只画一个相互联通的区域
- 静态笔刷可以选中多个彼此不联通的区域

**示例**：
- 帆船在海上缓慢行驶，大海泛起波浪
- 小草被风吹动，两只狗向不同方向转头看向远方
- 苹果下落，掉进水里

#### 对口型

**功能说明**：上传配音/歌唱文件，让视频人物口型和音频完美同步

**使用方法**：
1. 使用可灵AI生成包含完整人物面容的视频
2. 点击预览视频下的「对口型」
3. 上传本地配音/歌唱文件，或通过文本朗读功能在线生成配音
4. 可灵AI将自动匹配人物口型与音频

## 八、常见问题与解决方案

### 8.1 提示词编写常见问题

| 问题 | 解决方案 |
|------|----------|
| 生成效果不稳定 | 多次调整prompt，抽多张图片；重要词放最前面，反复强调 |
| 动作不自然 | 使用"先...然后..."描述动作顺序；避免复杂物理运动（如球类弹跳） |
| 角色一致性差 | 使用参考图功能；详细描述角色外貌特征 |
| 文字生成错误 | 文字内容用引号标注；指定字体风格和位置 |
| 风格不统一 | 确保所有参考图风格一致；提示词中明确指定画风 |

### 8.2 平台限制与规避

| 限制 | 说明 | 规避方法 |
|------|------|----------|
| 写实真人脸部 | 即梦暂不支持上传写实真人脸部素材 | 使用动漫/卡通风格；使用AI模特生成 |
| 数字敏感度 | 可灵对数字不敏感，"10个小狗"数量难保持一致 | 避免精确数字；使用"一群"、"多个"等模糊描述 |
| 复杂物理运动 | 两家平台都难生成复杂物理运动 | 避免球类弹跳、液体飞溅等复杂物理效果 |
| 视频时长 | 即梦最长15s，可灵最长10s | 使用视频延长功能；分段生成后剪辑 |
| 唱歌控制 | 暂不支持唱歌内容的完整控制 | 使用对口型功能后期配音 |

### 8.3 最佳实践总结

1. **从简单开始**：先用简洁的提示词测试，再逐步添加细节
2. **多次迭代**：生图/生视频像抽卡，多次尝试找到最佳效果
3. **参考示例**：学习官方示例的提示词写法
4. **善用参考图**：上传参考图可以大幅提升可控性
5. **明确指定**：重要的元素要在提示词中明确指定，不要假设AI会理解
6. **避免负面词**：与其描述不要什么，不如明确描述要什么
7. **使用专业术语**：镜头语言、艺术风格等使用专业术语效果更佳
