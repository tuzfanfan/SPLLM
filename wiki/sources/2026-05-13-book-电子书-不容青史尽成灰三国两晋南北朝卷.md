# 不容青史尽成灰（三国两晋南北朝卷）- 来源摘要

## 概述

《不容青史尽成灰——三国两晋南北朝卷》由张嵚著，是一部以人物为中心的历史普及读物。全书通过一个个被正史忽略或被演义歪曲的历史人物，重新审视三国两晋南北朝时期的历史真相。第一章以"三分天下自他终"的西晋名将王濬为核心，颠覆了"三国晚期人才凋零"的刻板印象。

## 核心内容

### 王濬：从"富二代"到统一功臣

| 阶段 | 事迹 |
|------|------|
| 少年 | 世家子弟，放荡不羁，20岁后"浪子回头" |
| 河东从事 | 铁面无私，巡查时5个县令闻风而逃，1人砍翻5个歹徒 |
| 巴郡太守 | "为政以宽"，出台中国最早的"奖励生育"政策，人口增3倍，土地增4倍 |
| 益州刺史 | 取缔邪教，兴办教育，"精神文明建设" |
| 大司农 | 受羊祜举荐，主持建造"楼船" |
| 灭吴之战 | 公元280年率水师顺江而下，完成统一大业 |

### 三国晚期的重新认识

- **战争规模远超前中期**：曹魏灭蜀、西晋灭吴的规模远超赤壁之战
- **经济恢复**：三足鼎立让各国获得休养生息时间，人口经济迅速恢复
- **人才不输前代**：王濬、羊祜、杜预等人的能力毫不逊色于前期英雄

### 王濬的造舰计划

- 每艘楼船长120步，可载士兵2000人，堪称"当时世界的航空母舰"
- 用库存绸缎与土人交换木材，节约劳动力
- 造船与水师训练同步进行，统筹方法先进

## 关键洞察

1. **"时无英雄"是误解**：三国晚期不是人才凋零，而是演义的偏见
2. **王濬的治理智慧**：对百姓"宽"，对贪腐"严"，宽严并济
3. **"奖励生育"政策的历史意义**：巴郡因战乱出现大规模弃婴，王濬的政策挽救了无数生命
4. **民谣"阿童复阿童"**：王濬小名"阿童"，民谣预言了他统一中国的历史使命
