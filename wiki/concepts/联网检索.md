# 联网检索

## 定义

> **联网检索（Online Search / Internet Retrieval）** 是指AI图像生成系统在生成内容时，能够实时访问互联网上的知识库，获取真实世界的信息（如地标建筑、历史事件、科学事实等），从而生成更准确、更符合现实的内容。这是Seedream 5.0 Lite的特色功能。

## 核心原理

### 传统AI生成 vs 联网检索增强生成

**传统AI生成**：
```
提示词 → AI模型（基于训练数据）→ 生成结果
局限：知识截止于训练时间，无法获取最新信息或实时知识
```

**联网检索增强生成**：
```
提示词 → 联网检索（获取最新/特定知识）→ AI模型（结合检索结果）→ 生成结果
优势：知识实时更新，可引用真实世界的信息
```

### 联网检索的工作流程

```
用户输入提示词
  ↓
AI分析：需要哪些真实世界知识？
  ↓
联网检索：查询相关知识点（地标、事件、人物、风格...）
  ↓
知识融合：将检索结果融入生成过程
  ↓
生成：基于真实知识的内容
```

## 应用场景

### 1. 真实地标生成
- **旅游宣传**：生成真实存在的景点（如"2024年巴黎奥运会主场馆"）
- **地理教育**：生成世界各地的地标建筑
- **城市规划**：基于真实地理环境生成场景

### 2. 历史事件还原
- **教育插图**：生成历史事件的场景（如"古罗马斗兽场"）
- **纪录片**：还原历史时刻的视觉呈现
- **博物馆展示**：历史人物、文物的数字化重现

### 3. 科学可视化
- **科普插图**：生成科学概念的可视化（如"DNA双螺旋结构"）
- **医学教育**：生成解剖学、病理学的视觉内容
- **技术说明**：生成复杂技术原理的示意图

### 4. 流行文化
- **影视海报**：生成基于真实电影风格的内容
- **书籍插图**：为文学作品生成符合时代的插图
- **游戏概念图**：参考真实历史或文化背景的设计

## Seedream 5.0 Lite的联网检索

### 功能特性
- **实时知识**：访问最新信息，不受训练数据时间限制
- **精准引用**：可以指定具体的知识来源（如"参考2024年巴黎奥运会视觉风格"）
- **事实核查**：生成内容更符合真实世界的事实
- **风格溯源**：可以检索并引用特定艺术家、流派的真实信息

## 联网检索的优势

### 对比无联网检索

| 维度 | 无联网检索 | 联网检索增强 |
|------|----------|-------------|
| **知识时效性** | 受限于训练数据时间 | 实时获取最新信息 |
| **事实准确性** | 可能生成不存在的内容 | 基于真实知识生成 |
| **特定知识** | 无法精确引用特定知识 | 可以指定具体的知识点 |
| **可信度** | 容易产生幻觉（hallucination） | 生成内容有据可查 |

## 联网检索质量优化

### 提示词中的检索指令

| 指令类型 | 示例 | 效果 |
|----------|------|------|
| **明确引用** | "参考埃菲尔铁塔的真实设计" | 精确检索特定对象 |
| **时间限定** | "2024年最新的建筑设计风格" | 检索特定时间段的信息 |
| **风格溯源** | "参考梵高真实画作《星月夜》" | 检索特定艺术作品 |
| **地理定位** | "巴黎圣母院的真实外观" | 检索特定地理位置的信息 |

### 检索质量检查清单
- [ ] 提示词是否明确了需要检索的知识点？
- [ ] 是否指定了具体的时间、地点、人物？
- [ ] 生成结果是否符合真实世界的事实？
- [ ] 如果需要，能否提供知识来源？

### 常见错误

| 错误 | 原因 | 解决方案 |
|------|------|----------|
| **检索指令模糊** | "生成真实的建筑" | 具体化："生成巴黎圣母院的真实外观" |
| **过度依赖检索** | 提示词完全依赖检索 | 平衡检索指令和创意描述 |
| **忽视版权** | 检索并生成受版权保护的内容 | 注意版权边界，用于学习/研究目的 |
| **检索失败** | 查询的知识不存在或难以检索 | 简化查询，或改为基于训练数据生成 |

## 发展趋势

### 当前局限
- **检索速度**：联网检索会增加生成时间
- **知识覆盖**：部分冷门或小众知识可能检索不到
- **多语言支持**：非英文知识的检索质量可能较低

### 未来方向
- **多模态检索**：不仅检索文本知识，还能检索图像、视频
- **私有知识库**：除了公网知识，还能检索用户私有文档
- **实时更新**：生成过程中持续监控知识变化
- **检索理由**：AI能解释"为什么使用这个知识"，增强可解释性
