# 革命心理学（勒庞）

## 概述

法国社会心理学家古斯塔夫·勒庞的经典之作，从心理学角度分析了革命中群体行为的非理性特征。勒庞以其著名的群体心理学理论为基础，探讨了革命中群众的情感、信念和行为模式，揭示了理性在群体行动中的失效机制。

## 核心内容

| 核心主题 | 主要观点 |
|---------|--------|
| 群体非理性 | 个体在群体中丧失理性判断力 |
| 情感传染 | 群体中情绪像疾病一样迅速传播 |
| 领袖魅力 | 革命领袖通过暗示和感染力控制群众 |
| 信念的力量 | 群体行为受简单而强烈的信念驱动 |
| 革命周期 | 从狂热到幻灭再到新秩序的循环 |

## 关键洞察

1. 勒庞的群体心理学理论对理解当代社会运动仍有重要参考价值。2. 革命中的群体行为遵循'情感逻辑'而非'理性逻辑'——情绪的强度远比论据的说服力重要。3. 革命领袖的成功不在于其理性程度，而在于其'暗示力'和'感染力'。4. 该书与勒庞的另一名著《乌合之众》共同构成了群体心理学的理论基础。
