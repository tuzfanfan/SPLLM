# 进化心理学

## 定义

> **进化心理学（Evolutionary Psychology）** 是用进化论解释人类心理机制的研究领域，认为人类行为和心理机制是自然选择的结果。

## 核心原理

### 基本假设

```
进化压力 → 适应性心理机制 → 现代行为表现
```

| 假设 | 说明 |
|------|------|
| **心理机制** | 大脑也是进化产物 |
| **适应性** | 在原始环境中增加生存繁衍几率 |
| **现代失配** | 现代环境与原始环境不同 |
