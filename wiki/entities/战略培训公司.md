# 战略培训公司
## 概述
战略培训公司（Strategic Coach）是丹·苏利文创办的企业家培训组织，致力于帮助成功的企业家在事业和生活上持续成长。公司拥有遍布两个大洲的约120名员工。

## 关键属性
| 属性 | 内容 |
|------|------|
| 创始人 | 丹·苏利文 |
| 总部 | 北美（两个大洲） |
| 员工规模 | 约120人 |
| 核心业务 | 企业家成长培训和教练服务 |
| 宏伟目标 | "不断成长" |

## 详细描述
战略培训公司创设的每一个方法和理念都来源于最基本的原则。其核心工作方式是观察成功企业家，发现其成长障碍及思维方式上的根由，然后提出简单有效的方法帮助其看清并改变思维方式。公司的理念和方法不仅适用于企业家，也被整理成书籍供大众学习。
