## 核心观点（深度提炼）

### 1. 世界观的构成

**世界观**不仅仅是一些孤立的事实，而是一个相互关联的观念体系。

```
观察事实 → 理论解释 → 世界观体系 → 指导行动
```

| 要素 | 说明 |
|------|------|
| **事实** | 观察到的现象 |
| **理论** | 解释事实的观念 |
| **世界观** | 相互关联的理论体系 |

### 2. 科学革命的结构

基于托马斯·库恩的范式理论：

| 阶段 | 说明 |
|------|------|
| **常规科学** | 在现有范式内进行解谜活动 |
| **反常积累** | 出现范式无法解释的现象 |
| **危机** | 反常太多，范式受到质疑 |
| **革命** | 新范式取代旧范式 |
| **范式转换** | 世界观彻底改变 |

### 3. 工具主义 vs 实在论

| 立场 | 核心观点 | 代表 |
|------|----------|------|
| **工具主义** | 理论是工具，不关心真假 | 实用主义者 |
| **实在论** | 理论是对真实世界的描述 | 大多数科学家 |

### 4. 关键科学史案例

| 案例 | 旧范式 | 新范式 |
|------|--------|--------|
| **地心说→日心说** | 地球是宇宙中心 | 太阳是中心 |
