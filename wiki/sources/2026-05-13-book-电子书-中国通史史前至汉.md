# 彩版图文天下·中国通史（史前—汉）- 来源摘要

## 概述

《彩版图文天下·中国通史（史前—汉）》由墨人编，是一部图文并茂的中国历史普及读物。全书从史前时期写到汉代，以精炼简洁的文字和精美珍贵的图片勾勒出中国历史演进的基本脉络，涵盖政治、经济、军事、文化、艺术、宗教、思想和生活方式等方面。

## 核心内容

### 历史分期与大事年表

| 时期 | 时间范围 | 关键事件 |
|------|----------|----------|
| 史前时期 | 距今200万-前2070年 | 元谋人、北京人、仰韶文化、铜石并用时代 |
| 夏朝 | 约前2070-前1600年 | 中国第一个王朝建立 |
| 商朝 | 约前1600-前1046年 | 甲骨文、青铜器 |
| 西周 | 约前1046-前771年 | 分封制、礼乐制度 |
| 春秋战国 | 前770-前221年 | 百家争鸣、秦统一 |
| 秦朝 | 前221-前207年 | 统一六国、焚书坑儒 |
| 汉朝 | 前206-220年 | 文景之治、汉武盛世 |

### 史前文明演进

1. **古人类进化**：直立人→早期智人→晚期智人（距今200万-1万年前）
2. **旧石器→新石器**：从采集狩猎到农业畜牧（约前1万年）
3. **仰韶文化**：距今7000-5500年，率先迈开走向文明的步伐
4. **铜石并用时代**：约前3500-前3000年，开始制造小件铜器
5. **夏朝建立**：约前2070年，进入古代文明时代

## 关键洞察

1. **"读史能够开阔人的眼界和心胸"**：历史帮助人们超越一时一地的局限
2. **中华文明的连续性**：从史前到汉代，中华文明经历了完整的起源和发展过程
3. **多维度历史叙述**：不仅关注政治军事，也涵盖经济、文化、艺术、宗教等
4. **图文结合的呈现方式**：图片与文字互补，增强历史阅读的直观性
