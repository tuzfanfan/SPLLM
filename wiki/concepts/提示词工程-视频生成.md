# 提示词工程-视频生成

## 定义

视频生成提示词工程是指通过结构化、精确化的自然语言描述，引导AI视频生成模型产出符合预期的视频内容的技术方法。

## 提示词结构

### 基础框架

```
[主体描述] + [动作/运动] + [场景/环境] + [镜头语言] + [光影/氛围] + [情绪/节奏]
```

### 进阶结构（多模态场景）

```
@素材引用 + 用途说明 + 时间轴描述 + 情绪节点 + 技术要求
```

## 关键要素

### 1. 时间轴描述
将视频按时间分段描述，确保叙事连贯：

```
0-2秒：开场，特写镜头
3-8秒：发展，中景展示
9-12秒：高潮，快速剪辑
13-15秒：结尾，拉远镜头
```

### 2. 情绪节点标注
明确标注每个阶段的情绪状态：

```
情绪：好奇 → 紧张 → 惊喜 → 满足
```

### 3. 镜头语言
使用专业术语描述运镜：

| 术语 | 含义 |
|------|------|
| 推/拉 | 镜头前进/后退 |
| 摇 | 镜头左右/上下转动 |
| 移 | 镜头平移 |
| 跟 | 跟随主体移动 |
| 环绕 | 360度围绕主体 |
| 希区柯克变焦 | 推拉变焦效果 |

### 4. 景别控制

| 景别 | 描述 | 适用场景 |
|------|------|----------|
| 特写 | 面部或细节 | 情绪表达 |
| 近景 | 胸部以上 | 对话场景 |
| 中景 | 膝盖以上 | 动作展示 |
| 全景 | 全身+环境 | 场景建立 |
| 远景 | 大场景 | 氛围渲染 |

## 最佳实践

### DO（推荐）
- ✅ 使用具体、可量化的描述
- ✅ 分时间段描述复杂场景
- ✅ 明确标注情绪变化
- ✅ 引用参考素材时说明用途
- ✅ 使用专业术语描述镜头语言

### DON'T（避免）
- ❌ 模糊的主观描述（如"好看"、"酷"）
- ❌ 过长的连续描述不分段
- ❌ 忽略时间和空间的逻辑关系
- ❌ 混合多个不相关的场景
