## 核心理论

### 1. 范式理论

**范式（Paradigm)** = 科学共同体共享的模型、标准、方法和信念。

| 要素 | 说明 |
|------|------|
| **符号概括** | 公式、定律 |
| **模型** | 类比、图像 |
| **范例** | 标准解法 |
| **价值观** | 简单性、一致性 |

### 2. 科学革命的结构

```
常规科学 → 反常积累 → 危机 → 革命 → 新范式
```

- **常规科学**：在范式内解谜
- **反常**：范式无法解释的现象
- **危机**：反常积累，范式受质疑
- **革命**：新范式取代旧范式
- **不可通约性**：范式间无法完全翻译

### 3. 对逻辑实证主义的批判

| 旧观点（逻辑实证主义） | 库恩的新观点 |
|--------------------------|-------------------|
| 科学是累积的 | 科学是革命的 |
| 理论通过证实进步 | 范式通过革命转换 |
| 观察是中性的 | 观察负载理论 |
| 科学通向真理 | 科学通向更优的范式 |
