# Oral Copy — 口播文案与公众号长文创作技能

> **定位**：一站式文案创作技能，覆盖口播短视频（A/B/C三类）和公众号长文（D类），提供从选题到成稿的完整方法论。

---

## 一、四大文案类型与公式

### 类型 A：数据活人感（适合产品/服务推广 · 短视频口播）

**核心逻辑**：权威数据背书 + 个人真实体验 = 可信且有温度

**公式**：
```
[文献段] 双机构背书 + 数据冲击 + 口语化解读
    ↓
[活人感段] 具体使用场景 + 真实情绪 + 前后对比
    ↓
[升华段] 洞察升华 + 邀请互动
```

**结构模板**（1分钟/60秒）：

| 时段 | 时长 | 内容 | 要求 |
|------|------|------|------|
| 文献段 | 0-22秒 | 双机构数据+口语化解读 | 机构名后【停顿】，数据后用"简单说就是"过渡 |
| 活人感段 | 22-48秒 | 第一人称场景+情绪转折 | 具体时间+地点+状态，不掩饰脆弱 |
| 升华段 | 48-60秒 | 洞察+互动邀请 | 金句收尾，评论区互动 |

**文献引用规则**：
- 格式：【研究机构+年份法】，如"美国心理学会2024年"
- 引用2个权威机构，包含年份和样本量
- 核心数据有冲击力且口语化可解读
- 引用后立刻关联个人经历

**活人感四要素**：
1. 第一人称"我"的视角
2. 具体场景（时间+地点+状态）
3. 真实情绪（不掩饰脆弱）
4. 转折瞬间（从困扰到惊喜）

---

### 类型 B：人生感悟（适合情感共鸣/价值观输出 · 短视频口播）

**核心逻辑**：具体小事 → 意外转折 → 认知升级 → 场景共鸣 → 权威背书 → 情绪释放

**公式**：
```
[故事引入] 具体小事 + 悬念/意外转折
    ↓
[认知翻转] 一句话颠覆常识（核心观点）
    ↓
[场景迁移] 从物到人，激活读者自身痛点（至少2个场景）
    ↓
[权威背书] 经典+白话解释（老子/庄子/心理学等）
    ↓
[升华收尾] 金句+具象画面+对仗句式
```

**结构模板**（1-2分钟）：

| 时段 | 占比 | 内容 | 要求 |
|------|------|------|------|
| 故事引入 | ~25% | 日常小事+意外转折 | 低门槛、高代入、制造悬念 |
| 认知翻转 | ~10% | 一句话核心观点 | 短、有力、颠覆预期 |
| 场景迁移 | ~20% | 2个读者痛点场景 | 用"这像不像你……"反问句式 |
| 权威背书 | ~15% | 经典名言+白话解释 | 先解释说服，再贴权威标签 |
| 升华收尾 | ~30% | 金句+画面+对仗 | 适合截图转发 |

**关键技巧**：
- **钩子设计**：不抛观点讲故事，制造信息差（"四个字""一句话"）
- **说教规避**：全文无"你应该""我们必须"，每个观点用故事/画面包装
- **金句密度**：每段至少1句可截图转发的金句
- **情绪曲线**：好奇→代入→震撼→共鸣→释然→感动

---

### 类型 C：产品种草（适合电商/带货/品牌推广 · 短视频口播）

**核心逻辑**：痛点定位 → 产品方案 → 信任证明 → 行动号召

**公式**：
```
[痛点段] 精准定位用户痛点（不说教，用反问）
    ↓
[方案段] 产品+场景+情绪转折
    ↓
[信任段] 产品介绍+差异化卖点
    ↓
[行动段] 促单+互动
```

**结构模板**（40-60秒）：

| 时段 | 占比 | 内容 | 要求 |
|------|------|------|------|
| 痛点段 | ~20% | 用反问/反常识制造冲突 | "你有没有发现……都在暗示……" |
| 方案段 | ~30% | 产品+使用场景+情绪 | 第一人称，具体细节 |
| 信任段 | ~30% | 产品参数+差异化 | 性能数据+独特卖点 |
| 行动段 | ~20% | 促单+互动邀请 | 具体行动指令 |

**品牌叙事融入**（可选）：
- 痛点→方案→价值证明（三步转化公式）
- 差异化竞争五段位：避开功能价值内卷，打感性价值/稀缺价值

### 类型 D：公众号长文（适合深度内容/公众号输出 · 长文写作）

> **来源**：整合自「数字生命卡兹克」公众号长文写作方法论

**核心定位**："有见识的普通人在认真聊一件打动他的事。"

**核心价值观**：
- 永远对世界保持好奇（不是"我会被取代吗？"，而是"我能用它玩点什么？"）
- 讲人话，像个活人（拥抱不完美，大胆使用"我觉得""我认为"）
- 真诚是唯一的捷径（有缺点就说，不懂就承认）
- 有所为有所不为（动笔前先问：这是我真想表达的吗？）

#### D.1 选题判断（HKR质检法）

动笔前每个选题必须通过HKR质检：
- **H (Happy)** 足够有趣、有悬念？标题和开头能让人好奇想点开？
- **K (Knowledge)** 有信息量？看完能学到新东西？
- **R (Resonance)** 能戳中情绪？让人"对对对我也这么想"？

S级选题三项兼备，及格至少两项。只占一项要重新审视，零项坚决放弃。

**选题交集模型**：好选题 = 专业领域 + 读者兴趣 + 时间节点

**角色代入法**（发散思考）：
- "一个很忙的普通用户"：能帮我省时间/解决具体麻烦吗？
- "一个爱玩的朋友"：够有趣吗？能让我"卧槽还能这样？"
- "一个焦虑的学习者"：能让我学到新东西、有新角度吗？

#### D.2 五种文章原型

写之前先判断属于哪种，每种的写法重心不同：

**① 调查实验型**：亲自下场做一件事，然后报道发现
- 核心："我替你去做了这件事"
- 写法重心：过程叙事 + 层层发现 + 每一步都带真实反应
- 示例：买9.9的DeepSeek、亲手给AI投毒、花499找人上门装OpenClaw

**② 产品体验型**：拿到产品实际使用，带着读者一起体验
- 核心："跟我一起玩"
- 写法重心：场景驱动 + 真实感受 + 跟其他产品的自然对比
- 示例：miclaw手机Agent、Seedance 2.0

**③ 现象解读型**：观察到一个现象，然后层层深入分析
- 核心："你注意到了吗？背后是什么？"
- 写法重心：观察→好奇→研究→哲学升维
- 示例：三宫格图片刷屏、AI看不到爱心

**④ 工具分享型**：分享实用工具/Prompt，用个人故事包裹
- 核心："我发现了一个好东西"
- 写法重心：个人故事铺垫→工具展示→效果惊艳
- 示例：天赋挖掘Prompt

**⑤ 方法论分享型**：系统性地分享长期积累的经验
- 核心："我把压箱底的东西掏给你了"
- 写法重心：每节必须可执行 + 坦诚学习成本和失败点 + 谦逊铺垫
- 示例："如何找回你的创造力""用AI三年的9条心得"

#### D.3 风格内核

**节奏感**：像跟朋友聊天，不像写报告。句子时长时短，大量逗号制造口语停顿。一句话自成一段制造重点。偏出去的内容要用"扣主线句"拉回来。

**知识输出方式**：知识是"聊着聊着顺手掏出来"的，不是"下面我来给大家科普一下"。

**私人视角**：用"我也面临这个问题"连接个人经历和公共议题，经常从自己的真实经历切入。

**亲自下场**：不是隔空评论，而是真的去做那件事。让读者感觉到"这个人真的做了"。

**人物画像法**：从数据点出发，3-5句话内想象背后那个具体的人的完整人生（触发点数据→快速代入→多维堆砌→情感锚定→细节具象化）。

**文化升维**：聊完具体事情后，自然连接到更大的文化/哲学/历史参照物。不是硬凑的升华，是"聊着聊着自然想到了"。

**句式断裂**：极短句子独立成段，制造停顿和重量感（如"黑暗森林。""大时代啊，朋友们。"）。关键节点用一下效果极强，不能滥用。

**回环呼应（契诃夫之枪）**：前面埋的细节后面要响。开头留钩子，结尾callback回来，形成前后因果的闭合感。

**谦逊铺垫法**：给出观点前先用自谦降低防御心（"我也不知道行不行""不成熟的经验"）。

**反向论证**：先满足读者期待，再打破它（"你以为Prompt技巧要很复杂？结果就是复制粘贴。"）。

**英雄之旅叙事弧**：遇到问题/好奇心→一步步去做踩坑→秀出结果。起点必须是具体的、读者能代入的困境。

**逐一展示法（升番逻辑）**：多个产品/案例对比时逐一展示，每个带吐槽点评。排列遵循升番逻辑——最弱放前面，最炸留最后，中间有"以为到顶了结果还能往上翻"的惊喜。

**对立面的理解与承认**：讲观点前先站在对方角度把处境具体化，承认合理，再切入自己的不同视角。

#### D.4 结构模板

```
【开头】感性切入，从具体事件/场景开始，迅速建立情绪
  ↓
【背景铺垫】简要科普（聊天式），让非专业读者也能看懂
  ↓
【核心内容】分几个板块展开，每个板块有：
  - 一个明确观点
  - 至少一个具体场景/人物/对话支撑
  - 私人视角的连接
  - 一句扣主线的话
  ↓
【升华】从具体事件拉到更大的文化/哲学/历史参照物
  ↓
【收尾】选最合适的一种：
  - 引用收尾 / 哲思余韵 / 行动呼吁 / 信念宣言 / 回环呼应
  ↓
【固定尾部】
以上，既然看到这里了，如果觉得不错，随手点个赞、在看、转发三连吧，
如果想第一时间收到推送，也可以给我个星标⭐～
谢谢你看我的文章，我们，下次再见。
```

**字数与格式**：
- 4000-8000字
- 段落要短，一句话一段很常见
- **不加小标题**，靠口语化转场句自然衔接（"说到这个""回到xxx这块"）
- 只有"N条心得"分条目结构才用数字编号，也不是正式标题

#### D.5 AI协作角色边界

**AI擅长**：找证据佐证、找类比比喻、按确定角度扩写、补充学科背景、梳理逻辑结构

**AI做了会暴露**：第一手观察和真实经历、核心创意角度、情绪的真实表达、数据到人物的同理心转换

**理想协作流程**：
```
人：提供素材 + 核心观点 + 个人经历 + 情绪节点
 ↓
AI：补充背景知识 + 找证据类比 + 结构建议 + 按角度扩写
 ↓
人：二次改写（加入自己的声音、打破节奏、补充真实细节）
 ↓
AI：按四层自检体系检查 → 输出修改建议
 ↓
人：终审和定稿
```

## 二、通用写作规范

### 语言风格
- **短句为主**：每句不超过20字（口播）/ 长短句交替制造节奏（长文）
- **口语化连接词**："然后""不一会""可是""就好像"（口播）/ "坦率的讲""说真的""反正我觉得""回到xxx这块"（长文）
- **情绪标记**：【停顿】【语气加重】【叹气】【笑】（口播）/ "。。。""？？？""= ="（长文）
- **结尾互动**：邀请评论区互动（口播）/ 固定尾部三连（长文）

### 绝对禁区（长文D类严格执行，口播A/B/C类参考适用）

1. **套话禁用**："首先...其次...最后"、"综上所述"、"值得注意的是"、"不难发现"、"让我们来看看"、"接下来让我们"
2. **过度结构化**：不用bullet point罗列观点，不大量加粗，不用小标题切割
3. **标点禁令**（长文D类）：
   - 不使用冒号"："，用逗号代替
   - 不使用破折号"——"
   - 不使用任何双引号（""和""），用「」或直接不加
4. **高频踩雷词绝对禁用**：
   - "说白了" → 换成"坦率的讲"、"其实就是"
   - "意味着什么？" / "这意味着" → 换成"那结果会怎样呢"、"所以呢"
   - "本质上" → 换成"说到底"、"其实"
   - "换句话说" → 换成"你想想看"、"也就是说"
   - "不可否认" → 直接删掉，换成正面陈述
5. **假设性例子**：禁用"比如有一次..."编造场景，用"就像我今天正在搞的xxx"真实细节
6. **空泛工具名**：不说"AI工具""某个模型"，要说具体名字
7. **教科书开头**：禁止"在当今AI快速发展的时代"类空话，永远从具体事件切入

### 推荐口语化词组（长文D类主动使用，口播类参考适用）

**转场过渡**：坦率的讲、说真的、我是真的觉得、反正我觉得、怎么说呢、其实吧、你想想看、我跟你说、回到xxx这块、这块需要注意一下、顺着上面的再聊聊

**表达判断**：我有时候觉得、我一直觉得、这话听着有点刺耳但、不是说xxx不行而是说、我自己的感受是、我始终坚信

**承认自嘲**：说实话我也不确定、我自己也还在摸索、可能有些想法还不成熟、这个事儿我也踩过坑、愚钝如我

**情绪表达**：这种感觉太爽了、我当时就愣住了、想想就觉得兴奋、我真的被震撼到了、太离谱了、给我一下子整不会了、鬼使神差的、你敢信？？？

**口头禅口癖**：这玩意、不是哥们、我寻思了一下我没寻思明白、有个屁的xxx、真的就是一声叹息、太牛逼了、比较骚的事

### 避坑指南（口播A/B/C类）
- ❌ 不说教，不说"我们应该""你必须"
- ❌ 不堆砌多个数据（类型A最多2个机构）
- ❌ 不用绝对化用词（最、第一、唯一等）
- ❌ 不用虚假宣传用语
- ✅ 文献引用后立刻关联个人
- ✅ 活人感段要有具体细节
- ✅ 金句要有截图转发价值

### 情绪价值植入（可选增强）
| 情绪价值要素 | 植入方式 |
|-------------|----------|
| 情感抚慰 | 说出读者不敢承认的焦虑 |
| 身份认同 | 把读者拉入某个群体 |
| 归属感 | "原来不止我这样想" |
| 自我实现 | 给读者一个成长方向 |

## 三、类型判断决策树

```
用户需求
├── 短视频口播/60秒以内
│   ├── 推广产品/服务 + 有数据支撑 → 类型A（数据活人感）
│   ├── 情感共鸣/人生感悟/价值观 → 类型B（人生感悟）
│   ├── 电商带货/品牌推广 → 类型C（产品种草）
│   └── 复合需求 → 按主次排序，先主类型后补充
├── 公众号长文/深度内容
│   ├── 亲自做一件事报道发现 → 类型D-①（调查实验型）
│   ├── 产品实际使用体验 → 类型D-②（产品体验型）
│   ├── 现象观察深入分析 → 类型D-③（现象解读型）
│   ├── 工具/Prompt分享 → 类型D-④（工具分享型）
│   └── 经验方法论系统分享 → 类型D-⑤（方法论分享型）
└── 不确定 → 询问用户输出平台和内容深度
```

**复合需求处理**：
- "产品推广+人生感悟" → 先B（故事引入）→ 再A（数据背书）→ 再C（产品介绍）
- "产品推广+品牌叙事" → 先C（痛点）→ 再C（方案）→ 品牌叙事融入信任段
- "口播+长文" → 先用口播公式写短版，再用长文方法论扩写深度版

```markdown
[标题]

## 自检概述
[自检表格]

## 拍摄建议
[场景、画面、BGM、字幕]
```

### 长文类（D）输出格式：
```markdown
## 文章标题
[标题]

## 完整文章
```

## 五、质量自检清单

### 口播类自检（A/B/C）

| 检查项 | 通过标准 |
|--------|----------|
| 钩子有效性 | 开头3秒内能否抓住注意力？ |
| 情绪曲线 | 是否有明确的情绪起伏（低→高→释放）？ |
| 说教规避 | 全文是否无"你应该""我们必须"？ |
| 金句密度 | 每段是否至少有1句可截图转发的句子？ |
| 口播适配 | 句子是否短小（<20字）？是否有停顿点？ |
| 违禁词检查 | 无绝对化用词、无虚假宣传、无不当比较？ |
| 情绪价值 | 是否命中至少1个情绪价值要素？ |
| 互动引导 | 结尾是否有明确的互动邀请？ |

### 长文类自检（D）— 四层自检体系

#### L1 硬性规则检查（自动扫描层）

| 检查项 | 通过标准 | 修复方式 |
|--------|----------|----------|
| L1-1 禁用词 | 全文无"说白了""意味着""本质上""换句话说""不可否认""综上所述""首先...其次...最后""值得注意的是""不难发现" | 用推荐口语化词组替代 |
| L1-2 禁用标点 | 全文无冒号、破折号、双引号 | 冒号→逗号，破折号→逗号/句号，双引号→「」或去掉 |
| L1-3 结构套话 | 无"让我们来看看""在当今...时代""随着...发展"，无超过3个bullet point，无大段加粗 | 改为散文叙述 |
| L1-4 工具名 | 所有AI工具/产品使用具体名称 | 替换空泛表述 |

**通过标准**：以上四项零命中。

#### L2 风格一致性检查（模式匹配层）

| 检查项 | 通过标准 |
|--------|----------|
| L2-1 开头 | 从具体事件/场景切入，非宏大叙事；第一句让读者想"然后呢？" |
| L2-2 节奏 | 长短句交替；至少3处一句话独立成段；偏离后有扣主线句；有疑问句刹车转向 |
| L2-3 口语化 | 至少8-10个不同口语化表达；有论述中的故意打破；有自嘲/承认不足；有情绪标点 |
| L2-4 标点禁令二次确认 | 全文无冒号、破折号、双引号 |

**通过标准**：L2-1全通过，L2-2至少3/4，L2-3至少3/4，L2-4通过。

#### L3 内容质量检查（深度审查层）

| 检查项 | 通过标准 |
|--------|----------|
| L3-1 观点支撑 | 每个核心观点有具体人/场景/细节/数据支撑 |
| L3-2 知识输出 | 知识以"随手掏"方式呈现，无教科书式科普 |
| L3-3 文化升维 | 至少一处从具体事件连接到更大参照物，且自然 |
| L3-4 对立面与同理心 | 讲观点前有对对方立场的理解和承认 |
| L3-5 类型专项 | 按D.2五种原型做针对性检查 |
| L3-6 逐一展示 | 多案例对比时用逐一展示+吐槽，非一次性罗列 |

**通过标准**：L3-1和L3-2必须全通过，其余按适用性检查。

#### L4 活人感终审（最终人格层）

核心问题：**"读完这篇文章，我感觉是一个有见识的普通人在认真聊一件打动他的事，还是一个AI在给我输出信息？"**

| 感知维度 | 通过标准 |
|----------|----------|
| L4-1 温度感 | 情绪是体感记忆（"我当时就愣住了"）而非知识性描述（"我感到非常震撼"） |
| L4-2 独特性 | 有"只有这个作者才会写出来的角度" |
| L4-3 姿态 | "有见识的普通人在认真聊"，非"导师教学生"或"品牌做营销" |
| L4-4 心流 | 从头到尾读无注意力断点，无需回头理解逻辑 |

**通过标准**：整体感觉"这像是真人写的"。AI味重的段落需用更口语、更私人、更不完美的方式重写。

## 六、与其他技能的协作

| 协作技能 | 协作方式 |
|----------|----------|
| prompt-flow | 当用户请求"写个文案"时，prompt-flow 先走反向沟通收集需求，再触发 oral-copy |
| hv-analysis | 类型A/C文案需要产品研究数据时，调用 hv-analysis 获取市场数据 |
| khazix-writer | 类型D长文写作时，参考 khazix-writer 的完整风格示例库和内容方法论 |
| neat-freak | 会话结束时，将本次文案创作经验同步到记忆 |
