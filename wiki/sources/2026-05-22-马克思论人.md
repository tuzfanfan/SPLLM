# 马克思论人
| 属性 | 内容 |
|------|------|
| 作者 | 埃·弗洛姆（德文编著）；陈世夫、张世广（中文译编）；王太庆（译文校订） |
| 出版信息 | 陕西人民出版社，1991年12月第1版，ISBN 7-224-02014-1 |
| 类型 | 哲学/马克思主义研究 |
| 核心主题 | 马克思的人学思想、人的本质、异化理论、社会主义的人本主义阐释 |

## 核心观点
1. 弗洛姆从西方马克思主义人本主义流派立场出发，系统阐释马克思关于人的本质、异化和社会主义的思想
2. 认为马克思的历史就是人越来越发展又越来越异化的历史，社会主义意味着从异化中解放出来
3. 强调马克思思想的连贯性，认为青年马克思与老年马克思之间不存在根本断裂
4. 完整收录了马克思《1844年经济学—哲学手稿》中的关键选段
5. 将弗洛伊德的心理分析理论同马克思的人学思想进行综合尝试
