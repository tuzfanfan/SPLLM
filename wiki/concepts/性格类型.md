# 性格类型

## 定义

> **性格类型** 是指根据人的心理特征（能量来源、信息收集、决策方式、生活方式）进行的分类系统。MBTI将人分为16种具体类型。

## 四大性情禀赋

MBTI的16种类型可以归为4大性情禀赋：

| 性情禀赋 | 包含类型 | 特征 |
|----------|----------|------|
| **SJ 传统主义者** | ISTJ, ISFJ, ESTJ, ESFJ | 重视传统、秩序、责任 |
| **SP 经验主义者** | ISTP, ISFP, ESTP, ESFP | 活在当下、灵活、实用 |
| **NT 概念主义者** | INTJ, INTP, ENTJ, ENTP | 战略思维、理性、概念化 |
| **NF 理想主义者** | INFJ, INFP, ENFJ, ENFP | 理想主义、人情味、价值驱动 |

## 应用技巧

### 快速识别他人性格

| 观察维度 | 看什么 | 判断方法 |
|----------|--------|----------|
| **能量** | 说话量、社交活跃度 | 多→E，少→I |
| **信息** | 关注细节还是大局 | 细节→S，模式→N |
| **决策** | 讲理还是讲情 | 逻辑→T，价值→F |
| **生活** | 计划性强还是随性 | 计划→J，灵活→P |

### 用对方的语言交谈

| 类型 | 沟通要点 |
|------|----------|
| **S型** | 给具体事实、数据、步骤 |
| **N型** | 讲愿景、意义、未来可能性 |
| **T型** | 讲逻辑、利弊、效率 |
| **F型** | 讲价值、感受、人际关系 |
| **J型** | 给计划、时间表、明确结论 |
| **P型** | 给选项、保持灵活、不要逼迫 |
