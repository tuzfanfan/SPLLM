# 可灵AI使用指南 — 图片生成

## 概述

可图（Kolors）是可灵平台上的AI图像生成能力，支持文生图、参考图生图、AI图像编辑、AI模特与试衣等功能。

### 可图核心能力总览

| 能力 | 说明 |
|------|------|
| 文生图 | 2.0模型擅长风格与电影质感；1.5模型擅长真实人像；1.0模型基础能力 |
| 图生图 | 能保持角色特征、人物长相，有风格转绘功能和通用垫图功能 |
| AI图像编辑 | 扩图、局部重绘、消除笔等能力 |
| AI模特与试衣 | 上传或生成AI模特，上传衣服图片直接获得试衣效果 |

---

## 一、文生图模型

### 提示词构成要素

| 要素 | 说明 |
|------|------|
| 主体 | 对主体外貌细节和姿态等的描述（发型发色、服饰穿搭、五官形态、肢体姿态等） |
| 主体行为 | 对主体行为姿态的描述，定格某一个画面的行为动作 |
| 场景 | 主体所处的环境，包括前景、背景等 |
| 美学补充 | 风格、光影、色彩、镜头语言、氛围等美学要求 |

### 生图模型驯服经验

1. **抽卡心态**：生图模型的效果像抽卡一样是不定概率的，可以多次调整prompt
2. **电影质感**：想要电影质感的图片，记得强调"电影质感"、"电影氛围"等词
3. **重要词前置**：重要的词放最前面，模型响应不佳的词可反复强调
4. **使用场景**：如有明确使用场景，建议写出图片使用场景
5. **字数控制**：字数一般在几十字~300字为宜

### 可图2.1模型优势

- **语义遵循大幅提升**：对多种元素、复杂指令、颜色位置等响应有大幅度提升
- **电影质感提升**：电影大片的氛围和层次，画面构图更有高级感
- **支持风格拓展**：能支持百余种风格
- **其他优势**：画面残图率低、画面质量领先；生图结果更具异质性

## 二、参考图功能

### （一）单图参考

#### 1. 角色特征参考
- **功能**：维持角色的长相、衣着等特征
- **支持模型**：可图1.5
- **使用场景**：剧情角色保持、泛同人创作、表情包、社交媒体

#### 2. 人物长相参考
- **功能**：维持人物的人脸长相不变，可改变服装、发型、配饰、场景
- **支持模型**：可图1.5
- **使用场景**：人物写真、剧情、泛同人创作

#### 3. 风格转绘
- **功能**：维持画面的主要内容不变，通过prompt描述改变画面风格
- **支持模型**：可图2.0
- **使用场景**：图片风格化、头像生成、转绘

#### 4. 通用垫图
- **功能**：基于图片内容，根据prompt要求来重新绘图
- **支持模型**：可图1.0
- **使用场景**：前述垫图场景或其他未覆盖的场景

### （二）多图参考

支持用户上传多张参考图，融合多种特征及元素（主体、风格、场景）。

#### 特色玩法

| 玩法 | 说明 |
|------|------|
| 水晶球 | 上传主体图、场景图，输入"水晶球" |
| AI山海经 | 上传多张主体图，输入"AI山海经" |
| 波利口袋 | 上传主体图、场景图，输入"波利口袋" |
| 跨次元合影 | 上传主体图、场景图，输入"跨次元合影" |

## 三、AI图像编辑

### 1. 局部重绘

通过指定重绘区域，并提供目标内容的提示词描述，可对图片进行元素增加、元素修改等操作。

**操作方式**：支持"快速选择"、"框选"、"涂抹"、"擦除"等工具指定重绘区域

### 2. 扩图

支持用户随意拖拽原图位置，改变原图大小，可自由扩充图片内容，放大画面视野。

## 四、AI模特

### AI模特的优势

1. **打通服装动态展示全流程**：无缝衔接AI换装功能，一键完成服装更换和搭配展示
2. **高真实感高美感**：生成的模特图片具有专业级的真实感和美感

### AI模特提示词公式

```
AI模特提示词 = 基础信息 + 表情或气质 + 发型 + 服装 + 姿势 + 环境氛围
```

### 提示词元素详解

| 元素 | 维度 |
|------|------|
| 基础信息 | 基础人种特征：亚洲、欧美、混血、拉美 |
| 表情或气质 | 严肃表情、优雅表情、端庄表情 |
| 发型 | 长度：超长、及肩、齐耳、短发；发色：自然黑、暖棕、亚麻色、金色 |
| 服装 | 材质：棉质、丝质、针织、蕾丝；颜色：白色、米色、藏青、驼色；风格：休闲、商务、复古、运动 |
| 姿势 | 基础站姿、身体角度、手部动作、表情细节、目光方向 |
| 环境氛围 | 背景特征、构图要求、风格定位 |

### 提示词撰写Tips

- Tip 1：重点是准确，而不是华丽的描述
- Tip 2：描述不易过于冗长
- Tip 3：服装描述中的鞋子为非必填，可根据全身/半身图调整
