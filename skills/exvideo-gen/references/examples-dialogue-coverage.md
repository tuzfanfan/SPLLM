## Example 01: Two-Person Confrontation Coverage Logic

### Status

- Type: source-method example
- Purpose: preserve a practical dialogue-coverage workflow for tension, power, and interiority
- Default inheritance: partial
- Replace before reuse: demo dialogue lines, food-prop staging, and any joke framing from the source

### What This Example Covers

- reverse shot is not a default answer
- close-up can escalate conflict inside a dialogue scene
- foreground occlusion can intensify the apparent pressure of one character
- occasional wide resets can restore geography and add tension
- inner reverse singles versus outer reverse singles should be chosen intentionally

### What To Preserve

- dialogue coverage should reflect relationship state, not only speaker order
- framing height and occlusion can shift perceived power
- single coverage, over-shoulder, and wider resets each have distinct jobs
- interior emotional moments need different coverage from physical or relational threat moments

### What To Replace Before Reuse

- demo lines and comedic staging
- any assumption that one conflict type fits every conversation
