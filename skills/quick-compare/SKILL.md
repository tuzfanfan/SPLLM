# Quick Compare

## 用途

在不启动整套重型研究的前提下，快速拉出差异图。

## 默认维度

- 面向谁
- 解决什么问题
- 怎么解决
- 最大优势
- 最大短板
- 适合什么场景

## 输入要求

- 至少要有两个明确对象
- 如果对象名称本身有歧义，先澄清再比

## 何时升级到 hv-analysis

如果出现下面任一情况，不要硬停留在 quick compare：

- 用户需要深度竞品研究
- 需要时间线或历史演化
- 需要商业化判断
- 需要正式报告级交付

## 何时不要用

- 用户只想了解单一对象
- 用户要的是历史脉络或长报告
- 用户其实只要一个简单推荐，不需要展开比对

## 输出结构

1. `一句话结论`
2. `共同点`
3. `关键差异`
4. `怎么选`

## 推荐输出模板

- `一句话结论`
- `共同点`
- `关键差异`
- `适用人群/场景`
- `怎么选`
- `是否建议升级深研`

## 邻近 skill 边界

- 与 `hv-analysis`：本 skill 做轻量比对，后者做正式深研
- 与 `prompt-flow`：如果用户还处在“这事该怎么走”的阶段，先让前置路由判断是否该进入 quick compare

## 规则

- 优先讲“对选择真正有影响的差异”
- 少做参数罗列，多做决策意义解释
- 如果差异非常小，要敢于明确说“本质差别不大”
