# 仇富——当下中国的贫富之争

## 概述

本书是学者薛涌对中国当下贫富差距问题的深度评论集，以与吴敬琏、江平、茅于轼等主流自由派知识分子的辩论为主线，探讨了中国经济改革中产生的贫富分化、拆迁暴力、权钱交易等社会问题。作者从市场经济的基本原则出发，批评了部分知识分子从改革推动者变为既得利益卫道士的转变。

## 核心内容

| 主题 | 核心观点 |
|------|----------|
| 仇富的根源 | 非理性财富积累导致的掠夺性行为，而非对财富本身的嫉妒 |
| 拆迁问题 | 政府权力未真正退出经济领域，官商勾结侵害普通百姓权益 |
| 知识分子转型 | 一代自由派从改革推动者变为既得利益卫道士 |
| 市场经济 | 真正的市场经济应保护个人权利，而非为权钱交易辩护 |

## 关键洞察

1. 作者指出'仇富'情绪的合理性在于对不义之财的反对
2. 自由派知识分子在获得地位后可能成为新的既得利益集团
3. 中国经济起飞主要依赖制造业廉价劳工的竞争优势
4. 知识权力不受挑战时同样会导致腐败
5. 真正的改革需要限制政府权力，保障个人权利
