# 第一家族 - 来源摘要

## 概述

本书是刘亚洲撰写的洛克菲勒家族传记，以"恶首富"与"首善"的双重身份审视这位世界首富的传奇人生。全书从洛克菲勒的商业帝国建设、托拉斯垄断模式、慈善事业开创三个维度，全面展现了这个"富过七代"的第一家族。书中特别强调洛克菲勒对中国的影响——协和医学院的建立和整个中国西医体系的发展。

## 核心内容

| 主题 | 核心内容 |
|------|----------|
| 商业奇迹 | 从小商人到世界首富、标准石油公司的建立与扩张 |
| 垄断与反垄断 | 托拉斯模式的创立、现代公司制度的奠基 |
| 慈善事业 | 洛克菲勒基金会、芝加哥大学、协和医学院 |
| 家族传承 | 富过七代的秘密、家族对美国政治文化的影响 |

## 关键洞察

1. **"恶首富"同时还是"首善"**：恶与善在洛克菲勒身上如此集中——既是垄断大鳄，又是慈善先驱。
2. **洛克菲勒的财富换算**：如果健在，其财富约2000亿美元，远超巴菲特和比尔·盖茨。
3. **中国协和医学院受惠于洛克菲勒**：中国的整个西医体系就是在协和的基础上成长壮大的。
4. **"富不过三代"的打破**：洛克菲勒已走进第七代，基金会仍是最有代表性的慈善机构之一。
5. **比尔·盖茨最崇敬的人是洛克菲勒**：盖茨面临反垄断官司时，心灵上的唯一慰藉就是洛克菲勒。
