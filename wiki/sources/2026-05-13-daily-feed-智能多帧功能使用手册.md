# 智能多帧功能使用手册

## 概述

「智能多帧」是即梦最新推出的多图驱动视频生成能力，支持上传最多10帧图像，模型会自动识别图像内容，结合提示词和设定的停留时长，生成空间连续、运镜流畅、节奏合理的一镜到底视频。

### 核心能力

- 上传多张关键帧图像（2-10张），实现一镜到底的视觉效果
- 自由设置每一帧之间的时长（1-6s），调整节奏表达
- 配合运镜提示词使用，让镜头更自然更连贯
- 支持空间运镜、产品展示、节奏驱动、角色动态、叙事等多种创作场景

### 基础参数

| 参数项 | 说明 |
|--------|------|
| 支持帧数 | 最多10帧（建议4-7帧，效果更稳） |
| 帧间时长 | 1-6s自己选择，视频总共最长可达到54s |
| 输入类型 | 图片 |
| 分辨率 | 720p |
| 提示词 | 针对两帧中间过渡写提示词，而非单纯描述图片画面 |

## 适用场景

### 1. 空间运镜类（空间穿梭）

通过镜头的平移、推进、拉远、环绕、跟随等连续运镜方式，实现自然衔接与无缝穿梭。

**提示词编写结构**：
```
【镜头运动方式】+【下一张图片的空间元素】+【环境氛围】+（可选情绪/动作）
```

**基础运镜词**：
- 镜头拉近 / 镜头拉远 / 固定镜头
- 镜头水平向右/左平移
- 镜头垂直向上/下移动
- 镜头俯视拍摄 / 镜头仰视拍摄
- 镜头旋转进入下一场景
- 镜头高速穿越 / 镜头360度环绕
- 镜头俯冲 / 镜头拔升 / 镜头穿梭 / 镜头贴地飞行

**注意事项**：
- 必须有镜头动作：用"镜头+动作"开头
- 动作与秒数匹配：大幅运动4-6s，小幅运动1-3s
- 镜头不要堆太多：一条提示词1-2种镜头动作即可

### 2. 角色动态类（复杂主体动态）

以角色的连续动作为核心，强调主体明确、动作连贯、与环境互动。

**提示词编写结构**：
```
【角色身份/外观】+【关键动作】+【环境元素】+【镜头运动方式】+（可选情绪/氛围）
```

**注意事项**：
- 动作连贯：相邻帧中动作最好有延续性
- 与环境互动：让角色动作与背景元素产生关联
- 动作和镜头匹配：快节奏动作配快速运镜
- 秒数合理：大动作3-6s，小动作1-3s

### 3. 产品展示类（商业产品广告）

以突出产品为核心，呈现产品的外观细节、功能特点及使用场景。

**提示词编写结构**：
```
【镜头运动方式】+【产品部位/特征】+【展示细节/功能】+【环境氛围/质感】
```

**常见镜头运动方式**：
- 镜头360度环绕产品
- 镜头沿产品边缘滑动
- 镜头推进聚焦Logo或关键部位
- 镜头穿过产品表面元素切换至另一部分

**注意事项**：
- 产品的细节和比例保持一致
- 物理变化循序渐进：用"缓慢""逐渐"等描述
- 用运镜制造变化：用基础运镜过渡画面

### 4. 节奏驱动类（卡点视频）

利用可自定义0-6秒帧间间隔的特性，通过画面切换速度与视觉变化，配合节拍或情绪节奏。

**提示词编写结构**：
```
【镜头运动方式/画面变化方式】+【变化元素/主体动作】+【节奏感修饰词】+【环境氛围】
```

**镜头运动方式**：
- 镜头快速推进 / 镜头急速拉远
- 镜头闪切 / 画面快速转换 / 镜头快速旋转

### 5. 叙事类

以长镜头贯穿故事，将空间运镜、角色动态、节奏变化等多种镜头语言融合成一体。

**提示词编写结构**：
```
【镜头运动方式】+【当前画面内容】+【过渡方式/动作】+【下一画面内容】+【氛围/情绪】
```

**编写要点**：
- 故事主线先定好：明确故事逻辑，按节奏顺序排帧
- 多类别融合：在不同帧用不同的镜头语言
- 过渡自然：帧与帧的连接要有空间或动作的合理性
- 情绪递进：前后帧的情绪逐步加强或缓和

### 6. 循环动画

首帧和尾帧保证图片一样即可，可以成为循环壁纸。

---

## 提示词编写关键要素

1. **明确镜头运动方式**：始终明确镜头的运动方式（拉近、拉远、平移、旋转等）
2. **简洁且有针对性的描述**：重点描述关键元素，避免过度细化无关细节
3. **注重情感和动作的衔接**：精确描写人物的动作与情感，避免模糊描述
4. **根据场景类型调整提示词**：不同场景类型有不同的提示词要求

**重要提醒**：不建议不写提示词。关键帧越好视频效果就越好，如果没有足够的信息，一定要写精准的提示词。
