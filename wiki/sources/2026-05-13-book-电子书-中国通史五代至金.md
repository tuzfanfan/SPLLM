# 彩版图文天下·中国通史（五代十国—金）

## 概述

本书是《彩版图文天下·中国通史》系列的第三册，涵盖从五代十国到金朝的中国历史。叙述了五代十国的分裂动荡、宋朝的文治武功以及辽、金、西夏等少数民族政权的兴衰。

## 核心内容

| 历史时期 | 核心内容 |
|----------|----------|
| 五代十国 | 政权更迭频繁、社会动荡 |
| 北宋 | 重文轻武、经济繁荣、文化鼎盛 |
| 南宋 | 偏安江南、岳飞抗金 |
| 辽金西夏 | 少数民族政权的兴衰 |
| 宋代文化 | 理学、宋词、科技发明 |

## 关键洞察

1. 五代十国的分裂为宋朝的统一提供了历史条件；2. 宋朝的经济文化成就远超其军事成就；3. 多民族政权的并立是这一时期的重要特征；4. 宋代科技发明对世界文明产生了深远影响；5. 文治与武功的失衡是宋朝最终灭亡的重要原因。
