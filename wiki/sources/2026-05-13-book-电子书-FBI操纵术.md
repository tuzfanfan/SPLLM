# FBI操纵术 - 来源摘要

## 概述

《FBI操纵术》由鲁毅著，是一部系统总结FBI在身体语言、攻心术、操纵术等方面理论和实战经验的心理学读物。全书分为"FBI特工神秘读心术"和"FBI特工绝密攻心术"上下两篇，将FBI特工在刑事侦破中运用的心理操纵术灵活应用到日常工作和生活中。

## 核心内容

### FBI读心术体系

| 观察维度 | 分析内容 | 判断依据 |
|----------|---------|---------|
| 头部形状 | 性格特征 | 8种头形对应不同性格 |
| 眼睛 | 德行、心地、人品 | 眼神坦荡vs狡猾、刚直vs游移 |
| 眉毛 | 情绪变化 | 皱眉肌、降眉间肌的运动 |
| 鼻子 | 性格倾向 | 鼻梁挺拔vs下陷 |
| 嘴巴 | 内心活动 | 嘴角上扬vs下垂 |
| 耳朵 | 遗传与性格 | 耳朵大小与形状 |

### 八种头形与性格

| 头形 | 性格特征 | 适合职业 |
|------|---------|---------|
| 正方头 | 追求自由、精力充沛、头脑简单 | 野外运动 |
| 长方头 | 凭智力获得成功、缺乏执行力 | 外交家、推销员 |
| 圆形头 | 和蔼幽默、享受生活、行动缓慢 | — |
| 三角头 | 智商高、善于思考、创造力强 | 思想家、发明家 |
| 新月头 | 谨慎、果断、三思而后行 | — |
| 凹额头 | 思维敏捷、人缘好、善于谋略 | 领袖人物 |

### FBI操纵术的核心观点

- "操纵术"并非贬义，而是一种战术和技术
- 人的一切行动都由心理控制
- 读心攻心需要认真观察、仔细判断
- "知人知面更要知心"

## 关键洞察

1. **"人心的相通性"**：FBI的心理操纵术适用于日常生活，因为人性是相通的
2. **"眼睛是心灵之窗"**：眼神可以反映一个人的德行、心地和人品
3. **"视线对视的矛盾心理"**：对视时既想让对方感到不快，又怕被看穿心理
4. **"不自信者的自我确认"**：习惯从别人眼中反映的自己来确认存在与价值
