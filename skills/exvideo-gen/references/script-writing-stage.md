# Story and Script Stage

Use this stage to turn a project idea, source script, reference work, narration, or story premise into an approved canonical script before storyboard production.

## Stage Position

```text
project brief
-> story and script
-> visual bible and character cards
-> storyboard
-> page production
```

The script is production truth for narrative intent. Storyboards may compress or visualize it, but must not silently change its character arc, causal chain, midpoint, climax choice, or theme.

Read `references/cinematic-shot-language.md` when a script needs storyboard-ready visual beats. At script level, specify shot language only when it carries story information, controls a reveal, marks an emotional turn, or establishes a recurring visual motif.

## Supported Routes

- `original`: develop a new story from a premise
- `adapt`: adapt supplied material into a video script
- `restructure`: retain abstract dramatic functions while replacing surface settings
- `narration`: write voiceover-led video copy
- `dialogue`: develop dialogue-led scenes
- `expand`: turn a synopsis or beat sheet into scenes
- `compress`: reduce a long story to a target duration

## Structural Rewrite Rule

When studying a reference work:

1. Extract abstract dramatic functions.
2. Lock the five-element story core.
3. Remove surface settings such as era, occupation, location, and props.
4. Rebuild relationships, conflict mechanisms, midpoint events, climax actions, and consequences.
5. Run an originality-distance check before script approval.

Do not preserve:
- proprietary characters or worldbuilding
- signature dialogue
- iconic or highly distinctive scenes
- the same key-event sequence
- the same resolution mechanism with renamed roles

```text
请先检查五大核心要素能否组成完整因果链，再开始创作。保留参考作品的抽象叙事功能，但重新设计人物关系、冲突机制、中点事件、高潮行动和具体情节，避免生成只更换时代、身份与场景的换皮故事。
```

## Script Deliverables

- logline

- character arcs

- scene outline
- dialogue draft
- voiceover copy
- complete script
- storyboard-ready scene and beat export

## Script Gate Checklist

- The protagonist's obsession produces the wrong actions.
- The inner flaw directly worsens the external conflict or relationship.
- The midpoint changes strategy, stakes, or understanding.
- The climax forces a choice between the old belief and growth.
- The climax action proves the character's change.
- The ending echoes the theme without merely stating it.
- The causal chain can be summarized without missing links.
- Reference works contribute abstract structure only.
- The new story changes at least three structural dimensions when using a reference.
- Duration and delivery format are suitable for storyboard conversion.

## Storyboard Handoff

Export only approved script truth:

```yaml
storyboard_handoff:
  script_id: SCRIPT-01
  approved_logline:
  approved_beats: []
  scene_candidates: []
  required_dialogue: []
  required_visual_motifs: []
  required_shot_intents: []
  emotional_progression: []
```

Do not let storyboard convenience rewrite locked story decisions. Return to this stage when a visual constraint requires a narrative change.
