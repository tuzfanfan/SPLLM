## Example 01: Director-Style Asset Preparation Before Shot Generation

### Status

- Type: source-method example
- Purpose: preserve the workflow that builds character, costume, prop, scene, and palette assets before storyboard generation
- Default inheritance: partial
- Replace before reuse: exact project subject, source model names, and any one-workflow branding

### What This Example Covers

- same-character multi-costume preparation
- key prop asset preparation
- detailed scene asset preparation
- color-card constraints per sequence
- prompt structure that describes image elements first, then light and color, then consistency, then constraints

### What To Preserve

- asset preparation is an upstream production stage, not an afterthought
- character, costume, prop, scene, and palette should not be collapsed into one fuzzy reference
- color logic is stronger when stored as a reusable asset artifact
- high-quality shots often come from strong asset preproduction more than clever last-minute prompts

### What To Replace Before Reuse

- source-specific model names
- source-specific subject matter
- any assumption that one asset density fits every project
