# 格列弗游记

## 概述

《格列弗游记》是英国作家斯威夫特的讽刺小说杰作，讲述了外科医生格列佛四次航海冒险的奇异经历。通过小人国、大人国、飞岛国和慧骃国等幻想国度，对当时英国的政治、宗教、科学和社会进行了辛辣的讽刺。

## 核心内容

| 游记 | 讽刺对象 |
|------|----------|
| 小人国 | 英国政党政治和宗教纷争 |
| 大人国 | 英国社会的自大与偏见 |
| 飞岛国 | 脱离实际的科学研究和空想 |
| 慧骃国 | 理性社会的理想与人类劣根性 |

## 关键洞察

1. 讽刺文学的最高成就之一，以幻想映射现实
2. 尺度的变化带来视角的转换，从而揭示社会荒谬
3. 慧骃国中马比人高尚的设定是对人类文明的深刻反思
4. 作品的讽刺具有超越时代的普遍意义
