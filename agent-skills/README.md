# Unified Agent Skills

This folder is the workspace-local home for agent skill repositories.

## Mappings

- `C:\Users\Administrator\.qclaw\skills` -> `E:\SPLLM\agent-skills\qclaw\skills`
- `C:\Users\Administrator\.openclaw\skills` -> `E:\SPLLM\agent-skills\openclaw\skills`
- `C:\Users\Administrator\.codebuddy\skills` -> `E:\SPLLM\.aweskill\skills`

## Notes

- The original skill folders were preserved as same-parent backups before the links were created.
- `WorkBuddy` already only exposed `aweskill` and `aweskill-doctor`, so it now uses the workspace-central `aweskill` store.
- App-bundled skill sets under install directories such as `D:\Dumates` and `E:\Wukong` were not moved here because they are packaged with the applications rather than user-managed skill roots.
