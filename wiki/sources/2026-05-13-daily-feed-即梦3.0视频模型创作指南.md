# 即梦3.0&3.0pro视频模型创作指南

## 概述

即梦视频3.0 Pro具有强大的语意遵循能力，写好prompt可以生成丰富多样的视频。核心是"直观表达出你想要的效果"，可以使用自然语言自由书写动作/运镜/风格/视角。

---

## 提示词构建公式

### 文生视频（T2V）
```
主体 + 动作 + 场景 + 镜头 + 风格 + （情绪演绎）+ （照明）
```

### 图生视频（I+T2V）
```
动作 + 镜头 + （情绪/照明）
```

### 基础起手式
- **I+T2V基础起手式**：`"主体" + "单动作"`
- **T2V基础起手式**：`"清晰的主体描述" + "场景" + "单动作"`
- **进阶**：动作指令可添加运动速度、运动方向和运动幅度方面的提示词

---

## 一、动作指令控制

### 1.1 单一动作（简单动作）

| 类型 | 说明 |
|------|------|
| 简单单一动作 | 走路、跑步、飞行、行驶等 |
| 进阶单一动作 | 跳水、格斗、冲浪、滑雪等 |

### 1.2 时序组合动作（复杂动作）

按照动作发生的时序，清晰描述出多个动作，实现单人物多动作/多人物多动作。

**注意事项**：
- ✅ 模型能够流畅地生成各类运动
- ❌ 当输入超过三个动作时，模型对动作的响应程度会下降
- ❌ 模型存在交互感较弱以及不符合物理规律等问题

---

## 二、情绪演绎

### 基础提示词编写逻辑（T2V）

1. 确定画面的主体&所处环境
2. 确定简单的情绪基调词：恐惧、悲伤、嘲讽、害羞等
3. 针对基础情绪辅以对应的脸部表情动作+动作控制

### 进阶玩法（I+T2V）

#### 单情绪进阶构建
参考影视中对于人物情绪的演绎桥段，加上不同的镜头选择和运镜以及辅以光影的打光处理

#### 多情绪递进/串联
叠加基础的情绪词来多样的情绪转变，符合剧情中人物的情绪递进

### 能力边界
- ✅ 能够准确执行常见的情绪词所带来的表情变化&肢体变化
- ❌ 对于悲伤、忧郁等出现的眼泪或汗水等提示词不敏感
- ❌ 对于极端和较为复杂的情绪词需要较多的阐述

### 注意事项
- 脸部需要清晰并且正面角度偏多
- 最好针对单人进行情绪的叙述
- 建议加入程度词：非常、极度、很、极端等

---

## 三、场景描述

### 场景构成要素表

| 构成要素 | 推荐度 | 说明 |
|----------|--------|------|
| 场景地点 | 必须 | 决定空间构图，明确"事件发生在哪里" |
| 发生时间 | 较推荐 | 提供光影与时序的美学基础 |
| 空间氛围 | 较推荐 | 注入情绪、叙事感和氛围词 |

### 空间氛围优化思路

❌ **不建议写**：
- "寂静氛围" / "孤独感很强" / "悲伤氛围"（抽象词，模型难以对齐）

✅ **推荐写**：
- "她一个人站立月光洒落的冷蓝色空间" → 把"孤独"变成"空旷空间 + 单人主体 + 冷色调光影"
- "黄昏的天台，夕阳余晖照在身上，空气里带着温暖的金色氛围" → 把"温暖"变成"色调+时间"

### 构建完整场景步骤
1. 最基础：只写场景地点
2. 加入时间序列
3. 加入氛围营造

---

## 四、风格描述

### 4.1 风格直出（T2V）

**注意**：直接把风格写在提示词里，不建议使用"美美的""风格酷酷的""好看的"等词语

#### 风格分类

| 分类 | 类型 |
|------|------|
| 平面2D风格 | 黑白线稿、美漫风格、日本平面漫画、2D韩漫风格 |
| 立体3D风格 | 3D动画、低多边形、MG图形动画、毛毡动画、像素游戏、体素风格、故障艺术、CG渲染 |
| 传统艺术风格 | 工笔画、网点印刷、油画风格、铅笔画、水彩风格、黑白水墨风格 |
| 动漫风格 | 美漫风格、日式风格动漫、影偶动画 |

### 4.2 风格延续（I+T2V/I2V）

模型对多种风格的核心特征具备精准的识别与复现能力：
- **风格元素高度统一**：能稳定捕捉并延续目标风格的典型特征
- **智能补全**：新元素会自动和原本的画风匹配，不会突兀

## 五、镜头语言

### 5.1 基础运镜

| 镜头类型 | 说明 | 效果 |
|----------|------|------|
| 推镜头 | 镜头逐渐向主体推进 | 强调细节、展现内心世界、营造紧张感 |
| 拉镜头 | 镜头逐渐远离主体 | 揭示主体与环境的关系、表现孤独感 |
| 摇镜头 | 以固定支点为轴做水平或垂直转动 | 引导视线扫过场景多个元素 |
| 移镜头 | 沿水平方向平稳移动 | 展现空间的纵深感与连续性 |
| 跟镜头 | 始终跟随运动的主体 | 突出主体的动态与存在感 |
| 航拍镜头 | 从空中进行拍摄 | 展现宏大景观、营造史诗感 |
| 环绕镜头 | 以主体为圆心进行360度环绕 | 将焦点集中在主体身上 |
| 变焦镜头 | 改变镜头的光学焦距 | 创造戏剧性效果 |
| 主观镜头 | 模拟角色的双眼 | 身临其境地体验角色感受 |
| 固定镜头 | 机位完全不动 | 制造强烈的戏剧张力、宿命感 |

### 5.2 进阶运镜

组合多个镜头动作，形成连续的镜头过渡。

**操作建议**：
- 每次组合建议使用2-3个镜头动作最稳妥
- 复杂镜头建议逐句拆写

**不推荐的写法**：
- 提示词中写"炫酷""复杂""快速切换"等含糊词语
- 连续镜头跨度太大
- 同一个镜头中加入太多动作

### 5.3 景别和视角控制

- **景别**：远景、全景、中景、近景、特写
- **视角**：水下镜头、航拍镜头、高机位俯拍、低机位仰拍、微距摄影、FPV视角、第一人称视角、鱼眼镜头

## 六、切镜能力

即梦模型独有功能，支持在同一prompt里包含多个切镜，保持主体/风格/场景的延续性。

### 切镜写法格式

**格式1**：使用「切镜：」显式标记
```
切镜1：一个女孩在海边奔跑，阳光洒在她的脸上
切镜2：镜头拉远，女孩站在夕阳下的礁石上
切镜3：夜晚来临，女孩仰望星空
```

**格式2**：使用「镜头一、镜头二」
```
镜头一：镜头从上方向下俯拍，一位男孩站在悬崖边
镜头二：镜头切换至男孩正面，他面带坚定的表情
镜头三：视角切至男孩脚边，一颗小石子滚落悬崖
```

**格式3**：使用镜头语言关键词
```
全景：广袤沙漠上，一队骆驼穿越金色沙丘
中景：镜头跟随其中一位旅人，他望向远方
特写：他的眼睛映出远处绿洲的倒影
```

**限制**：5秒视频最多5个切镜，超过会导致效果下降

## 七、创意特效

### 7.1 首尾帧类型模块

以"首帧 + 尾帧"形式生成视频，AI自动在两帧之间生成过渡视频。

| 类型 | 说明 |
|------|------|
| 空间运镜类 | 从一个空间位置过渡到另一个 |
| 角色动态类 | 角色从一个状态过渡到另一个 |
| 身份跃迁类 | 角色身份的转变 |
| 状态演化类 | 环境或主体的状态变化 |
| 功能触发类 | 触发某个动作或事件 |

### 7.2 首尾帧创意玩法

- 变手办、性别转变、变赛车手、变玩偶
- 返老还童、变挂件

### 7.3 I+T2V创意特效

- 亲吻彼此、骑动物、爆炸特效、动物拟人
- 沸腾、捏捏乐、人物立体、建筑冰封
- 人物像素化、变出翅膀、妙笔生花、文字特效

## 八、Prompt控制美感

### 8.1 人物外形

核心公式：`核心特征 + 年龄性别 + 身材/体态 + 服饰风格 + 场景构建`

创作要点：
- "核心特征"精准描述：面部五官、皮肤质感、标志性元素、发型
- "年龄性别"直观定位
- "身材体态"固定轮廓
- "服饰风格"增添细节
- "场景构建"营造氛围

### 8.2 画面美感

核心公式：`主题氛围 + 环境基底 + 感官细节 + 情感锚点 + 风格调性`

创作要点：
- 明确"核心氛围"，奠定情绪基调
- 构建"环境内容"，明确时间、地点、环境特征
- 加入"感官细节"，从五感延伸
- 强化"感情锚点"，增强记忆点
- 调整"风格调性"，强化整体质感
