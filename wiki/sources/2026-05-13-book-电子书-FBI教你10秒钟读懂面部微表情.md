# FBI教你10秒钟读懂面部微表情 - 来源摘要

## 概述

《FBI教你10秒钟读懂面部微表情》由霍晨昕著，是一部基于心理学家保罗·艾克曼（Paul Ekman）研究成果的微表情识别指南。全书系统介绍了微表情的概念、面部肌肉的运作机制、真假表情的辨别方法，帮助读者在人际交往中更准确地判断他人的真实情绪。微表情分析技术于20世纪90年代初被FBI采用并沿用至今。

## 核心内容

### 微表情的定义

| 特征 | 描述 |
|------|------|
| 持续时间 | 最短1/25秒，最长不超过1/4秒 |
| 本质 | 破坏了情绪应有的完整性，瞬间换以另一种表情 |
| 价值 | 最容易露出马脚的面部线索 |
| 发现者 | 保罗·艾克曼（20世纪80年代末） |

### 面部关键肌肉

| 肌肉 | 位置 | 功能 |
|------|------|------|
| 额肌 | 眉毛上方 | 紧张时眉毛提高、额头出现褶皱 |
| 皱眉肌 | 眉毛内侧 | 发愁或生气时形成垂直褶皱 |
| 上睑提肌 | 上眼睑内 | 紧张时睁眼，放松时闭眼 |
| 眼轮匝肌 | 眼睛周围 | 控制眨眼和眼部表情 |

### 真表情 vs 假表情

- **真表情**：无意识反应，不受控制，没有经过大脑思考
- **假表情**：刻意伪装，有意识反应
- **表现准则**：从小被教导控制表情的社会规范

### 基础情绪

快乐、愤怒、悲伤、厌恶、惊讶、恐惧、轻蔑——情绪可以组合出现

## 关键洞察

1. **"1/25秒的闪烁"**：微表情持续时间极短，但出卖了被刻意掩饰的真实情绪
2. **"有些肌肉你控制不了"**：某些面部肌肉具有强自主性，难以靠意识控制
3. **教皇的政治表情**：1982年教皇与波兰领袖的微笑握手传达了重要的政治信号
4. **练习方法**：看过几百张脸之后就能捕捉微表情和辨认表情真假
