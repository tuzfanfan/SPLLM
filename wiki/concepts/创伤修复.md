# 创伤修复

## 定义

> **创伤修复（Trauma Recovery）** 是从心理创伤中恢复的过程，包括情感急救、认知重构、行为激活和社会支持等多个层面。

## 核心原理

### 创伤不是事件，是反应

**核心命题**：同样的事情发生在不同人身上，有人受伤、有人无恙——关键在于**反应模式**，不是事件本身。

```
创伤事件 → 个体反应模式 → 创伤/成长
```

### 为什么有些人永不受伤？

| 特质 | 说明 | 培养方法 |
|------|------|----------|
| **成长心态** | 把创伤当学习机会 | 重新解释创伤意义 |
| **情绪调节** | 快速从负面情绪中恢复 | 正念、冥想训练 |
| **意义建构** | 从创伤中找到意义 | 写创伤日记、帮助他人 |
| **社会连接** | 拥有可靠的支持系统 | 建立深度关系 |

## 修复方法

### 1. 情感急救

| 步骤 | 说明 |
|------|------|
| **确保安全** | 首先保证物理和心理安全 |
| **稳定情绪** | 深呼吸、 grounding 技巧 |
| **寻求支持** | 联系可信赖的人 |
| **专业帮助** | 必要时寻求心理咨询 |

### 2. 认知重构

- 改变对创伤的理解和解释
- 从"为什么是我？"到"这对我意味着什么？"
- 寻找创伤中的成长机会

### 3. 行为激活

- 通过行动打破创伤循环
- 恢复日常规律
- 逐步尝试新活动

2. **重构意义**：寻找创伤中的成长
3. **建立支持**：可靠的社会连接
4. **专业帮助**：必要时寻求咨询
