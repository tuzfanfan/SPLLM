# 不容青史尽成灰——春秋战国卷

**作者**: 张嵚

## 概述

本书以通俗生动的笔法讲述春秋战国时期的历史故事，揭示被正史忽略的重要历史细节。开篇以郑庄公'小霸'为主线，详细叙述了春秋时代如何从周王朝'天下一统'转变为诸侯争霸的图景。通过'克段于鄢'、'黄泉会母'、'繻葛之战'等经典事件，以及卫懿公'仙鹤亡国'等生动故事，深入分析了礼崩乐坏的时代背景和诸侯争霸的政治逻辑。

## 核心内容

| 历史事件 | 核心内容 | 历史意义 |
|----------|---------|--------|
| 克段于鄢 | 郑庄公纵容弟弟公叔段谋反后一举歼灭 | 纵容缺点是最好的打击手段 |
| 黄泉会母 | 郑庄公与母亲武姜的恩怨与和解 | 孝道沦丧的标志 |
| 繻葛之战 | 郑庄公以少胜多击败周天子联军 | 周王室威望扫地，诸侯争霸开始 |
| 周郑交质 | 周天子与郑庄公互相交换人质 | 天子权威丧失的象征 |
| 仙鹤亡国 | 卫懿公爱鹤如命导致亡国 | 统治者失民心必亡 |

## 关键洞察

1. 郑庄公'小霸'是春秋争霸的序幕，他捅破了周王室'金玉其外'的窗户纸。
2. '克段于鄢'的智慧：如果恨一个人，最好的办法就是放纵他的缺点。
3. 繻葛之战中郑庄公采用'打结合部'的战术，利用周军联军鱼龙混杂的弱点。
4. 郑国虽称霸一时却缺乏长远战略眼光，四战之地的地缘限制了其发展潜力。
5. 卫懿公'仙鹤亡国'深刻说明：统治者不把人民当人，人民也不把他当人。
6. 春秋时代的根本转折是礼崩乐坏——宗法制的基石开始动摇。
