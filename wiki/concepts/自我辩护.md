# 自我辩护

## 定义
自我辩护是指人们为自己的愚蠢看法、糟糕决策和伤害性行为进行合理化解释的心理过程。与撒谎不同，自我辩护是自欺欺人，让人们确信自己已经尽力了。

## 特征
根据《错不在我》：
- **无意识性**: 通常是无意识进行的
- **自利性**: 总是朝着对自己有利的方向
- **持续性**: 一旦开始就会不断强化
- **欺骗性**: 比谎言更具欺骗性，因为连自己也相信

## 常见表现
- "我不可能再做任何其他事情了"
- "实际上，这是解决问题的最佳方式"
- "我正在为国家尽我所能"
- "那些杂种是咎由自取"
- "我有权这样做"

## 与撒谎的区别
| 撒谎 | 自我辩护 |
|------|----------|
| 知道自己在说假话 | 自己也相信辩护的理由 |
| 目的是欺骗他人 | 目的是欺骗自己和他人 |
| 有意识的 | 通常是无意识的 |
| 清楚知道真相 | 扭曲了对真相的认知 |

## 危害
1. **阻碍学习**: 无法从错误中学习
2. **加深偏见**: 强化原有错误观念
3. **破坏关系**: 在冲突中推卸责任
4. **维持错误**: 坚持已被证明错误的观点
5. **造成伪善**: 行为与信念不一致

## 识别方法
1. 觉察"一定是有人出错了，但不是我"的想法
2. 注意面对反面证据时的防御反应
3. 观察自己是否过度解释行为
4. 检查记忆是否过于自利

## 克服方法
1. **承认错误**: 直接说"我错了"
2. **寻求反馈**: 主动听取反面意见
3. **成长型思维**: 将错误视为学习机会
4. **换位思考**: 从他人角度看问题
