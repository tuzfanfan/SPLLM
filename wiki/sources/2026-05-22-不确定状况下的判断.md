# 不确定状况下的判断：启发式和偏差

## 核心观点（深度提炼）

### 1. 三种核心启发式

**核心命题**：人在不确定条件下做判断时，依赖简化的经验法则（启发式），但这些启发式会导致系统性偏差。

```
判断过程：
  复杂信息 → 启发式简化 → 快速判断 → 系统性偏差
```

| 启发式 | 定义 | 导致的偏差 |
|--------|------|------------|
| **代表性启发式** | 用相似性判断概率 | 忽略基础概率、赌徒谬误 |
| **可得性启发式** | 用回忆难易判断频率 | 媒体影响、鲜活性效应 |
| **锚定与调整** | 从初始值调整判断 | 锚定效应、谈判劣势 |

### 2. 代表性启发式导致的偏差

| 偏差 | 说明 | 例子 |
|------|------|------|
| **基础概率忽略** | 忽视事件发生的先验概率 | 忽略疾病基础发病率 |
| **赌徒谬误** | 认为独立事件有"记忆" | "连输5次，下次该赢了" |
| **共轭谬误** | 误判细节增加概率 | 认为"银行出纳且女权主义者"概率>单纯"银行出纳" |
| **样本大小忽略** | 忽视小样本的随机性 | 小样本极端值被误认为规律 |

### 3. 可得性启发式导致的偏差

| 偏差 | 说明 | 影响 |
|------|------|------|
| ** retrievability** | 容易回忆的信息被高估 | 媒体报道影响风险感知 |
| **有效性** | 生动、具体的信息权重大 | 个人经历>统计数据 |
| **想象性** | 容易想象的事被认为更可能 | 灾难片影响风险判断 |
| **假关联** | 媒体集中报道造成虚假关联 | 误以为某些事件相关 |

### 4. 锚定效应

| 场景 | 机制 | 对策 |
|------|------|------|
| **谈判** | 先开价者设定锚点 | 准备自己的锚点 |
| **估价** | 初始价格影响最终判断 | 独立评估，不看标价 |
| **预测** | 初始数字影响后续估计 | 多角度验证，不依赖单一参考 |
