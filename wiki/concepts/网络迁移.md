# 网络迁移

## 定义

> **网络迁移（Cyber Migration）** 指现实世界的行为模式、社会关系和心理机制向网络空间转移和变形的过程。这种行为迁移并非简单复制，而是在网络环境中发生质变和放大。

## 核心原理

### 迁移类型

| 类型 | 现实行为 | 网络变形 | 变形特征 |
|------|----------|----------|----------|
| **社交迁移** | 面对面交流 | 社交媒体互动 | 更开放但也更脆弱 |
| **消费迁移** | 实体购物 | 网络购物 | 冲动性增强 |
| **犯罪迁移** | 传统犯罪 | 网络犯罪 | 跨地域、匿名化 |
| **性迁移** | 现实亲密关系 | 网络性活动 | 去抑制、多样化 |
| **教育迁移** | 课堂学习 | 在线学习 | 自主性增强但专注力下降 |

### 迁移机制

```
现实行为 → 网络环境 → 条件反射改变 → 行为变形 → 新行为模式固化
```

- [[条件作用]]：网络奖励机制重塑行为模式
- [[在线去抑制效应]]：降低行为约束
- [[匿名性（网络）]]：改变身份认知

## 关键特征

| 特征 | 说明 |
|------|------|
| **加速效应** | 网络使行为传播和扩散速度加快 |
| **放大效应** | 网络环境放大某些行为的强度 |
| **变形效应** | 行为在网络中发生质变 |
| **不可逆性** | 迁移后的行为模式难以完全恢复 |
