# 五千年演义：三国兴亡

## 概述

《五千年演义：三国兴亡》是"五千年演义"丛书之一，由隐石霖编著。本书以章回体演义形式讲述三国历史，从东汉末代皇帝汉献帝刘协登基的初平元年（190年）开始，到280年孙皓降晋、全国统一为止，历时九十年。本书不同于《三国演义》，尊重史实，避免对重大事件的编造，力求在引人入胜的故事中提供准确、系统的三国知识。

## 核心内容

### 历史时间线

| 时间 | 事件 |
|------|------|
| 189年 | 灵帝死，少帝刘辩即位，何进掌权 |
| 189年 | 董卓进京，废少帝立献帝 |
| 190年 | 关东诸军讨董卓 |
| 220年 | 曹丕篡汉建魏，三国时期开始 |
| 280年 | 司马炎灭吴，三国归一 |

### 主要人物

#### 宦官集团
- **张让、赵忠**：十常侍首领，灵帝称其为"父母"
- **蹇硕**：上军校尉，西园新军统帅，试图刺杀何进

#### 外戚集团
- **何进**：大将军，何皇后之兄，优柔寡断
- **何太后**：灵帝皇后，太子刘辩生母

#### 军阀势力
- **董卓**：凉州军阀，废少帝立献帝，残暴专权
- **袁绍**："四世三公"，名门望族代表
- **曹操**：典军校尉，后成为乱世奸雄
- **刘备**：汉室宗亲，与关羽、张飞桃园结义
- **吕布**：勇将，先后投靠丁原、董卓

### 关键事件

1. **灵帝卖官**
   - 三公官职定价一千万钱
   - 曹嵩（曹操父）花一万万钱买得太尉
   - 崔烈半价五百万钱买官

2. **西园新军**
   - 上军校尉蹇硕（宦官）
   - 中军校尉袁绍
   - 典军校尉曹操
   - 助军左校尉赵融等八人

3. **何进之死**
   - 袁绍建议召董卓进京胁迫太后
   - 曹操反对："只需一名管刑法的官员逮捕罪魁"
   - 宦官抢先动手，何进被杀
   - 袁绍大杀宦官两千余人

4. **董卓专权**
   - 废少帝刘辩，立献帝刘协
   - 毒死何太后
   - 纵兵为匪，屠杀百姓
   - 曹操刺杀未遂，逃亡

5. **曹操杀吕伯奢**
   - 误杀吕伯奢全家
   - 名言："宁我负人，人毋负我"

## 关键洞察

1. **宦官与外戚的斗争**：东汉末年政治的核心矛盾，两大集团交替专权，最终同归于尽。

2. **袁绍的短视**：坚决劝何进召董卓进京，却在董卓到来时不敢反抗，最终逃往冀州。

3. **曹操的政治眼光**：反对召外兵进京，预见会引起大乱；主张只惩办少数罪魁。

4. **董卓的残暴**：从"豪爽仗义"到"纵兵为匪"，展现军阀的强盗本性。

5. **历史的偶然与必然**：灵帝早死、何进优柔、董卓入京，一系列偶然事件促成三国乱世。

## 本书特色

- **观点新**：依据马克思主义观点评价历史人物和事件
- **写名人、写大事**：重点突出，连续性强
- **选材全面**：政治、经济、军事、外交、科技、文化各领域
- **语言通俗**：难字注音，古地名注今名，官职说明职权
- **大事不虚，小事不拘**：保持历史真实，允许细节虚构
