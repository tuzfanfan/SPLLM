# Fabric Briefing Pack

## 目标

把 `hotspot-radar` 抓到的原始列表和正文，转成更便于判断和传播的 briefing 层。

## 1. Summary Pass

适用：
- 日报
- source 页摘要
- 编辑快速过稿

输出：
- 一句话总览
- 5 到 10 个主点
- 3 个值得继续追的方向

## 2. Micro Summary Pass

适用：
- 目录页
- 封面摘要
- 通知消息

输出：
- 1 到 2 句话
- 尽量带一个最值得看的角度

## 3. Five Sentence Pass

适用：
- source 页短摘要
- 给后续研究 skill 的 handoff

结构：
1. 发生了什么
2. 为什么现在发生
3. 谁会受影响
4. 哪个细节最值得看
5. 下一步可以怎么跟进

## 4. Tag Pass

从热点里抽：
- 行业
- 品牌
- 产品
- 争议主题
- 叙事标签

## 5. Compare Pass

适用：
- 同一天多条热点在讲同一件事
- 多个媒体叙事明显不同

输出：
- 各来源共同点
- 主要分歧
- 哪个版本更值得深挖
