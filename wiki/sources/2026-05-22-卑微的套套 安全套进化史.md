# 卑微的套套 安全套进化史
| 属性 | 内容 |
|------|------|
| 作者 | （美）安妮·科利尔（Aine Collier） |
| 出版信息 | 上海文艺出版社，2013年4月第1版，ISBN 978-7-5321-4467-9 |
| 类型 | 社会历史 / 性文化史 |
| 核心主题 | 安全套从古至今的进化史，涉及人类行为、科技、疾病、政治、心理学和宗教 |
## 核心观点
1. 安全套的历史是一部关于人类精神的历史，包括人类精神中所有的错误和瑕疵
2. 安全套的使用贯穿了人类文明的各个阶段，从古埃及、古希腊、古罗马到现代社会
3. 安全套的发展与宗教、政治、道德观念的冲突始终存在，形成了复杂的文化战争
4. 安全套从最初的动物肠衣、纸莎草制品，发展到橡胶制品，再到现代乳胶产品，技术不断进步
5. 艾滋病的出现使安全套重新成为公共卫生的核心议题
6. 安全套产业从手工作坊发展为年利润几十亿美元的全球性产业
