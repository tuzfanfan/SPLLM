# 白寿彝讲历史：明清卷

## 概述

本书是白寿彝主编的《中国通史》的通俗版本明清卷，由白至德编写。以通俗易懂的方式讲述了明朝和清朝的历史，从政治制度到社会文化，全面展现了中国最后一个封建王朝时期的兴衰历程。

## 核心内容

| 朝代 | 核心内容 |
|------|----------|
| 明朝 | 朱元璋建国、靖难之役、郑和下西洋、明朝灭亡 |
| 清朝 | 清军入关、康乾盛世、鸦片战争、清朝覆灭 |
| 政治制度 | 明清两代的政治体制和官僚制度 |
| 社会文化 | 明清时期的社会变迁和文化成就 |
| 对外关系 | 闭关锁国与西方冲击 |

## 关键洞察

1. 明清两代是中国封建社会的晚期阶段；2. 明朝的政治制度对后世影响深远；3. 康乾盛世是清朝国力的巅峰；4. 闭关锁国政策导致中国落后于世界；5. 明清的兴衰为后世提供了深刻的历史教训。
