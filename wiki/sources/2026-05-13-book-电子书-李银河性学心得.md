# 李银河性学心得

## 概述

本书是李银河性学研究的学术随笔集，以深入浅出的方式介绍了性学的基本概念、理论和方法。

## 核心内容

| 主题 | 内容 |
|------|------|
| 性学基础 | 性学的基本概念和研究方法 |
| 性文化 | 中国性文化的历史演变 |
| 性别研究 | 性别的社会建构与权力关系 |
| 性与社会 | 性与婚姻、家庭、法律的关系 |

## 关键洞察

1. 性学是一门严肃的学术研究领域
2. 性文化反映了一个社会的文明程度
3. 性别不是天生的，而是社会建构的
4. 对性少数群体的态度是社会进步的标尺
