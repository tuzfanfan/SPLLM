# 匿名性（网络）

## 定义

> **匿名性（网络）（Online Anonymity）** 指在网络环境中隐藏或模糊真实身份的能力和状态。网络匿名性是[[在线去抑制效应]]的核心驱动因素之一，对网络行为产生深远影响。

## 核心原理

### 匿名性光谱

| 级别 | 特征 | 示例 |
|------|------|------|
| **完全实名** | 真实身份完全公开 | 银行、政务系统 |
| **半实名** | 部分身份公开 | 职业社交网络 |
| **伪匿名** | 使用固定化名 | 论坛、博客 |
| **匿名** | 完全隐藏身份 | 匿名论坛、暗网 |

### 双面效应

| 效应 | 正面 | 负面 |
|------|------|------|
| **自我表露** | 更愿意分享内心感受 | 过度分享隐私信息 |
| **社会参与** | 弱势群体敢于发声 | 仇恨言论泛滥 |
| **创造力** | 减少评价顾虑 | 不负责任的创作 |
| **监督** | 保护举报人和异见者 | 逃避法律责任 |

## 心理机制

```
匿名性 → 降低社会监控感 → 降低自我意识 → 行为去抑制
```

| 机制 | 说明 |
|------|------|
| **去个体化** | 丧失个人身份感，融入群体 |
| **责任分散** | 感到个人责任降低 |
| **社会监控弱化** | 缺乏社会规范的即时约束 |
| **认知解放** | 打破社会期望的束缚 |
