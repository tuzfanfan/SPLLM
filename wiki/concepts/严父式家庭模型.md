# 严父式家庭模型

## 定义

> **严父式家庭模型（Strict Father Model）** 是乔治·莱考夫提出的道德政治框架之一，认为世界危险且永远如此，孩子天生就坏需要改造，通过严厉管教培养纪律和自律。

## 核心特征

| 维度 | 内容 |
|------|------|
| **世界观** | 世界危险，永远如此 |
| **人性观** | 孩子天生就坏，要改造 |
| **养育方式** | 严厉管教，体罚培养纪律 |
| **道德核心** | 自律、顺从、明辨是非 |
| **财富观** | 成功=道德，贫穷=不道德 |
| **政府职能** | 保护+国防，不干预市场 |
| **外交政策** | 道德权威不需"举手请准" |

## 道德体系

### 核心道德
1. **自律（Self-Discipline）**：通过严厉管教培养
2. **顺从（Obedience）**：尊重权威，服从管教
3. **明辨是非**：有清晰的道德界限

### 衍生道德
- **个人责任**：自己对自己负责
- **适者生存**：市场自由竞争
- **道德权威**：权威不需请示他人

## 政治表现（保守派）

### 经济政策
- **减税**：减少政府干预，让市场自由
- **削减福利**：避免养懒人，促进自立
- **放松监管**：企业自我约束更有效

### 社会政策
- **反对堕胎**：明确的道德界限
- **反对同性婚姻**：传统家庭价值观
- **支持持枪**：自我保护是基本权利

### 外交政策
- **单边主义**：道德权威不需"举手请准"
- **军事优先**：保护国家安全
- **反恐战争**：世界危险，需要强硬应对

## 经典案例

### 施瓦辛格竞选奇迹（2003年加州罢免选举）
- **严父式英雄**：健美冠军、动作明星 → 激活严父模型
- **"举手请准"框架**：暗示联合国（儿童）需向美国（成人）请示 → 激活严父道德
- **进步派失败**：格雷·戴维斯用"自身利益"框架，但选民按价值观投票
- **跨模型投票**：蓝领工人家里是严父，投票给施瓦辛格

### "9·11"如何改变美国大脑
- **建筑物隐喻激活**：双塔是头、是身体 → 飞机=子弹、火焰=鲜血
- **恐惧框架持续激活**：橙色警报、反恐战争 → 持续激活严父模型
- **镜像神经元效应**：看到大楼倒塌 = 自己身体倒下 → 生理性恐惧

## 批评与局限

### 批评观点
1. **过于简化**：真实的家庭和道德观更复杂
2. **二元对立**：忽略了中间立场
3. **文化偏见**：主要基于美国政治分析

### 现实复杂性
- 很多人同时持有两种模型的某些方面
- 议题不同，激活的框架可能不同
- 文化会随时间演变
