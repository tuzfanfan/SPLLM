# 巴菲特与索罗斯21个投资秘籍 - 来源摘要

## 概述

《巴菲特与索罗斯21个投资秘籍》由胡金盛著，以巴菲特和索罗斯两位投资大师的实际操作案例为基础，总结出21个投资秘籍。全书从投资作风、心态、策略等角度，结合A股市场实例，阐述普通投资者应具备的投资素养。

## 核心内容

### 第一法宝：自信而不迷信

| 秘籍 | 核心内容 |
|------|----------|
| 自信成就巴菲特 | 1969年牛市中坚决退出，1973年抄底《华盛顿邮报》，1000万变2亿 |
| 不被分析师左右 | 巴菲特称分析师为"股鼠"，从不阅读证券公司报告 |
| 不迷信权威 | 巴菲特总部设在远离纽约的奥马哈，避免华尔街影响 |
| 不迷信工具 | 技术分析被法默教授称为"占星术" |
| 不迷信内幕消息 | "让百万富翁破产的最快方法就是告诉他小道消息" |

### 巴菲特经典投资案例

- **美国运通**（1963）：遭诈骗后股价暴跌，巴菲特大量买入，4年后股价飙升至180美元
- **可口可乐**（1988）：以市场最高价75%买入，3年内股价上涨3倍
- **华盛顿邮报**（1973）：1000万美元投资，10年后升值为2亿美元

### 三种致命"迷信"

1. 迷信权威——分析师预测准确度仅相当于抛硬币
2. 迷信工具——没有电脑炒股软件能让人稳定赚钱
3. 迷信内部消息——内幕消息可能让你一年内破产

## 关键洞察

1. **自信源于研究**：巴菲特的自信不是盲目的，而是建立在对企业详细研究的基础上
2. **A股分析师的教训**：2007-2008年A股从6000点跌至1664点过程中，分析师的预测几乎全部错误
3. **"囚徒困境"与投资**：不要把赚钱的命运放在别人手里，要独立判断
4. **直觉的价值**：充分研究后的直觉往往比技术分析更可靠
