# 即梦 3.5 Pro 使用手册（Seedance 1.5 pro）

## 概述

即梦 3.5 首次引入「视频自动配音与音效生成」能力。模型不仅可以生成更好的视频画面，还能自动添加匹配的**环境音效、人声对白、音乐配乐**，实现音画一体的创作体验。

### 音频能力核心亮点

- ✅ 模型自动补足的环境音与画面高度匹配，声音自然、不突兀
- ✅ 语种、方言生成能力较强，尤其是中文声音指令执行优秀
- ✅ 情绪演绎到位、拟声表现自然，贴合角色状态
- ✅ BGM风格/氛围，以及背景音效贴合视频的基调
- ✅ 口型准确，音画同步能力强

## PART 1: 音频能力说明

### 1. 环境音效能力（环境/声景）

**定义**：背景中自然或人工产生的声音，模型不仅能自动补足符合画面内容的环境声，还可以通过提示词进行精细控制。

#### 能力说明
- 自动识别场景，生成匹配环境音（如海浪声、雨声、街道车流、人群嘈杂等）
- 可通过提示词控制环境音的种类
- 支持动态声场（远近变化、左右位置感），以及静音留白

#### 音效类型
| 类型 | 说明 |
|------|------|
| 比较单一的环境音 | 海浪声、雨声、风声等 |
| 多音源混合 | 施工声、锣鼓声、人群声等 |
| 动态声场 | 声音有空间变化，层次丰富 |

#### 注意事项
- 如需明确控制音效，可在提示中说明背景声音种类、出现时机、方位等信息
- 若想让模型自由发挥氛围音，可省略音效提示，让模型根据画面自动判断

### 2. 人声对白能力

**定义**：模型能够自动生成自然、真实、口型同步的人声对白，支持多语言、多角色、多种情绪和个性表达。

#### 能力说明
- 支持单人独白与多人对白，可自动生成符合人物身份和场景的语音内容
- 支持语言与口音多样性，中英双语切换流畅，可实现部分小语种和方言
- 支持提示词精控对白内容，可指定关键词、完整台词、说话顺序、语速与停顿节奏
- 支持丰富的情绪表达与语气控制（喜悦、悲伤、生气、惊讶、恐惧、平静等）
- 实现精准口型同步，无论正脸、侧脸、遮挡或快速运动镜头
- 支持非语言人声生成，如笑声、叹息、喘息等

#### 对白场景
| 场景 | 说明 |
|------|------|
| 单人独白 | 一个人的自言自语或内心独白 |
| 多人对话 | 多角色交互对话 |
| 语言与口音多样性 | 粤语、小语种、方言、中英混合 |
| 情绪表达与语气控制 | 冲突插话、情绪变化 |
| 精准口型同步 | 正脸、侧脸、背影/转体 |
| 拟声：非语言人声 | 笑声、叹息、喘息 |
| 特殊音色展示 | 木偶/机器人音、不同年龄音色 |

#### 注意事项
- 当前对白内容与提示词匹配度高，但若提示过多角色或台词，仍可能出现表达顺序或语调不准确的情况
- 对复杂停顿、打断、长对白、重叠语音等表现稳定性仍在持续优化中
- **暂不支持唱歌内容的完整控制**

### 3. 音乐配乐能力

**定义**：模型可自动为视频生成背景配乐，风格与画面氛围匹配。

#### 能力说明
- 自动匹配视频情绪氛围生成配乐（如温暖、紧张、浪漫、神秘）
- 支持指定风格的音乐背景

#### 注意事项
- 当前版本暂不支持生成指定旋律或具体歌曲
- 无法模仿特定音乐作品
- 音乐整体质量稳定，但在部分复杂场景下可能存在与画面节奏契合不够的问题

## PART 2: 应用场景

### 1. 影视场景
音频能力可驱动多角色对白、音画同步与情绪演绎，使人物更真实、情节更沉浸

### 2. 广告场景
支持产品讲解、卖点表达与配乐烘托，实现较为完整的广告视频

### 3. 宣传场景
通过场景声+旁白+配乐组合实现完整输出，可控表达重点，情绪渲染氛围

### 4. 知识科普场景
可生成自然口播配画面，提升知识传播效率

### 5. 娱乐场景
利用音效细节构建沉浸体验，如键盘声、水声、走路声等（ASMR）。适合小红书、B站等轻内容娱乐表达

### 6. 音乐表演类场景
乐器演奏、音乐表演等

## 提示词技巧

### 环境音提示词示例
```
固定镜头，风吹书页翻页声，远处若隐若现的海浪声以及海鸥的声音
稻田间响起远处鸡鸣声和风吹过稻田的声音
```

### 对白提示词示例
```
镜头中，一名士兵趴在泥泞中，满脸是土，神情焦急恐惧。镜头剧烈晃动，爆炸声震耳欲聋。他紧握电话大吼："总部！这里是查理班！我们被包围了——请求支援！快！"
```

### 音乐配乐提示词示例
```
孤独感，萧瑟感的音乐背景，镜头跟随主体，远处有车驶来
惊悚恐怖的背景音乐，画面中起风吹动红色飘带
史诗级震撼、磅礴大气的音乐风格
```

### 综合场景提示词示例
```
背景音为暴雨声以及雷电声伴奏为较为紧张的音乐；图中远处的人物以愤怒且夹杂着雨声的声音说道："跑啊，你怎么不跑了？"，然后跪在镜头前的人以虚弱的声音说道："废话少说，开枪吧"
```
