# 中华上下五千年

## 概述

本书由诸葛祥蜀、赵荣织编著，是一部面向青少年的中国通史读物。全书以时间为线索，以讲故事的形式，从政治、经济、文化、科技、军事等方面，勾勒了中华文明的演进过程。

本书从远古时期开始，历经夏、商、周、秦、汉、三国、晋、南北朝、隋、唐、五代十国、宋、辽、金、元、明、清等历史朝代，直到新中国成立，系统展现了中国历史的波澜壮阔和绚丽多姿。

## 核心内容

### 史前文明

#### 考古大发现

| 发现 | 时间 | 意义 |
|------|------|------|
| 北京猿人 | 1921年周口店 | 五十万年前的人类化石 |
| 蓝田猿人 | 1964年陕西蓝田 | 一百一十万年前，比北京猿人早六十万年 |
| 元谋人 | 1965年云南元谋 | 一百七十万年前 |
| 半坡遗址 | 1954年西安 | 六千多年前的农业文明 |
| 河姆渡遗址 | 1973年浙江余姚 | 七千多年前的稻作文明 |
| 二里头遗址 | 1958年河南偃师 | 夏代遗址，证明夏朝存在 |
| 殷墟甲骨文 | 1899年河南安阳 | 商代文字，揭开商代历史 |

#### 山顶洞人之家
- **时间**：距今一万八千年前
- **特征**：有别于猿人的"新人"
- **生活方式**：聚群而居，使用火，制作石器工具
- **社会形态**：没有家庭，没有社会分化，共同劳动共同生活

#### 半坡遗韵
- **时间**：六千多年前
- **特征**：母系氏族社会后期
- **农业**：种植谷子，饲养家畜
- **手工业**：制陶、纺织、编织
- **建筑**：村落布局，防御沟壕

### 远古传说

#### 三皇五帝

| 人物 | 身份 | 贡献 |
|------|------|------|
| 盘古 | 创世神 | 开天辟地 |
| 女娲 | 人类之母 | 造人、补天 |
| 伏羲 | 人文始祖 | 发明八卦、结网捕鱼 |
| 燧人氏 | 火祖 | 钻木取火 |
| 神农氏 | 农业之神 | 尝百草、发明农耕 |
| 黄帝 | 华夏始祖 | 统一华夏，发明创造 |
| 炎帝 | 神农氏后裔 | 与黄帝共同构成华夏族 |

#### 涿鹿炎黄战蚩尤
- **背景**：黄帝部落与炎帝部落合并
- **对手**：九黎族首领蚩尤
- **战争**：涿鹿之战，黄帝战胜蚩尤
- **意义**：奠定华夏族基础

#### 尧舜禅让
- **尧**：善于治理天下，制定历法
- **舜**：孝顺友善，以德服人
- **禅让**：尧传位给舜，非世袭
- **意义**：古代民主制度的典范

#### 大禹治水
- **背景**：洪水肆虐，百姓苦难
- **方法**：疏导为主，而非堵截
- **精神**：三过家门而不入
- **成就**：治水十三年，制服洪水

### 夏商周时期

#### 夏朝
- **建立**：中国第一个王朝
- **大禹**：开国君主
- **启**：世袭制开始
- **桀**：暴君，夏朝灭亡

#### 商朝

**商汤**：
- 推翻夏桀，建立商朝
- 为民祈雨，仁慈爱民
- "网开三面"的典故

**伊尹**：
- 厨师出身的贤相
- 辅佐商汤、外丙、仲壬、太甲
- 放逐太甲，后迎回复位
- 忠臣的榜样

**盘庚迁都**：
- 第五次迁都，迁至殷
- 限制贵族享乐，缓和阶级矛盾
- 商朝中兴，"殷道复兴"

**商纣王**：
- 历史著名暴君
- 酒池肉林，荒淫无度
- 剖心比干，残害忠良
- 牧野之战，自焚而亡

#### 西周

**周文王**：
- 被商纣囚禁于羑里
- 演《周易》，发展周国
- 为武王伐纣奠定基础

**周武王**：
- 牧野之战，大败商纣
- 建立西周王朝

**周公**：
- 辅佐成王，"一哺三辍"
- 制礼作乐，奠定周朝制度
- 营建东都洛邑

**周厉王**：
- "壅民之口，甚于防川"
- 压制言论，百姓敢怒不敢言
- 被民众推翻，流亡彘地

**周幽王**：
- "烽火戏诸侯"
- 为博褒姒一笑，戏弄诸侯
- 犬戎攻破镐京，西周灭亡

## 关键洞察

1. **考古与文献的结合**：现代考古发现不断印证和补充历史文献，使我们对古代历史有了更清晰的认识。

2. **神话传说的历史价值**：远古神话传说虽然带有想象成分，但反映了先民对自然和社会的认识，具有重要的文化价值。

3. **朝代更替的规律**：暴政导致灭亡，仁政带来兴盛，这是中国历史反复验证的规律。

4. **文明演进的连续性**：中华文明是世界上唯一延续至今的古老文明，具有强大的生命力。

5. **历史人物的多面性**：历史人物往往具有复杂性，不能简单地用好坏来评判。
