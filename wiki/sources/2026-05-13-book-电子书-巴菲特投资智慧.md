# 巴菲特的投资智慧 - 来源摘要

## 概述

《巴菲特的投资智慧》由李榕园著，2011年出版，系统解读"股神"沃伦·巴菲特的投资理念与操作案例。全书分为四部分十章，从"现金为王""控制贪欲""安全第一""投资要看未来"等维度，结合巴菲特投资星座能源、比亚迪、高盛、可口可乐等经典案例，阐述巴菲特"三要三不要"的投资智慧精华。

## 核心内容

### "三要三不要"投资理念

| 类别 | 内容 |
|------|------|
| **要一** | 投资始终把股东利益放在首位的企业 |
| **要二** | 投资源垄断型行业（道路、桥梁、煤炭、电力） |
| **要三** | 投易获得信息、前景看好的企业 |
| **不要一** | 不要贪婪（1969年股市疯狂时悉数抛出） |
| **不要二** | 不要跟风（2000年不投网络概念股，避开股灾） |
| **不要三** | 不要投机（期待股票明天上涨是愚蠢的） |

### 四次股市暴跌中的操作

| 年份 | 操作 |
|------|------|
| 1973年 | 提前退场，等待股市跌透后买入 |
| 1987年 | 1985年起大规模出货，1988年买入可口可乐 |
| 2000年 | 不投高科技网络股，安然度过股灾 |
| 2008年 | 投入280多亿美元抄底（星座能源、高盛、比亚迪等） |

### 经典投资案例

- **星座能源集团**：2008年9月以47亿美元现金收购，股价为2003年以来最低
- **比亚迪**：2008年9月以每股8港元认购2.25亿股，一年后账面获利逾500%
- **可口可乐**：1988-1989年投入10亿美元买入

## 关键洞察

1. **现金为王的真谛**：不是死守现金，而是在最佳时机将现金变为增值资产
2. **保险浮存金的妙用**：伯克希尔公司一半收益来自保险业务，保费收入提供源源不断的投资资金
3. **"当人们贪婪时恐惧，当人们恐惧时贪婪"**：巴菲特核心投资哲学
4. **只用闲钱投资**：亏了不影响生活，赌中了就大赚
