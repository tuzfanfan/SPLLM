# 自由及其背叛：人类自由的六个敌人
| 属性 | 内容 |
|------|------|
| 作者 | [以赛亚·伯林]（Isaiah Berlin） |
| 出版信息 | 译林出版社，BBC广播演讲录，1952年首播 |
| 类型 | 政治哲学/思想史 |
| 核心主题 | 自由的敌人——六位思想家如何以自由之名背叛自由 |

## 核心观点
1. 爱尔维修、卢梭、费希特、黑格尔、圣西门、迈斯特六位思想家都探讨人类自由问题，但最终他们的学说与个体自由相抵触。
2. 这些思想家并非回答旧问题，而是改变了问题本身的性质，让读者"换一种眼光"看待事物。
3. 他们生活的时代（18世纪末至19世纪初）是自由民主制时期的黎明阶段，其思想对19世纪和20世纪影响深远。
4. 功利主义原则——人类唯一追求快乐、避免痛苦——是爱尔维修的核心发现，但由此推导出的社会改造方案却可能威胁个体自由。
5. 伯林区分了"回答问题的思想家"和"改变问题性质的思想家"，后者更为危险也更为深刻。
