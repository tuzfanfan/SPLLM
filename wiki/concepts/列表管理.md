# 列表管理

## 定义

> **列表管理（List Management）** 指使用列表来管理任务、想法和信息的方法。列表是释放大脑记忆负担、提高组织效率的有效工具。

## 核心原理

### 列表的作用

| 作用 | 说明 |
|------|------|
| **释放记忆** | 将任务从工作记忆转移到外部存储 |
| **可视化** | 将抽象的任务变为可视化的列表 |
| **优先排序** | 通过列表确定任务优先级 |
| **追踪进度** | 通过列表追踪任务完成情况 |
| **减少焦虑** | 将模糊的担忧变为具体的行动项 |

### 列表类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **待办列表** | 需要完成的任务 | 今日待办、本周待办 |
| **想法列表** | 需要记住的想法 | 灵感、创意 |
| **清单** | 标准化的检查项 | 出差清单、发布清单 |
| **目标列表** | 长期目标 | 年度目标、季度目标 |
| **问题列表** | 需要解决的问题 | 待解决问题 |

### 列表管理原则

| 原则 | 说明 |
|------|------|
| **及时记录** | 想到就记，不要依赖记忆 |
| **定期清理** | 定期回顾和清理列表 |
| **具体明确** | 任务描述要具体可执行 |
| 估算时间 | 为每个任务估算时间 |
| **优先排序** | 确定任务优先级 |
