# 前言

人有病，天知否

据说某医院规定：

护士微笑须露八颗牙齿。

你说有没有毛病!

但人是不承认自己有病的。

讳疾忌医，这便如何是好!

还是我们的老祖宗老实，

昔齐宣王向孟子坦陈：

“寡人有疾，寡人好货。

寡人有疾，寡人好色。

寡人有疾，寡人好勇。”

齐宣王的这些毛病，迁延遗传，

今人有过之而无不及。

又要钞票、又要面子，

这些毛病，难道仅医院得见?

你我身心，也都染有类似病毒。

据说蜂蛰可以去毒，

黄蜂、阿兰斗胆在钱报辟专栏，

名曰“医患麻辣烫”，自疗疗人。

草头郎中，疗效如何，不敢保证。

唯愿读者诸君一笑警心。

在下：“阿弥陀佛!”

# 刷牙去

7岁的圆圆正在换牙，三颗新牙有些黄斑，美牙能增三分俏，今后找女婿附加值会高许多，圆圆妈七哄八哄，把孩子哄到专科医院。

娘儿俩好不容易挂上号，排队候诊。圆圆喝完娃哈哈、看完蜡笔小新卡漫、涂鸦三张画纸，小孩猴屁股哪坐得住?幸有嫁定金龟婿的信念支撑着圆圆妈，候起候倒，在走廊里坐等2个小时，终于轮到了!这时已近中午11点半。

都说一口烂牙在牙医眼里是“掘金洞”——颗颗烂牙都是钱哪!但此话在这位牙医这儿行不通，他掰开圆圆嘴巴不到半分钟，说：“回去吧，回去多刷牙。”

“她每天都刷三遍以上的，为什么还发黑?是不是有别的原因?”做娘的问得小心翼翼。

医生面有不悦之色：“你当医生还是我当医生?就是刷牙，多刷刷!”医生闲话不多，金口如同动力不足的发条，就只能开1分钟。

做娘的低下眉头，愁上心头：金龟婿远去矣!

# 阿背哥

药房ABC三个窗口都有病人在排长队拿药，人挤人。一位瘦精精的中年男人家努力往窗口候记候记，拿着一罐药打听：“医生，格个药介个吃?”

“一天三次。”

“饭后还是饭前?”

“饭后。”

“是二分之一粒还是三分之一粒?”

“请看说明书。”

“过白开水好不好的?”

“可以。请麻烦让一下，下一位!”

“医生，我还是弄不懂，我怕药苦，好不好放点儿白糖?”

“随便吧……”

“哦，我屋里厢还有瓶蜂蜜，好不好放一瓢羹调调?”

晕倒!

# 记者宣传，看病免费

村妇春妹到杭州打工，得了子宫肌瘤，便到城郊结合部的小门诊部看病。坐堂医生非常热情地检查了一下，叹了口气：“这个病么，死是死不了的，但治不好的话，女人家没得做了。”

春妹还要给夫家生崽，怎能不做女人?她用乞求的眼神望望医生：“医生，用多少钱治得好?”

“这个嘛……没有4000元是下不来的。”

“我老公一月赚800元，我做钟点工一个月才400元，医生，能不能高抬贵手减一点?”

医生悲天悯人地想了想，说：“那么这样吧，现在全社会都在关爱民工，你到报社呼吁一下，让记者给我这个门诊部写一篇千字表扬稿，这4000元治病费就全给你免了!”

# 外国疗法

绍兴的老董拗不过儿子的孝顺，到杭州动一个小手术。他患的是前列腺炎，就是广告上说的“滴滴嗒嗒”的毛病。儿子托了熟人，用了一项新技术，是外国引进的一种疗法，一种新式消融术用到命根子上，可以无痛治愈困扰老董7年的旧疾。

老董肉痛那昂贵的手术费，但转念一想，那顽疾，据说只要10秒钟就能根治，到底现在医术发达了，伢乡下人也享受国际待遇了!

儿子缴了费用，老董上了手术台，医生还在说笑，樯橹间灰飞烟灭——那新式武器“砰”的一声在老董的命根子里爆炸——老董的男人生涯就此终结!

# 张姨做“落儿”

张姨最近老是睡不着，老公催她看医生。慕名去了一家省级大医院，坐堂医生眼睛贼尖，10分钟就诊断她得了抑郁症。开了一张龙飞凤舞的处方单，大半是中药名。他指点道：“这几帖药我们医院没有，要到外面医院去配，不远的，出医院大门左转200米就到。”

张姨一下子觉得自己是抑郁了，捏着救命的处方单，跌跌撞撞出了门。恍恍惚惚转到那家小医院，门口一个穿白大褂的倒也和善，说：“配中药的吧?二楼。”

张姨把处方单递到窗口，觉得药剂师高高在上须仰视才见，自己显得特别渺小。不一会儿，药剂师就把一摞配好的中药包推到她面前：“喏，一天喝两次，一共煎服7天。先去隔壁窗口付钱：462元。”张姨捧着中药包，就像华老栓捧着人血馒头。

张姨到家一五一十说给丈夫听，丈夫跑的码头多，有些奇怪：“这么大的医院怎么没有你要配的中药?偏偏要去小医院?你最喜欢看‘周末喜相逢’，看你笑得前仰后合，哪像抑郁症?”

唉，就当做“落儿”吧。张姨为此抑郁了整整一个月，那药费，毕竟相当于1个月的保姆费呢。

# 贵是贵的，药是好的

85岁的章大爷上周头晕肢麻，女儿陪他上医院做彩超、磁共振，大弄了，总算一颗心放落。检查结果只是脑部小血管有些老化，配了50多元的药。医生嘱他每天吃药，多走动走动就行了。

大爷心想，50多元的药顶个屁用!

这天到小花园早锻炼，碰到热心肠的牛大妈在甩背、踢腿。

“听说你小中风啦?小心一下子瘫了，现在的儿女没有吃得落长日子守床边的……”牛大妈拉着章大爷的手，语重心长。

大爷最忌人说不行了。牛大妈快人快语：“我亲家母跟你一样的毛病，吃了一种北京出的中药，300多元一小颗，贵是贵的，药是好的，现在天天去银泰广场跳早场舞，不要太利爽噢。老章，你做死做活一辈子，现在女儿一个月赚1万块，钞票用不光，还不孝敬你?”说得老章爽快地掏了腰包。

3天后，女儿回家来看老爸，老爸向她吹嘘这种药丸，说已服了2天，神清气爽。女儿不放心，向医生同学打听这只药：

——只限脑中风重症抢救时用。

“阿爸，你介糊涂，弄不好吃多了真要中风了呢!”

这个牛大妈!章大爷差点背过气去。

# 黄梅天天气潮

赵大姐到一所擅长治疗泌尿系统疾病、广告打得梆梆响的小医院做人流，医生一查很严重：“你有性病哎。”赵大姐先是一阵头晕、一脸红晕，又一阵心慌、一阵气急，想自己堂堂正正做人至今，没有做过亏心事，不怕鬼敲门，转念一想，丈夫驻外地数月，莫非已经拈花惹上了野草?

顾不上医生强拉硬拽要配药，赵大姐像一头母狮一样冲回家，丈夫在哄女儿学小狗叫呢。“叫，叫，叫什么春?!给我滚出来!”

和丈夫一顿唇枪舌剑，老实的丈夫脸越憋越红，气不打一处来：“我……我还怀疑你呢。情人节那天晚上你到青藤和一个野男人吃茶，作啥吃到包厢里去了?”

“你血口喷人!你手机短信上三个‘我爱你’的留言怎么解释?!”

闹到精疲力竭，撕破了脸，谁都说了“离婚”这个字眼。丈夫说要离也要离得清白，一定要找那位医生再确认一下是什么样的性病。

那医生哪见过夫妻俩又杀了回马枪?匆匆检查了一下，改口说：“噢，没啥，可能这几天黄梅天天气潮，你得霉菌也是正常的。过几天就会好的么。”

# 先走一步

大医院医生双休日利用休息时间走穴，深受小城镇病家欢迎。周末，一位大牌医生又接到某县城医院的紧急电话，马上出诊。

抢救室里病人等得心焦，大牌医生不慌不忙，穿上隔离消毒服，但手机的耳塞没拿下，没办法，业务繁忙么!

开胸术刚做到一半，手机响了。他把手术刀交给助手，走出隔离房接听，雪白的消毒服溅上了些许病人的鲜血。

过了一会儿，大牌医生匆匆进手术室，对助手说：“乡下还有一台手术等着我，先走一步了。”手术台上，可怜全麻病人是个“睁眼瞎”，剖膛开肚等候着，大牌医生却拜拜啦!

# 头痛医头，脚痛医脚

大热天下班回家，一记闷棍——停电了，好在冰箱里的可乐和西瓜还凉丝丝的，大头阿三一记头吃落去半只瓜、两听可乐，从嘴里舒服到心里。

当时是爽的，半夜里就不爽了，胃里像鱼钩儿钩肉一样，阵阵发紧发痛，痛得他抱牢枕头咬牙切齿。后来呕吐，吃了霍香正气丸也没用，他脸孔煞白冒虚汗，好不容易熬到天亮去了附近一家大医院。

挂了西内科，排了半天队伍，阿三终于坐到一位眼镜儿医生面前。医生眼皮没抬看也不看，就说：“肚皮痛?去消化内科。”大头阿三想又要排队，烦不过，就问：“你说胃疼叫我去看消化科，如果头疼看脑外科，骨头痛看骨科，这点医疗常识我也有的，那你们西内科医生干什么呢?”眼镜儿医生说现在分科分得细了，为病人好嘛。大头阿三忍着痛说：“如果我头痛，同时胃也痛、胸也闷，难道叫我一记头挂三只号子去看三个科不成?”

这真是“头痛医头，脚痛医脚”。

# 医学观摩

医院来了一群老外实习生，来作医学观摩。

冬病夏治正是中医特色，在背脊上按不同疾病找准对应的穴位，拿捏有度，贴上6枚自制小黑丸，最后“啪”地贴上6张四方膏药。隔7～1 0天再来贴一回，一共三趟，接下来就等到冬至再贴了。外国佬儿听说这样就能治鼻炎、肺炎和哮喘什么的，看了真当稀奇，一边观摩一边记笔记，还拍照片。

这天来了一位巧笑倩兮的摩登女郎患者，见有10多位洋人围观，红颜不悦，明眸一闪，对坐堂医生悄声耳语了一下。尽管香风熏得几分醉，但坐堂医生仍面有难色，意思是外国佬儿交了钱的，如果……

僵持不下，摩登女郎拿了块纱巾盖到白皙的背上，老外以为用了什么新疗法，举起相机猛拍，女郎想想这帮家伙在自己国家蛮注重人家隐私的，到中国怎么就乱来了呢，终于恶狠狠来了一句洋骂：SHIT!

# 养生迷宫

一家生产肿瘤辅助药的知名药厂牵头主办的健康论坛，来的都是大伯大妈，台上一圈专家，匆匆说完两句话就开始义诊。

大伯大妈呼拉围住救命医生，医生翻翻病历，看看脸色，马上娴熟地拿出两套方子，一套是“处方”，另一套叫“咨询方”，“处方”上开的是照病历上原来的治疗方案进行，而把肿瘤辅助药开在“咨询方”上。一开就是三个疗程以上，算算要3万多元。

医生很贴心地告诉大伯大妈们，回去想想好，毕竟要一大笔钱，但效果是没有二话的，是肿瘤康复最好的药，没癌还可以防癌，子女孝顺的话叫他们出钞票嘛。大伯大妈们像被催了眠，都连连点头称是，那么到哪里拿药呢?“喏，出门左转再右转，穿条马路转个弯就到了，在可的超市旁边的综合楼二楼，要记牢噢。”医生好心送他们出门，生怕他们晕头转向，悲天悯人地指出了一条康庄大道。

# 孤独症

建宁从河南来杭州打工半年了，想煞老婆和儿子。老婆大热天带了3岁半的小子从老家赶出来看他。小子认得几个字，会数1到100，在老家是奶奶的掌中宝，但有一大毛病，不喜欢开口，不和小朋友玩，不理会大人。

都说杭州医生高明，建宁就带儿子进了一家市级医院。医生是个女的，蛮和善的，当场做了一个智力测试，要建宁付100元钱给她就可以了，明天来看结果，如果到窗口付的话要150元。建宁想女医生知道民工赚钱不容易，千恩万谢地回去了。

第二天一去，就听到不幸的消息，说他儿子得了孤独症，医生推荐他买78元一盒的保健品，从桌子底下拿出两盒，说如果不要发票，便宜到70元，买两盒先吃吃看。

建宁两口子愁眉苦脸地买了药，好好的小子，咋就得了怪病呢?这个药，要吃多少盒呢?他责怪老婆没带好孩子，老婆又急又伤心，赌气跑回老家。建宁恍惚中连出两箱次品，被工厂开除了。一周后，建宁带儿子去女医生那里复诊，人已不在，听说因为在诊室私自配药被调离了。建宁呆在那里，愤怒地想：家里弄得七零八落，向谁去喊冤?这样下去，我也要被弄出孤独症来了!

# 终于上手了

奥运会期间，小芳休了一个年假，到门诊手术，动一个乳腺纤维瘤，因是小手术，没有找熟人。到手术室，医生很年轻，态度也很好，不托熟人又何妨?但小芳躺在床上心里到底有些发慌，到底是动刀子的，万一……

局麻后，医生开始动手动刀，一边安慰小芳别怕别怕，手术不大，取出来的异物不大，马上缝合就好了。但小芳分明感到他的手在颤抖，大概是小芳太紧张了，传染给他了吧。

手术时间不到一刻钟，回家不到两小时，血肿疼痛非常厉害，再去看门诊。门诊医生说，因为纤维瘤比较深，内层没有缝合，一直血肿。于是小芳再吃了一遍苦。

托了熟人去打听，到医院理论，才知道给小芳上手的，是从小医院来的实习医生，实习医生扣了当月奖金，但听说他愤愤不平，振振有辞地辩解说：“总得有人做试验品!”

# 你急我不急

“砰!”星期天下午3点半，阿德哥在一家商店玻璃门上重重地撞了一记，眉头上裂开一大口子，鲜血直流。撞大运了!来不及买彩票，他便急急赶往一家大医院，看到堂皇的就诊楼，懊恼的心好像也得着了安慰。

“辰光过了，不挂号了。”挂号处的人头也不抬。“四点还不到，我还流着血，为什么不挂号了?”“我们两点半就不挂号了。”“我很远赶过来，还流着血，总得给我处理一下吧!”“那你自己找医生去。”阿德哥就昏沉沉自己去找医生，又被人拦住，说去分诊台问。到了分诊台，一位40岁左右的妇女在整理一些票据。“请帮我问问医生，能否给我看看?”沉默。“请帮我问问医生，能否给我看看?”阿德哥耐性够好的。沉默。“你能帮我问问医生有辰光给我看吗?”老实人也有脾气的啊。“你喊什么?你等着。”中年妇女终于开口了。理好票据，关上电脑。中年妇女终于去问医生了。终于答复“医生让你去挂号”。挂了急诊，但还得等，因为只有一个医生看门诊。

时间一分一秒地过去……阿德哥终于理解了爱因斯坦的相对论——在医院等待的时间是最长的。当他走出医院，看了看表，已经晚上6点20分了。

# 小屁孩的一生

SU有一只血统高贵的斑点狗“屁屁”，体型流畅，毛色黑白相间，模子蛮大的，据说可以做猎狗。SU花了1000元配种费，找了门当户对的另一半。“屁屁”相亲、结婚、洞房，直至生子，半年内一气呵成，可比主人快多了，SU到现在还是钻石王老五一个呢。

“屁屁”的儿子自然叫“小屁孩”。这小屁孩还特金贵，喝牛奶要过敏，喝40℃稀粥没事情，冷粥一喝就吐，弄得像小王子一样。有一天，小屁孩突然不思饮食，脾气暴躁，到后来恹恹地躺在地板上，站都站不起来。

SU赶紧给医院老同学打电话，打的奔将过去。此为宠物医院耶?非也，堂堂正正给人类看病的二甲医院。同学知道SU的脾气，量体温，开方子，配药，挂盐水，凡是1岁的孩子怎么来，他就怎么一丝不苟地给狗治，完全给了小屁孩以“人权”待遇。呜呼哀哉，没出三天，小屁孩还是停止了呼吸。SU悲痛之余，又给老同学打电话，老同学说：“这事没法办，我这儿太平间收存死人还忙不过来呢……要不，去公墓问问?”

# 疑似吸毒病人

国庆长假，好戏连台。章大伯住在西湖边的医院里惹得心痒痒，眼饥肚不饥，身定心不定。特别是听说《旷世墨宝——浙江馆藏唐宋元明书画珍品大展》在西湖美术馆举办，作为书画虫儿，挠拨得他眼皮都一跳一跳的。但是医生说治疗还要一星期。

上午医生巡检，一瓶盐水挂上之后，章大伯佯装散步，一散就散到了5公里外的画展现场(当然是打的)。

他戴起老花镜儿，把鼻尖凑得毛近，盯着那些名画，兴奋得汗都沁出来了。他忘乎所以地捋起袖子，手臂皮下埋着一支静脉置管(挂盐水和补充营养液用的)露馅啦。旁边的姑娘儿，以为此人不是吸毒者就是艾滋病，马上闪得老远。章大伯苦笑一声，唉啦!一个戴着值班袖章的麻杆儿慢慢踱了过来，章大伯一看形势不妙，以鬼子出逃的速度迅速打的奔将去也!

# 睡错床

贵子腆着个大肚子进产房了，老公阿黄左手一个接生包，右手一碗鸡汤侍候到“闲人免进”牌前。护士一努嘴：“门外候着去，快的话一两小时，慢的话一两天。”

阿黄退到门口一看，一排“黑漆板凳”(husband)蹲着，有的抽着烟，有的盯着报纸不知在看什么，有的谈空天。一位胡子拉茬的男人说：“我已经熬了一通宵了，老婆还没有生。要不是丈母娘逼着，我早就逃掉了!现在的女人家真作，不光每次产前检查都要老公陪，还要陪伴分娩，说也要叫我尝尝生伢儿的痛苦味道。丈母娘说，换尿布片和泡奶粉的生活叫我早早操练起来，这真是阴阳颠倒!”阿黄脖子一紧，苦日子就在眼面前，如果贵子也要生10多个小时，难道我就像呆头鹅一样在门口立10个小时?

……

贵子腆着个大肚子进病房了，肚皮痛了五六个小时，才开了二指，医生叫她歇歇力。只见护士长扯着一个大男人的耳朵，说：“快醒醒，你睡错床了!”贵子定睛一瞧，气得面色铁青——阿黄躺在床上睡得好香，哈拉子流得老长，正做着抱儿子的美梦呢。

# 迷魂阵

老朱年轻时在地质队工作，风餐露宿，吃不好吃不净，落下个肝区疼痛的毛病，戴“老乙肝”帽子已10多年。老婆心疼他，见最近疼得厉害，催他去大医院体检。老朱一偷懒，去了离家不远的区级医院，排队挂号抽血，七荤八素地忙了一上午。过三天去拿化验单，好心的医生说，换家大医院看看吧，好像是肝硬化。

这回是老婆全陪，但是区医院验出来的指标大医院不认账，一切从头再来。花了200多元检验费不说，一周后权威医生一句话：到肝病专科医院去看，要抓紧!又让化验指标成了废纸一堆。

老朱就像进了迷魂阵任人摆布，累得脚底踩棉絮，脸上是一层“防冷涂的蜡”。专科医生察言观色，说赶紧去办住院手续吧。等老婆付住院押金的时候，他身子突然瘫软下去，不省人事——已重度肝昏迷危及生命!

# 阿根伯的伟哥之旅

伟哥开禁了，原来要泌尿科主治医生才能开方子，现在哪个医生都好开了．凭方子到药店购买。阿根伯从报纸上看到这个好消息，拿出100元私房钱换回一小粒“蓝色药丸”，心想过生日那天，让老太婆大吃一惊。吃完生日蛋糕，老太婆心满意足上床继续看每天吊牢的电视连续剧《中国式离婚》。

阿根伯用檀香皂汏了一个香喷喷的浴，咽下“蓝色小精灵”，急急忙忙钻进被窝——不知道物理反应快不快?阿根伯不停地掀开棉被往下瞄，等得心咚咚跳，老太婆说：“今朝介兴奋咋啦，没有足球，不要跟我抢频道。”

等到《中国式离婚》放完，阿根伯觉得下面还是涛声依旧，不禁急了起来，抢过遥控板一阵乱按。老太婆终于忍不住熟睡过去，阿根伯一直在跟“微软”作战。唉，这颗药莫不是过期船票，赶不上趟了?

丘比特耳语：伟哥是真伟哥，可爱情不是物理反应，它需要电闪雷鸣磨擦出化学反应，阿根伯，还是多跟拜伦学几首肉麻的爱情诗吧。

# 名医经纪人

黄老有一顶国家级名老中医的头衔，金秋时节，全国各地飞来的会议邀请信多得他数不过来。

老早有个徒弟四眼儿，现在弃医从商，在社会上厮混多年，据说有闲也有钱，愿意帮黄老打理各到各处的邀请函。就像一个名角儿有经纪人打理钱财一样，四眼儿也负责谈判、讨价还价、购买往返机票等杂务。

黄老乐得清静，专心准备论文提纲便是，但有些过意不去。四眼儿拍拍胸脯：“老师您见外了，我义务帮您，心情愉快胜过一切。”

前天黄老去成都，却气得血压升高，原来学术会议上碰到一位老同学，亲眼见到老同学笑纳3000元讲课费，自己职称高，威望高，四眼儿却对他说只有1000元补贴。经纪人一家伙就吞下2000元，怪不得他“心情愉快胜过一切”呢。

# 院长病了

“院长肚皮痛!”这成了这家二甲医院不胫而走的重大新闻。凡是相关科室副高以上职称的临床医生都被院长秘书紧急召到了院办。

李博士美国留学多年，老周是全科医生，郭老是国家级名老中医，邱姐是“胃癌治疗一只鼎”，刚拿了科技进步三等奖……经过众人一番谨慎地望闻问切，会诊结果是：病因不详，挂盐水留观。

捱到后半夜，院长痛了24小时，实在顾不了风度，轻度昏迷。一位外地来的实习医生捅破窗户纸：“快开刀，这是急性阑尾炎!”跌煞绊倒上麻药，一拉开肚子，李博士脸色大变：阑尾炎已急转成为腹膜炎。

半个月后，卫生局长来看视院长，宽慰道：“老兄，你还算好的，一年前我的阑尾炎生生变成了肠穿孔!”

# 来一斤田七

老公最近不舒服，老到医院报到，七七八八的检查做得蛮多，胃镜照过，血验过，心电图也做过，除了胃有一点点溃疡，别无大碍。

他的老父亲是个民间土郎中，支招说田七可以活血化瘀，久治不愈的老胃病可以吃吃看。老公一听心动了，跟老婆说买一点吃吃看吧。

老婆疼老公，一向也大方，买冬枣论箱买，买品牌到专卖店卡一刷就是几千元。心想，是补药的话多补总不错，干脆下猛药，买它个一斤!反正也花不了多少钱。

到药房去配，医生一听晕了：田七是论克买的，1元7角5分1克，3克一小包，哪有论斤买的——又不是农贸市场买萝卜番薯。

# 隐身人

开小车，住排屋，泌尿科主任吴医生最近发了。光靠那点奖金，门都没有!他是怎么发的呢?这个秘密持续了很久。

“吴医生，老病号来了，是陈小姐。”护工白阿姨探头向吴医生报告。

陈小姐就是吴医生“发财的秘密”。

证据如此确凿，毛病出在哪里呢?

白阿姨是医院聘请的行风监督员。

老话没错：若要人不知，除非己莫为。

# 碰到一个黑脸的

# 滋润人参

“冬令进补春来打虎”的道理大家都晓得，有病的调补，无病的强身，所以现在医院里会做膏方的老药工、老中医俏得不得了，越老越红。

中内科章伯年过七旬，人称“赛华佗”，红光满面，须发白眉，每年冬天都吃正官庄的高丽参，自己就是冬令滋补的活广告。名气大了，病人看不光，推不出去的苦。首长专车还经常候在后门口，要他去深海侯门问诊，是首长家的座上宾，连带着帮首长家的首长一并“望闻问切”了。

院长羡慕得不得了，有一回为了造新住院大楼的事，搞来搞去搞不定，特意要章伯捎带上他，面觐首长。此事后来玉成，院长一高兴，在全院大会上宣布：保留章伯终身岗位!

同事们都说，这句话语着实比正官庄的高丽参补多了哩!

# 此艾非彼艾

针灸拔火罐，医院里已经见怪不惊了。李大伯颈椎酸疼，人精瘦，医生找准穴位插下一根根银针，浑身经络都通了，很舒服的。但见胖乎乎的医生点燃了一蓬像烟叶一样的干草，火苗一闪一闪的，李大伯说：“作啥用的?”

“等歇用艾草给你拔火罐。”

“哎哟!”李大伯带着一身银针逃下病床，“那要在我身上烫出伤疤的，而且出血部位要染上艾滋病的。千万千万别……”

胖医生拿着一蓬艾草暗自发笑：咳，此艾非彼艾，哪有见血死!

# 生辰之烦

李小姐近来每天都懊恼，未来公婆说明年两头无春，是“寡妇年”，结婚不吉利，一定要争取在春节前完婚。

这样就要赶在年前办喜酒，从去年11月份开始就准备，最近突然遇到麻烦了。原来李小姐的未来公婆不知听了谁的话，说是一定要给小两口排排八字。而今新法接生，父母都不知道儿女出生的确切时辰。未来公公灵机一动，特意赶到医院产科去查准媳妇的生辰八字，怕医生不肯，还编个造话说想寻找失散25年的外甥女儿。女医生不明底细，就查出来告诉他了。拿着李小姐的生辰八字，去找神算子一合计，坏了!与宝贝儿子命相不合，不宜结婚!

新房、酒席、婚纱照都一一安排了，突然说不合适结婚，苦了小两口。李小姐想：早知道宜不宜婚，不是凭感情，而是要看双方的出生时辰，那妇产科兼营婚配，变成婚姻介绍所算了!

# 都是“本”的

今朝年三十，骆医生家鸡鸭满堂、腊肉串串、米酒飘香，叫上亲亲眷眷包一张圆台面，晚上团团圆圆守岁，比上饭店乐胃多了。

骆医生家的年货可是实实在在“本”的，连“二本”都没有。她是肝病专家，每年慕名来求医的病人莫佬佬，尤其是乡下来的，更是把骆医生当作女菩萨。现在红包不好随便送了，但农民就是想感恩，把养了一年的猪杀了，割下腿肉，腌了鱼干，捉几只爹娘养的本鸡本鸭儿，拎上自己舂的糯米年糕、老婆晒的番薯干、大缸的腌白菜，兴冲冲赶到骆医生府上。不收吧，农民心心念念的一片心意，怎忍拒绝?

所以还在喝腊八粥的时候，骆医生家客厅已变成鸡舍鸭圈，楼下“阿珍农庄”的老板娘找上门来了：

“病人送给你的，肯定是正宗本塘的。我们每天来收购，给你留下足够的年货，帮你弄清爽，其余卖给我们做招牌菜，长期合作!”

于是皆大欢喜。

# 医生也“进补”

春节七天湿嗒嗒的，到哪里游荡都不尽兴。小马医生都学会搓麻将了，吃吃喝喝之余，实在无聊。

昨天，同科室的大马医生叫她去跳芭蕾。小马暗笑，凭你马大嫂介大的身坯，还踮起脚尖跳小天鹅?大马医生一拍大脚胖：“小马啊，像你这种麻杆儿身材，风一吹就要倒的，练芭蕾最好了。我们老师说的，跳芭蕾能协调肌肉和脂肪的分配，使你的身材更匀称，气质更高雅。”

练功房里跳芭蕾的身材，奇出怪样，但她们都一丝不苟地盯着大镜子，好像镜子里头就是自己的未来。大马和小马，一个气喘吁吁地吸进大肚腩，一个挺胸昂首做扩胸运动。一个钟头后，都觉得自己轻飘飘了，好似吃了一颗神仙丸。

# 骂是爱

因为病痛，重症病人脾气都不大好，家里人都宽容地成为受气包——相当于帮他排毒，也好比哄一个婴儿，别太计较了。

但病人大多喜欢讨医生骂，把唾沫飞溅当作天降甘霖，当作高级桑拿，几天不骂还想得慌。

吃到第三个月时，老周脸肿起来了。药吃得越多，痛得越厉害。老婆煞煞剋剋骂他一顿，碰上李鬼啦!毫稍去药监局举报。一查还真是假的，根本没有这个药厂!检查人员说，这个假药可能含有精神麻醉类药物，短期能缓解，长期要中毒。老婆吓老周：弄得不好，还要致残致死呢。

老周吓坏了，跟执法人员讨红袖套戴，做啥?

到邻舍隔壁作科普宣传，像扫除法盲一样扫除药盲!

# 无痛拔牙

小汪学徒满师，要上岗了。

师傅说：“先把麻药注射到坏牙里，等一支烟的工夫，病人舌头大了，再拔。”

小汪一板一眼地按照操作流程来，他不吸烟，所以“一支烟的工夫”太难掌握。没等他想利索，病人已经呲牙咧嘴地躺在牙椅上。他只好戴上口罩，煞有介事地对病人说：“张口。”

找准位置推麻药，手都抖了。

抖抖地退到操作间，小汪偷偷点上一支烟，搁在烟灰缸上，等烟头快烧到海绵头了，探出头问：“舌头大了没?”

“大了，大了。”那病人搭着舌头猛点头。

那就拔吧!

病人发出凄厉的叫声——妈呀，痛死啦!

师傅教训徒弟：“烟吸着烧得快，点着不吸时间过得慢，你超时了，麻劲儿早过啦。你这样拔法，还不如相声里人家江湖郎中，点个炮仗拔牙来得痛快呢! ”

# 发煤炉

# 油水太多

白领们每天小车开进开出，电梯乘上乘下，每天卡路里的消耗量极少。公司条件好，油水多，这是公认的，体现在食堂师傅身上，烧菜用油就当撒撒水。

今天中午食堂的荤菜有油爆虾、红烧肉、肉饼蒸蛋，但窗口门可罗雀；而素三鲜、炒青菜的窗口，打菜师傅却忙得满头大汗，体形奇出怪样的员工争先恐后要油水少的。

原来昨天刚刚下发了体检表，检出高血脂、高血压……“三高”人群一箩筐!

# 孵空调

谁没事往医院跑啊?可赵大妈入夏以来，三个月如一日，每天到医院休闲吧报到。一瓶矿泉水、一条毛巾、一本病历卡，一坐就是半天，原来是到医院孵空调来了。

白天子女上班，自己有高血压，待在医院既纳凉又放心，所以赵大妈每次总把病历卡放在身边，9点多过来，带一碗早上烧好的中饭和菜蔬，“两耳不闻身边事，一心只顾乘风凉”，直到毛5点钟回家。这几天，她干脆把给孙女儿打的毛衣也带过来了。

唉，赵大妈呀，赵大妈!医院休闲吧主要是为了病人候诊的，各种病菌都有，你千万要注意卫生，中饭就不要在那儿将就了，等真染么病，哪儿有介舒服啊!

# 瘦身还是伤身

周大伯懂得要老来俏，等待黄昏恋。药店里有个坐堂医生向他推荐了甩脂机，说是“剧烈的振动，疯狂燃烧脂肪，在不经意间圆塑身之梦”，于是花5000多元买了一台。

刚开始一周，先是肚皮发痒发红，后来是头晕，大伯都坚持下来了，想想总能先苦后甜，抱得美人归。

每天一早，周大伯面对魔鬼身材指日可待的诱惑，忍受头晕目眩的痛苦，用坐堂医生的魔鬼语言激励自己：全方位脂肪运动，运动五脏六腑，燃烧血管和器官壁中的脂肪，促进血液循环，预防和辅助治疗腰肌劳损、高血压、脂肪肝、糖尿病、冠心病、打鼾等肥胖并发症……

最近大伯在菜场听到“甩脂机”可致身体损伤和减肥无依据的消息后，心生恐慌，浑身浑脑痛，没想到啤酒肚照旧，自己还成为“健康实验品”!他气得去找坐堂医生算账，那个胖女人却早已脚底抹油，溜了。

# 另类

从医学理论上说，中暑是指在高温环境下人体体温调节功能紊乱而引起的急病。但眼下，除了高温、烈日暴晒外，工作压力过大、空调房间呆的时间过长、睡眠不足、过度疲劳等也都是引起中暑的高危因素。

王先生所供职的IT公司，整个夏天冷气开得十足。在“冻感之楼”呆了一周，王先生就面色潮红、脉搏细弱了，猛灌白开水也无用，反而体温升高到38℃以上。跌跌撞撞去看中暑门诊，与一帮在工地上讨生活的农民兄弟在候诊室汇合，黑脸的农民兄弟问：“细胳膊兄弟，啥时候我们轮换一下工作，说不定咱俩的毛病都好了!”

# 如此坐堂

呼吸科毛医生烟瘾大，加上最近刚离婚，心情郁闷，看门诊的时候也熬不牢要抽两支；内分泌科的阿花生了伢儿身材像吹了气一样蹭蹭往边上鼓，偏偏每周二的肥胖门诊要她去坐堂；已过知命之年的老周眼见毛发渐蔬，最近学了种头发的新技术，主持脱发门诊……

旁观者曰：这三个医生，自家镜子照照，病人逃光是肯定的，医生管委 会还是要求他们先把自家毛病看看好，否则知趣点，换岗走人!
