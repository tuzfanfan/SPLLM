# 办公室攻略：中国人不可不知的123个职场陷阱

## 概述

曹荣所著的职场生存手册，归纳了职场中最危险且最易遇到的8大类123个陷阱。全书通过大量真实案例，从领导关系、同事关系、下属管理、心态调整、人际交往、细节注意、言语分寸、自我认知等八个维度，全方位解析职场中的风险点。

## 核心内容

| 陷阱类别 | 陷阱数量 | 核心警示 |
|---------|--------|--------|
| 领导关系 | 约20个 | 不把领导当回事、功高盖主、越级汇报 |
| 同事关系 | 约15个 | 轻信同事、抢占功劳、办公室恋情 |
| 下属管理 | 约10个 | 事必躬亲、独享功劳、轻易许诺 |
| 心态问题 | 约15个 | 自命不凡、好高骛远、频繁跳槽 |
| 人际交往 | 约15个 | 亮出底牌、陷于流言、不懂变通 |
| 细节问题 | 约15个 | 漠视规章、着装不当、占小便宜 |
| 言语分寸 | 约15个 | 泄露秘密、搬弄是非、乱发牢骚 |
| 自我认知 | 约18个 | 老好人、耍小聪明、缺乏法律意识 |

## 关键洞察

1. 职场陷阱的核心规律：大多数陷阱不是来自恶意设计，而是来自对职场规则的无知或忽视。2. '摆不正自己的位置'是最常见也最致命的职场陷阱——在错误的时间、错误的场合做了错误的事。3. 书中强调'明规则'的价值大于'潜规则'——真正的职业成功来自在明规则框架下的成就。4. 职场如战场，但战争的目的不是消灭敌人，而是保护自己、发展自己。
