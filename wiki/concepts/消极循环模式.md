# 消极循环模式

## 定义

消极循环模式是指精力过剩（活泼好动）孩子所处的负向发展循环：孩子闯祸 -> 被责备/忽视 -> "我不是好孩子" -> 更加叛逆 -> 表现更差 -> 遭到更多惩罚。这种循环一旦建立，会不断恶化。

## 核心要点

1. **负向反馈链**: "这孩子真难伺候" -> 责备、忽视 -> "没人喜欢我" -> 不断尖叫 -> 更被讨厌
2. **精力过剩的误读**: 活泼好动的孩子被贴上"难以管教"的标签，但其本质是精力充沛、好奇心强
3. **自信心的侵蚀**: 长期被责备的孩子耳边总是"不许""住手"，自信心严重下降
4. **家长情绪的恶化**: 孩子总闯祸导致家长越来越容易发脾气，形成双向恶化
5. **不等于失败**: 孩子不听话不代表家长不称职，只是养育面临了更大的挑战

## 应用场景

- 识别和打破消极的家庭互动模式
- 理解"问题儿童"的行为根源
- 家长自我情绪管理
- 教育方式的反思与调整
