# 前额皮质

## 定义

> **前额皮质（Prefrontal Cortex）** 即前额叶皮层，是大脑额叶最前方的区域，负责高级认知功能，包括理性决策、冲动控制、长期规划和意志力。前额皮质是自控力的神经基础。

## 核心原理

### 功能分区

| 区域 | 功能 | 对应意志力面向 |
|------|------|------|
| 左侧前额叶 | 推动行动 | [[我要做/我不要/我想要]]中的"我要做" |
| 右侧前额叶下方 | 抑制冲动 | "我不要" |
| 中部前额叶 | 目标导向 | "我想要" |

### 前额皮质的功能

| 功能 | 说明 |
|------|------|
| **理性决策** | 权衡利弊，做出理性选择 |
| **冲动控制** | 抑制不适当的冲动和行为 |
| **长期规划** | 设定和追求长期目标 |
| **工作记忆** | 保持和操作信息 |
| **注意力控制** | 集中和转移注意力 |
| **情绪调节** | 调节情绪反应 |

### 前额皮质与压力

| 压力水平 | 前额皮质状态 | 行为影响 |
|------|------|------|
| **低压力** | 正常功能 | 良好的自控力 |
| **适度压力** | 功能增强 | 短期自控力提升 |
| **慢性压力** | 功能萎缩 | 自控力下降 |
| **极端压力** | 功能关闭 | 完全失去自控 |

### 前额皮质的发展

| 阶段 | 特征 |
|------|------|
| **儿童期** | 快速发展，但功能不成熟 |
| **青少年期** | 仍在发育，冲动控制弱 |
| **成年期** | 成熟，约25岁完成发育 |
| **老年期** | 逐渐衰退，但经验可以补偿 |
