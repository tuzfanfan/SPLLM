# 可灵AI使用指南 — 视频生成

## 概述

可灵（Kling）是由快手大模型团队自研打造的视频生成大模型，支持文生视频、图生视频、视频续写、运镜控制、首尾帧等多个能力。

---

## 一、基础功能

### 1.1 文生视频

输入一段文字，可灵大模型根据文本表达生成5s或10s视频。

**支持模式**：标准模式（速度快）、高品质模式（质量佳）
**支持画幅**：16:9、9:16、1:1

#### 提示词构成要素

```
提示词 = 主体 + 主体运动 + 场景 + 场景描述 + 镜头语言 + 光影 + 氛围
```

| 要素 | 说明 |
|------|------|
| 主体 | 画面中的主要人物、动物、物体等 |
| 主体运动 | 对主体运动状态的描述，运动状态不宜过于复杂 |
| 场景 | 主体所处的环境，包括前景、背景等 |
| 场景描述 | 对主体所处环境的细节描述 |
| 镜头语言 | 超大远景、背景虚化、特写、长焦镜头、航拍、景深等 |
| 光影 | 氛围光照、晨光、夕阳、丁达尔效应等 |
| 氛围 | 热闹的场景、电影级调色、温馨美好等 |

#### 文生视频使用小技巧

- 尽量使用简单词语和句子结构
- 画面内容尽可能简单，可以在5s到10s内完成
- 用"东方意境、中国、亚洲"等词语更容易生成中国风
- 当前视频大模型对数字还不敏感
- 分屏场景可以使用prompt："4个机位，春夏秋冬"
- 现阶段较难生成复杂的物理运动（球类弹跳、高空抛物等）

### 1.2 图生视频

输入一张图片（可加文本描述），生成5s或10s视频。

#### 提示词公式
```
提示词 = 主体 + 运动，背景 + 运动……
```

#### 图生视频Tips

- 尽量使用简单词语和句子结构
- 运动符合物理规律，尽量用图片中可能发生的运动描述
- 描述与图片相差较大，可能会引起镜头切换
- 现阶段较难生成复杂的物理运动

### 1.3 多图参考

可灵AI 1.6模型支持上传最多四张参考图片，生成创意视频。

#### 多主体提示词公式

**单主体**：
```
提示词 = 单主体（主体细节描述）+ 主体运动 + 背景 + 其他信息
```

**多主体**：
```
提示词 = 多主体（每个主体的细节描述）+ 主体间互动 + 背景 + 其他信息
```

#### 多图参考适合的场景

- 前景角色及动作 + 背景环境
- 角色 + 服装 + 产品的展示
- 多角色「同框」互动
- 动漫二创

## 二、进阶功能

### 2.1 标准模式与高品质模式

| 特性 | 标准模式 | 高品质模式 |
|------|----------|------------|
| 生成速度 | 更快 | 较慢 |
| 推理成本 | 更低 | 更高 |
| 画面质量 | 色调柔和，动物更亲切 | 细节更丰富，构图与色调氛围更高级 |
| 擅长场景 | 人像、动物、动态幅度较大的场景 | 人像、动物、建筑、风景类等精细视频创作 |

### 2.2 运镜控制

| 运镜类型 | 说明 |
|----------|------|
| 推进/拉远 | 镜头向主体推进或远离主体 |
| 垂直摇镜 | 镜头在垂直方向上运动 |
| 旋转运镜 | 镜头围绕主体旋转拍摄 |
| 水平摇镜 | 镜头在水平方向上运动 |
| 大师运镜：左旋推进 | 组合运镜，向左旋转同时推进 |
| 大师运镜：右旋推进 | 组合运镜，向右旋转同时推进 |
| 大师运镜：推进上移 | 组合运镜，推进同时向上移动 |
| 大师运镜：下移拉远 | 组合运镜，向下移动同时拉远 |

### 2.3 首尾帧能力

上传两张图片分别作为视频的起始帧和结束帧，可灵AI自动生成两帧之间的过渡视频。

**Tips**：
- 尽量选择两张相同主题且近似的图
- 如果两张图片相差较大，可能会触发镜头切换

### 2.4 运动笔刷能力

在图片中通过"自动选区"或"涂抹"对某一个区域或主体进行选中，添加运动轨迹，支持6种主体和轨迹的同时设置。

**功能特点**：
- 动态笔刷：添加运动轨迹
- 静态笔刷：固定涂抹区域的像素点，避免运镜发生

**图像选区建议**：
- 单个动态笔刷只选中类别一致的单个物体
- 单个动态笔刷只画一个相互联通的区域
- 静态笔刷可以选中多个彼此不联通的区域

**运动轨迹建议**：
- 轨迹曲线的方向和长度都会起作用
- 选中物体的中间运动过程会严格按照绘制的轨迹移动

### 2.5 对口型

上传本地配音/歌唱文件，或通过文本朗读功能在线生成配音，可灵AI让视频人物口型和音频完美同步。

**使用方法**：
1. 使用可灵AI生成包含完整人物面容的视频
2. 点击预览视频下的「对口型」
3. 上传本地配音/歌唱文件，或通过文本朗读功能在线生成配音
4. 可灵AI将自动匹配人物口型与音频

## 三、场景应用

- **影视创作**：辅助影视前期概念预览、分镜生成
- **广告生成**：快速生成广告创意视频素材
- **创意表达**：个人创意视频创作、艺术表达
- **老照片复活**：通过图生视频让静态照片动起来
- **动漫二创**：基于动漫素材进行二次创作
- **产品展示**：角色 + 服装 + 产品的创意展示

## 灵感值花费计算

```
灵感值总花费 = 画质基准灵感值 × 生成时长倍数 × 生成数量
```

| 参数 | 参数值 | 消耗灵感值计算规则 |
|------|--------|-------------------|
| 生成模式 | 标准画质 | 基准灵感值 20 |
| 生成模式 | 高品质画质 | 基准灵感值 35 |
| 生成时长 | 5秒 | × 1 倍 |
| 生成时长 | 10秒 | × 2 倍 |
| 生成数量 | 1-4条视频 | × 1-4 倍 |
