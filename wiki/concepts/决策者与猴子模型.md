# 决策者与猴子模型

## 定义

> **决策者与猴子模型（Rational Decision-Maker vs. Instant Gratification Monkey）** 是由Tim Urban提出的拖延心理模型。大脑中存在理性的"决策者"（位于前额叶皮层）和追求即时满足的"猴子"，当决策者失去控制时，猴子就会接管行为，导致拖延。

## 核心原理

### 三大角色

| 角色 | 功能 | 行为特征 |
|------|------|------|
| **决策者** | 理性规划、长期决策 | 设定目标、制定计划、执行任务 |
| **猴子** | 即时满足、逃避不适 | 追求快乐、逃避困难、分散注意力 |
| **恐慌怪兽** | 紧急唤醒 | 在截止日期临近时唤醒决策者 |

### 拖延过程

```
任务出现 → 决策者计划 → 猴子接管 → 即时满足活动 → 恐慌怪兽出现 → 疯狂赶工
```

| 阶段 | 决策者 | 猴子 | 结果 |
|------|------|------|------|
| **计划期** | 制定计划 | 旁观 | 理性决策 |
| **执行期** | 被猴子赶走 | 接管控制 | 拖延开始 |
| **恐慌期** | 被恐慌怪兽唤醒 | 逃走 | 疯狂赶工 |
| **后悔期** | 反思 | 暂时安静 | 下次继续拖延 |

### 神经科学基础

| 脑区 | 角色 | 功能 |
|------|------|------|
| 前额叶皮层 | 决策者 | 理性思维、冲动控制、长期规划 |
| 边缘系统 | 猴子 | 情绪处理、奖赏寻求、即时满足 |
| 杏仁核 | 恐慌怪兽 | 恐惧反应、紧急唤醒 |

## 应对策略

| 策略 | 说明 |
|------|------|
| **缩小任务** | 让任务看起来不那么可怕，猴子不会太抗拒 |
| **设定小截止日期** | 提前唤醒恐慌怪兽 |
| **建立习惯** | 减少决策者的参与，降低猴子接管的机会 |
| **环境设计** | 减少猴子可以玩的"玩具"（分心物） |
