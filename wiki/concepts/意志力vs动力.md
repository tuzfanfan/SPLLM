# 意志力vs动力

## 定义

> **意志力vs动力（Willpower vs. Motivation）** 是斯蒂芬-盖斯在《微习惯》中提出的核心洞察：动力（Motivation）是不可靠的，因为它受情绪、情境和能量水平影响；而意志力（Willpower）虽然有限但可训练。微习惯策略的核心是不依赖动力，也几乎不消耗意志力。

## 核心原理

### 动力的特征

| 特征 | 说明 |
|------|------|
| **不可靠** | 受情绪、情境、能量影响 |
| **波动大** | 一天之内可能剧烈波动 |
| **递减效应** | 初始动力强，但很快衰减 |
| **依赖外部刺激** | 需要外部激励来维持 |

### 意志力的特征

| 特征 | 说明 |
|------|------|
| **有限资源** | 每天的意志力是有限的 |
| **可消耗** | 每次使用都会消耗 |
| **可恢复** | 休息和睡眠可以恢复 |
| **可训练** | 通过练习可以增强 |

### 对比分析

| 维度 | 动力 | 意志力 |
|------|------|------|
| **可靠性** | 低 | 中-高 |
| **可控性** | 低 | 中 |
| **消耗性** | 不消耗但不可靠 | 消耗但可恢复 |
| **可训练性** | 不可训练 | 可训练 |
| **适用场景** | 启动新行为 | 维持行为 |

### 微习惯的策略

```
传统策略：依赖动力启动 → 动力不足 → 失败
微习惯策略：不依赖动力，几乎不消耗意志力 → 持续执行 → 习惯形成
```

| 策略 | 说明 |
|------|------|
| **降低门槛** | 使行动不需要动力就能启动 |
| **减少意志力消耗** | 行动小到几乎不消耗意志力 |
| [[正反馈循环]] | 完成小行动产生动力，形成良性循环 |
