# 大唐这二百九十年2：天皇天后 - 来源摘要

## 概述

《大唐这二百九十年2：天皇天后》是"吃青菜的蜗牛"所著唐朝历史通俗读物第二册，聚焦于唐高宗和武则天时期的历史。全书讲述了武则天从才人到女皇的权力之路，以及这一时期唐朝政治、社会和文化的深刻变迁。

## 核心内容

### 核心历史事件

| 事件 | 内容 |
|------|------|
| 武则天入宫 | 从才人到皇后的晋升之路 |
| 二圣临朝 | 武则天与唐高宗并称"二圣" |
| 高宗去世 | 武则天掌握实际权力 |
| 建立周朝 | 武则天称帝，改国号为周 |
| 神龙政变 | 武则天被迫退位 |

### 武则天的权力之路

- **从才人到皇后**：政治智慧和手腕的展现
- **二圣临朝**：与高宗共同执政
- **称帝改周**：中国历史上唯一的女皇帝
- **治国成就**：科举制度的发展、边疆的巩固
- **历史评价**：千年以来对武则天的争议

## 关键洞察

1. **女性权力的巅峰**：武则天是中国历史上女性权力的最高代表
2. **权力斗争的残酷性**：武则天上位过程中伴随大量的政治清洗
3. **制度的延续性**：武则天时期唐朝的基本制度得以延续
4. **历史的争议性**：对武则天的评价至今仍有很大分歧
5. **"天皇天后"的含义**：反映了这一时期独特的权力格局
