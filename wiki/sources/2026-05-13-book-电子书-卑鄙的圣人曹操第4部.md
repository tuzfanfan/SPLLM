# 卑鄙的圣人：曹操（第4部）- 来源摘要

## 概述

《卑鄙的圣人：曹操》第4部由王晓磊著，聚焦建安元年（公元196年）前后的历史。本部核心事件是曹操"挟天子以令诸侯"——迎奉汉献帝建立许都，以及征讨豫州黄巾军、收留刘备、征讨张绣、兵败淯水、计杀吕布等重要战役。

## 核心内容

### 主要章节

| 章节 | 核心事件 |
|------|----------|
| 1-3 | 曹操决定迎奉天子，从黄巾军手中抢回豫州，连蒙带骗拐走皇帝 |
| 4-5 | 独揽大权，收留刘备，挟天子以令诸侯 |
| 6-7 | 征讨张绣，不战而胜；兵败淯水，害死曹昂和典韦 |
| 8-11 | 袁术称帝，借刀杀人之计，痛打刘表 |
| 12-16 | 兵政分权，祢衡击鼓骂曹，与袁绍决裂，击溃吕布 |

### 豫州黄巾之战

- 袁术扶植黄巾势力复归豫州，阻塞曹操西进和南下道路
- 黄巾首领黄邵夜袭曹营，被曹操识破设伏
- 于禁斩杀黄邵，乐进、曹昂三面夹击，黄巾军崩溃归降

### 关键人物表现

- **于禁**：斩杀黄邵立功，但被描写为争功心切之人
- **荀彧**：曹操首席谋士，主张迎奉天子
- **典韦**：贴身猛将，后在淯水之战中为保护曹操而死

## 关键洞察

1. **"挟天子"的战略远见**：曹操放弃攻打刘备、吕布，优先迎奉天子，体现了政治上的高瞻远瞩
2. **"借来用一用"的实用主义**：曹操对天子的态度不是忠诚，而是工具性的利用
3. **兵败淯水的代价**：宛城抢张绣婶婶导致反叛，典韦、曹昂、曹安民三人性命
4. **兵政分权的制度创新**：指定荀攸当军师，开创军事与政治分离的管理模式
