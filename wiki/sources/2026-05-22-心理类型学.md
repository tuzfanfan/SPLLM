# 心理类型学

**作者**: [[C.G.荣格]]（Carl Gustav Jung）

**译者**: 吴康、丁传林、赵善华

**出版社**: 华岳文艺出版社

**出版年份**: 1989年

**页码**: p1-p198（1个部分，可能不完整）

## 摘要

本书是荣格最重要的理论著作之一（原著德文版1921年出版），系统阐述了荣格的心理类型理论。书中提出了内倾/外倾两种基本态度类型和思维、情感、感觉、直觉四种基本心理功能，组合形成八种人格类型。本书以集体无意识为理论基石，反对弗洛伊德的泛性论，重新定义了力比多为普遍的生命力。荣格还深入探讨了象征在和解心理对立中的关键作用。

## 核心理论

### 1. 内倾/外倾两种基本态度类型
- **内倾型**：心理能量指向内部世界，关注主观体验和内在过程
- **外倾型**：心理能量指向外部世界，关注客观事物和外部环境

### 2. 四种基本心理功能
| 功能 | 核心特征 | 判断维度 |
|------|----------|----------|
| 思维 | 理性判断，追求逻辑和真理 | 理性功能 |
| 情感 | 价值判断，追求和谐与意义 | 理性功能 |
| 感觉 | 感知现实，关注具体感官体验 | 非理性功能 |
| 直觉 | 感知可能性，关注潜在模式 | 非理性功能 |

### 3. 八种人格类型
内倾/外倾 x 四种功能 = 八种类型：
- 内倾思维型、内倾情感型、内倾感觉型、内倾直觉型
- 外倾思维型、外倾情感型、外倾感觉型、外倾直觉型

### 4. 集体无意识理论基石
- [[集体无意识]]是心理类型理论的基础
- 原型（原始意象）影响个体的功能偏好和态度倾向
- 个性化过程涉及对[[优势功能]]和[[劣势功能]]的整合

### 5. 力比多的重新定义
- 反对[[弗洛伊德]]的泛性论
- 将力比多重新定义为普遍的生命力（精神能量）
- 力比多可以投向不同方向（内倾或外倾）

### 6. 象征理论
- 象征是和解心理对立的关键机制
- 通过象征，意识与无意识得以对话和整合
- 象征在梦、神话、艺术中普遍存在
