# 隐喻

## 定义

> **隐喻（Metaphor）** 不仅是修辞手法，更是人类思维和认知的基本方式。乔治·莱考夫和马克·约翰逊在《我们赖以生存的隐喻》中指出，隐喻通过将一个领域的结构映射到另一个领域，帮助我们理解抽象概念。

## 核心原理

### 隐喻不是装饰，是思维本身

传统观点：隐喻是语言装饰，可有可无
**莱考夫观点**：隐喻是思维的基本结构，决定了我们如何理解和体验世界

### 概念映射（Conceptual Mapping）

```
源领域（具体） → 目标领域（抽象）
例如：旅程 → 爱情
- 爱情是旅程
- 我们走到了十字路口
- 我们的关系停滞不前
- 我们分道扬镳了
```

## 经典隐喻案例

| **抚养式政府** | 政府 = 养育者，公民 = 孩子 | 进步派 |

| **双塔是社会象征** | 大楼倒塌 = 美国承诺沉没 |
| **飞机 = 子弹** | 攻击 = 对身体/头部的打击 |

### 3. 税收隐喻

| 说法 | 隐喻 | 隐含意义 |
|------|------|----------|
| **税收缓解** | 税收 = 痛苦，减税 = 药物 | 税收是坏事 |

- 人生是一场旅程

- 他走得很远（成就很大）

## 隐喻与框架的关系

```
隐喻 → 激活框架 → 塑造认知 → 影响决策
```

**例子**：
- "税收缓解"这个隐喻 → 激活"税收是痛苦"框架 → 人们认为减税是好事
- "伟大社会"这个隐喻 → 激活"社会是成长体"框架 → 人们支持社会福利

## 政治中的隐喻战争

### 保守派隐喻
- **严父家庭**：政府是严父，公民是孩子
- **市场是竞技场**：优胜劣汰，政府不干预
- **自由是财产**：政府拿走 = 偷窃

### 进步派隐喻
- **抚养式家庭**：政府是养育者，公民是孩子
- **社会是共同体**：互相帮助，政府保障
- **自由是赋能**：政府帮助 = 实现自由

### 产品命名隐喻
- "云存储"：数据 = 天空中的云（无处不在、自由访问）
- "流媒体"：内容 = 水流（连续、自然流动）
- "防火墙"：网络 = 建筑物，威胁 = 火（需要防护墙）
