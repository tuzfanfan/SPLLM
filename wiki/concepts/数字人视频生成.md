# 数字人视频生成

## 定义

数字人视频生成是指通过上传人物图片和音频素材，利用AI模型生成具有口型同步、动作自然、情绪演绎的视频内容。[[OmniHuman 1.5]] 将传统"只能对口型的数字人"升级为"能走位、能演戏、镜头能运动"的**数字演员**，角色从固定站位和固定镜头中被解放出来。

## 核心特性

### 1. 理解音频语义
角色能做出与音频语义相关的动作。例如：
- 说到"吞下蓝药丸"，角色立即展示蓝药丸
- 说到"递一下象牙线"时，角色会回头，镜头对焦到身后角色

### 2. 角色走动 + 镜头运动
支持像使用视频生成模型一样控制画面：
- 控制角色走位（向前走、转身、停下等）
- 控制镜头运动（跟随、环绕、推进、拉远等）
- 控制背景元素和画面事件

### 3. 生动的情绪演绎
- 识别并演绎音频和台词中的情绪
- 对白场景具有更强的演技效果
- 支持情绪层次控制和微表情控制

### 4. 多人场景支持
- 可指定画面中某一角色说话
- 其他人物也有自然动态
- 支持选择"全部角色"一起说话（合唱等场景）

### 5. 多样风格和主体支持
- 真人照片效果最佳
- 卡通、动漫角色有良好泛化能力
- 支持动物等非人形象驱动（猫、狗、像素风角色等）

## 提示词核心原则

### 三大原则
1. **讲故事式自然语言**：把编写提示词当成讲故事，使用连贯自然的语言，减少孤立词汇堆砌
2. **只描述动态事件**：图片中已包含的静态特征（服装、首饰等）无需描述
3. **清晰、不矛盾、少否定**：使用具体而非抽象的描述，分步骤引导

### 推荐提示词结构
```
镜头运动 + 说话角色情绪 + 说话状态（说话/哭泣/唱歌/...）+ 具体动作 + （可选）背景事件/其他角色的动作
```

### 高级控制能力

| 能力 | 说明 | 示例 |
|------|------|------|
| 连续动作及走位 | 用"先""然后"描述动作顺序 | "男人先向前走，然后停下脚步双手叉腰说话" |
| 多角色动作控制 | 描述角色间互动 | "男孩追上女孩，女孩不耐烦地转身" |
| 镜头运动控制 | 精确控制镜头移动方式和节奏 | "镜头向右环绕，聚焦到男人正面" |
| 情绪层次控制 | 描述细腻的情绪变化 | "先是神情淡定，随后突然紧张惊慌" |
| 特效/无中生有 | 添加参考图中没有的元素 | "空气中出现扭曲波动，父子如尘烟般消失" |
| 镜头焦点控制 | 前后景角色间的焦点切换 | "镜头对焦到身后倒地的国王" |
| 环境互动 | 角色与环境的自然互动 | "微风吹过，衣角和头发轻微飘动" |

## 适用场景

| 场景 | 说明 | 优势 |
|------|------|------|
| 影视短片 | 对话场景、情绪演绎、镜头语言 | 自然对白表现、专业影视感 |
| 幻想Vlog | 自拍视角的荒诞有趣内容 | 可配合即梦图片模型辅助生图 |
| AI MV | 歌手MV、舞蹈表演、音乐剧 | 节奏感驱动动作、动态镜头运动 |
| UGC创意 | 像素风、动物形象、虚拟形象 | 支持更多非人物形象和风格 |

## 基础参数

| 参数 | 规格 |
|------|------|
| 输入图片格式 | JPG, PNG 等 |
| 图片大小限制 | < 5MB, < 4096x4096 |
| 音频时长 | 推荐 <= 15秒，最大 30秒 |
| 支持分辨率 | 720P, 1080P |
| 生成模式 | 快速模式、大师模式 |
| 支持语言 | 不限，中英日等常见语种更佳 |

## 注意事项

- 视频清晰度高度依赖输入图片质量
- 15秒以内效果较好，15秒后可能出现衰退
- 人脸占比过小可能口型不动
- 人物长时间出镜再入镜后易出现一致性变化
- 极端姿势或角度效果可能不佳
