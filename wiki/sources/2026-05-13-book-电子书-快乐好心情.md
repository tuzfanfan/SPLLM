# 快乐好心情：让健康情绪伴随每一日 - 来源摘要

## 概述

《快乐好心情》是美国医生约翰·辛德勒所著的心理学通俗读物，由邱宏翻译。全书系统阐述了情绪与身体健康之间的关系，提出了"情绪诱发病"（EII病）的概念，指出大多数身体不适的根源在于不良情绪，并提供了实用的情绪管理方法。

## 核心内容

### EII病（情绪诱发病）

| 要点 | 内容 |
|------|------|
| 定义 | 情绪诱发的身体疾病 |
| 流行程度 | 就诊病人中74%-76%患有EII病 |
| 核心观点 | 情绪是人体固有的生理反应，不良情绪会导致生理疾病 |
| 易感人群 | 智商越高的人越容易患EII病 |

### 关键数据

- **奥克思那诊所**：500名肠胃疾病患者中74%得过EII病
- **耶鲁大学医院**：门诊部76%的患者得过情绪诱发病
- **高智商风险**：聪明人能同时发现十件让人闷闷不乐的事

### 核心理论

- **情绪的生理基础**：情绪是人本身固有的生理反应
- **不良情绪的积累效应**：长期不良情绪会导致身体机能紊乱
- **现代医学的盲点**：EII病是现代医学中容易被忽视的领域
- **情绪管理即健康管理**：管理好情绪就是管理好健康

## 关键洞察

1. **身心一体**：情绪和身体是不可分割的整体，情绪问题会表现为身体症状
2. **大多数"病"是情绪病**：去医院就诊的人中超过3/4实际上是情绪问题
3. **聪明人的烦恼**：高智商人群更容易发现负面事物，从而更容易患EII病
4. **预防胜于治疗**：管理好日常情绪可以预防大量身体疾病
5. **医学模式的转变**：需要从单纯的生物医学模式转向生物-心理-社会医学模式
