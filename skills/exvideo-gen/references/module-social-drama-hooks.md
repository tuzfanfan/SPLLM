# Social Drama Hooks

`module.id: social-drama-hooks`

Use this module when the user wants short-form drama built for high retention, strong emotional readability, and episode-end conversion pressure. Typical requests include:

- short vertical drama structure
- episode hook design
- emotional cliffhanger rhythm
- female-audience drama beat planning
- how to build a paid-point ending

Treat this module as a retention-first narrative layer. The goal is not generic screenwriting quality in the abstract; it is to produce a repeatable beat engine with strong hook density and escalating emotional payoff.

## Core Principle

Keep beat names reusable and plot specifics replaceable.

For short-drama projects, first identify the emotional framework before beat writing:

1. write a one-line story that captures who, what state, what core event, and what end state
2. list the episode-event chain in order, usually around the first ten episodes or the first major arc
3. inspect the end-of-episode hook direction
4. classify the repeated emotional pattern
5. reuse the framework with new characters, events, and surface plot

Common framework signals:

- repeated humiliation followed by proof of self suggests an uplift / reversal pattern
- repeated misunderstanding, escalation, and renewed misunderstanding suggests an emotional-spiral or tragedy pattern
- repeated forced proximity, gradual attraction, and external blockage suggests a forced-pairing or romance-pressure pattern
- if the hook keeps asking when the truth is revealed, the framework is likely reveal-driven
- if the hook keeps asking whether the relationship forms, the framework is likely relationship-driven

## Beat Engine

Common reusable beat families:

- opening visual hit
- extreme humiliation
- hidden setup clue
- small face-slap reversal
- ally reveal
- betrayal proof
- public comeback
- life-and-death crisis
- impossible moral dilemma
- episode-end cliffhanger

Each episode should lock:
- dominant emotional target
- 3-5 beat names
- end-hook type

When adapting an existing short drama, preserve the emotional framework and replace the surface skin:
- keep the hook direction
- keep the escalation rhythm
- keep the emotional mode
- change the character identities, circumstances, and concrete incidents
