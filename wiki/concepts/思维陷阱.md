# 思维陷阱

## 定义

> **思维陷阱（Thinking Traps）** 指在思考和决策过程中容易陷入的认知偏差和逻辑错误。李笑来在《把时间当朋友》中强调识别和避免思维陷阱是个人成长的关键。

## 核心原理

### 常见思维陷阱

| 陷阱 | 说明 | 表现 |
|------|------|------|
| **速成陷阱** | 相信可以快速成功 | 追求捷径、投机取巧 |
| **完美陷阱** | 追求完美导致拖延 | "做不到完美就不做" |
| **比较陷阱** | 与他人比较导致焦虑 | "别人都比我好" |
| **确认偏差** | 只关注支持自己观点的信息 | 忽视反面证据 |
| **沉没成本** | 因为已投入而继续错误方向 | "已经花了这么多时间" |
| **非黑即白** | 二元思维 | "要么成功要么失败" |
| **过度自信** | 高估自己的能力 | 低估任务难度和时间 |

### 思维陷阱的危害

```
思维陷阱 → 错误决策 → 浪费时间/资源 → 挫折 → 自我怀疑 → 更多陷阱
```

| 危害 | 说明 |
|------|------|
| **时间浪费** | 基于错误决策浪费大量时间 |
| **机会成本** | 错过更好的选择 |
| **心理负担** | 焦虑、自责、挫败感 |
| **成长停滞** | 重复犯同样的错误 |
