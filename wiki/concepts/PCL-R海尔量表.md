# PCL-R海尔量表

## 定义

> **PCL-R海尔量表（Psychopathy Checklist-Revised）** 是由[[罗伯特-海尔]]开发的标准心理测量工具，用于评估个体心理变态的程度。该量表是心理变态研究中最广泛使用的评估工具，被视为"黄金标准"。

## 核心原理

### 量表结构

| 维度 | 项目数 | 说明 |
|------|--------|------|
| **因素1：人际-情感** | 8项 | 自我中心、欺骗性、缺乏深度情感 |
| **因素2：社会越轨** | 9项 | 冲动性、不负责任、反社会行为 |
| **总计** | 20项 | 每项0-2分，总分0-40分 |

### 20项评估内容

**因素1：人际-情感特征**
| 项目 | 说明 |
|------|------|
| 表面魅力 | 外表迷人、善于社交 |
| 夸大自我价值 | 过度自信、自我膨胀 |
| 病态说谎 | 频繁说谎、欺骗他人 |
| 操纵性 | 利用他人达到目的 |
| 缺乏内疚感 | 做错事不感到内疚 |
| 情感浅薄 | 情感表达表面化 |
| 缺乏同理心 | 同理心缺失 |
| 不承担责任 | 将错误归咎于他人 |

**因素2：社会越轨特征**
| 项目 | 说明 |
|------|------|
| 冲动性 | 行为缺乏计划性 |
| 渴求刺激 | 追求刺激和冒险 |
| 不负责任 | 不履行义务和承诺 |
| 行为控制差 | 难以控制行为 |
| 早期行为问题 | 儿童期就出现行为问题 |
| 青少年犯罪 | 青少年期有违法行为 |
| 违反条件释放 | 违反假释或缓刑条件 |
| 多次婚姻 | 短暂的多次婚姻关系 |
| 青少年犯罪多样性 | 多种类型的违法行为 |

### 评分标准

| 分数范围 | 分类 | 说明 |
|------|------|------|
| 0-9 | 非心理变态 | 正常范围 |
