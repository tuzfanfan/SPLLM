# 情绪脑

## 定义

> 情绪就是能量。情绪脑的工作链条是：警报系统→情绪激素→腺素→能量，用于应对生命威胁。

情绪脑是七层自我模型中的第三层，产生各种情绪以应对危险。

## 工作机制

```
感知威胁 → 警报系统启动 → 情绪激素分泌 → 腺素释放 → 能量爆发
```

## 核心特征

- **应激反应**: 情绪的本质是能量，用于应对生命威胁
- **双刃剑**: 适度的情绪能量可以帮助应对危机，过度的情绪则导致失控
- **与多巴胺系统互动**: 情绪可以触发多巴胺-ATP系统，形成复合冲动

## 情绪失控的表现

- 火气上蹿，遇小事就火冒三丈
- 长期处于焦虑不安状态
- 压力山大，干什么都虎头蛇尾

## 管理策略

- 不能用意志力强行压制情绪（触发努力反向效应）
- 应从生理和环境层面入手调节
- 理解情绪脑的进化功能，接纳而非对抗
