# 即梦 Seedance 2.0 使用手册

## 概述

Seedance 2.0 是即梦平台推出的多模态视频生成模型，支持文本、图片、视频、音频四种输入模态的组合使用。核心升级在于"参考能力"——可以精准还原画面构图、角色细节、镜头语言、动作节奏等，实现真正可控的视频创作。

## 核心能力

### 1. 多模态输入支持

| 模态 | 格式限制 | 数量限制 | 大小限制 |
|------|----------|----------|----------|
| 图片 | jpeg、png、webp、bmp、tiff、gif | ≤ 9 张 | < 30 MB |
| 视频 | mp4、mov | ≤ 3 个，总时长 2-15s | < 50 MB |
| 音频 | mp3、wav | ≤ 3 个，总时长 ≤ 15s | < 15 MB |
| 文本 | 自然语言 | - | - |

**交互限制**：混合输入总上限 12 个文件

### 2. 参考能力（核心升级）

- **参考图像**：精准还原画面构图、角色细节
- **参考视频**：支持镜头语言、复杂动作节奏、创意特效的复刻
- **参考音频**：用于配乐、音效节奏控制

### 3. 视频延长与衔接

- 支持平滑延长与衔接
- 可按用户提示生成连续镜头
- 支持向前延长和向后延长

### 4. 视频编辑能力

- 角色更替
- 片段删减
- 内容增加
- 情绪修改

## 使用方法

### 交互形式

通过"@素材名"指定每个素材用途：
```
@图片1 作为首帧，参考@视频1的打斗动作
```

### 入口选择

- **首尾帧入口**：只上传首帧图 + prompt
- **全能参考入口**：多模态（图、视频、音频、文本）组合输入

### Prompt 写法建议

将参考的视频/图片/音频多次@，并注明：
- 情绪状态
- 时序安排
- 各环节细节

## 典型应用场景

### 1. 一致性提升

解决传统问题：
- 人物前后长相不一致
- 商品细节丢失
- 小字模糊
- 场景跳变
- 镜头风格不统一

### 2. 高难度运镜和动作复刻

上传参考视频即可模仿：
- 电影走位
- 专业运镜
- 复杂动作

### 3. 创意模板/特效复刻

支持"照着模仿"：
- 创意转场
- 广告成片
- 电影片段
- 复杂剪辑

### 4. 视频延长

- 延长指定时长
- 补充后续画面
- 保持连贯性

### 5. 音乐卡点

- 根据音乐节奏安排画面切换
- 关键帧位置控制

### 6. 情绪演绎

- 精准控制角色情绪变化
- 情绪过渡自然

## 重要限制

### 写真人脸限制

⚠️ **平台合规要求**：暂不支持上传包含写实真人脸部的素材（图片和视频均不行）。系统会自动拦截此类素材。

### 生成时长

- 最长 15 秒
- 可自由选择 4-15 秒

### 声音输出

- 自带音效/配乐

## 案例模式总结

### 编辑模式
修改已有视频中的特定元素，如替换角色、修改情绪、调整动作

### 延长模式
在已有视频基础上向前或向后延长，补充新内容

### 多参考模式
组合多个图片、视频、音频素材，实现复杂创意

### 一镜到底模式
连续追踪镜头，无切镜

### 卡点模式
根据音乐节奏安排画面切换

## 最佳实践

1. **明确标注**：素材多时，仔细检查各@对象是否标清楚
2. **合理分配**：优先上传对画面或节奏影响最大的素材
3. **详细描述**：在提示词中写清楚是"参考"还是"编辑"
4. **时序控制**：按秒数分段描述故事线
