# Intent 目录说明

本目录用于存放长期关注主题页。

与 `concept` 的区别：

- `concept` 关注“这是什么”
- `intent` 关注“我们要长期盯什么”

与 `product` 的区别：

- `product` 是产出
- `intent` 是持续监控目标

推荐页面内容：

- 主题定义
- 监控边界
- 重点来源
- 默认节奏
- 默认分析视角
- 关联概念、实体、产品页

推荐优先创建的 intent：

- 低空经济商业化进展
- AI 视频生成工具竞争格局
- 大学城科教文旅合作机会
