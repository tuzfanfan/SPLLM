# 炒股就是炒心态

## 概述

本书从心理学角度分析股票投资，提出'炒股就是炒心态'的核心观点。书中详细分析了投资者在股市中常见的心理误区。

## 核心内容

| 心理误区 | 表现与危害 |
|------|----------|
| 贪婪 | 涨了还想涨，错过最佳卖出时机 |
| 恐惧 | 跌了就恐慌抛售，造成不必要的损失 |
| 从众 | 盲目跟风，缺乏独立判断 |
| 损失厌恶 | 不愿止损，导致亏损扩大 |

## 关键洞察

1. 投资成功的70%取决于心态管理
2. 贪婪和恐惧是投资者最大的敌人
3. 建立投资纪律可以对抗情绪化决策
4. 长期投资心态比短期投机更有利于财富积累
