# 可灵AI工具手册

> 可灵（Keling）是强大的AI视频/图片生成工具，支持文生视频、图生视频、多图参考等多种创作模式。

## 来源信息

| 属性 | 值 |
|------|-----|
| 产品名称 | 可灵（Keling） |
| 开发商 | 可灵科技 |
| 核心模型 | 可灵 1.6（多图参考） |
| 特色功能 | 文生视频、图生视频、多图参考 |
| 手册数量 | 3个 |
| 生成模式 | 标准模式（720p）/高品质模式（1080p） |
| 画幅比例 | 16:9、9:16、1:1 |

## 核心功能（深度提炼）

### 1. 文生视频

**提示词构成要素**：

| 要素 | 说明 | 示例 |
|------|------|------|
| **主体** | 画面主要人物、动物、物体 | 一名士兵、一只大熊猫、一辆奔驰车 |
| **运动** | 主体运动状态 | 趴在泥泞中、弹吉他、奔跑 |
| **场景** | 主体所处环境 | 战场、湖边、街道 |
| **镜头语言** | 镜头应用及切换 | 超大远景、特写、长焦、航拍 |
| **光影** | 赋予摄影作品灵魂 | 晨光、夕阳、丁达尔效应、灯光 |
| **氛围** | 预期视频画面氛围 | 热闹的场景、电影级调色、温馨美好 |

**优质案例**：
- 一只大熊猫在湖边弹吉他 → 主体+运动+场景+氛围
- 镜头中，一名士兵趴在泥泞中... → 主体+运动+场景+镜头+光影+氛围+音乐

### 2. 图生视频

- **输入**：一张图片 → 生成5s或10s视频
- **模式**：标准模式（720p）/高品质模式（1080p）
- **比例**：16:9、9:16、1:1
- **生成数量**：1-4条
- **负向词**（可选）：不希望出现的内容

**特点**：
- 老照片复活
- 静态图片动态化
- 多图参考（1.6版本）

### 3. 多图参考（1.6版本）

**核心能力**：
- 上传最多4张参考图片（人物、动物、场景、服饰）
- 编写创意描述，融合多图素材
- 生成创意视频

**多主体提示词公式**：
```
[主体1描述] & [主体2描述] & [主体3描述] + 互动描述 + 场景描述
```

**适用场景**：
- 前景角色及动作 + 背景环境
- 角色 + 服装 + 产品展示
- 多角色"同框"互动
- 动漫二创

## 提示词工程关键技巧

### 1. 基础公式

```
主体（详细描述）+ 运动（具体动作）+ 场景（环境细节）+ 镜头（角度/景别）+ 光影（氛围光/效果）+ 风格（写实/动漫/电影级）+ 负面词（不希望出现的内容）
```

### 2. 多图参考技巧

- **主体描述**：为每个主体加入细致描述（外貌、动作、表情）
- **风格统一**：确保所有参考图风格一致
- **创意描述**：融合多图素材，生成创意视频
