# Fabric Augmentation Pack

这个参考包定义 `hv-analysis` 的三类增强动作：预大纲、轻量对比、关键论断校验。

## 1. Recursive Outline Pass

适用：
- 报告很大
- 对象复杂
- 需要先把问题空间拆开

输出格式：
- 一级：核心研究问题
- 二级：纵向、横向、交汇、商业化
- 三级：每一章的关键子问题
- 四级：每个子问题的证据需求

规则：
- 先拆问题，再搜资料
- 先列证据需求，再写判断

## 2. Compare Pass

适用：
- 正式横向分析前
- 需要先快速拉出竞品差异图

固定维度：
- 用户是谁
- 核心问题是什么
- 解决方案形态是什么
- 最大优势是什么
- 最大短板是什么
- 当前舆论和口碑关键词是什么

输出形式：
- 先 5 到 10 行快比对
- 再决定哪些对象值得进入正式横向章节

## 3. Claim Audit Pass

适用：
- 遇到“行业第一”“颠覆式”“爆发增长”这类高风险判断
- 不同来源说法相互冲突
- 需要把观点从“像是真的”提高到“证据链站得住”

审查问题：
1. 这条 claim 的原始来源是谁
2. 它是事实、判断，还是二手转述
3. 有没有第二个独立来源支撑
4. 有没有更好的反例或边界条件
5. 最终应该保留、降级表达，还是删除
