# 2010注册会计师考试教材：经济法 - 来源摘要

## 概述

《2010注册会计师全国统一考试教材：经济法》由中国注册会计师协会组织编写，是注册会计师全国统一考试的官方指定教材。全书涵盖法律基础知识、各类企业法律制度、证券法、合同法、票据法等重要法律领域。

## 核心内容

### 全书结构

| 章节 | 主题 |
|------|------|
| 第一章 | 法律基础知识（法律理论、法律行为、代理、诉讼时效、民事诉讼与仲裁） |
| 第二章 | 个人独资企业和合伙企业法律制度 |
| 第三章 | 外商投资企业法律制度（合资、合作、外资企业） |
| 第四章 | 公司法（基本理论、登记管理、有限责任公司、股份有限公司、股票债券、合并分立、解散清算） |
| 第五章 | 证券法（基本理论、股票发行与交易、债券发行与交易、证券投资基金、信息公开、禁止交易行为、上市公司收购） |

### 核心法律领域

1. **法律基础**：法律行为制度、代理制度、诉讼时效制度
2. **企业法**：个人独资企业、合伙企业、外商投资企业
3. **公司法**：有限责任公司和股份有限公司的设立、运营、变更、终止
4. **证券法**：股票和债券的发行与交易、证券投资基金、上市公司收购

## 关键洞察

1. **注册会计师的知识体系**：经济法是注会考试的重要科目，涵盖商事法律的方方面面
2. **法律框架的系统性**：从法律基础到具体商事法律，形成完整的法律知识体系
3. **实务导向**：教材内容紧密结合注册会计师执业需求
4. **2010年版本的时代特征**：反映了当时中国商事法律制度的最新发展
