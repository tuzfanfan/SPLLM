# 在线升级

## 定义

> **在线升级（Online Escalation）** 指网络互动中冲突和极端行为不断递增的现象。由于网络环境的匿名性、异步性和群体效应，原本温和的分歧可能迅速升级为激烈对抗甚至网络暴力。

## 核心原理

### 升级机制

```
初始分歧 → 回音室放大 → 群体极化 → 对立升级 → 网络暴力
```

| 阶段 | 特征 | 心理机制 |
|------|------|----------|
| **初始分歧** | 观点差异 | 认知偏差 |
| **回音室放大** | 同质化信息聚集 | 确认偏差 |
| **群体极化** | 观点趋向极端 | 从众心理 |
| **对立升级** | 人身攻击、标签化 | [[在线去抑制效应]] |
| **网络暴力** | 人肉搜索、威胁 | 去人格化 |

### 驱动因素

| 因素 | 说明 |
|------|------|
| **匿名性** | 降低攻击行为的心理门槛 |
| **群体极化** | 群体讨论使观点更极端 |
| **回音室效应** | 只接触同质化信息 |
| **算法推荐** | 强化已有观点，制造对立 |
| **异步沟通** | 缺乏即时反馈和调解 |
| **去人格化** | 将对方视为抽象符号而非具体的人 |

## 表现形式

| 类型 | 说明 | 危害程度 |
|------|------|----------|
| **言语升级** | 从讨论到争吵到辱骂 | 中 |
| **人身攻击** | 针对个人而非观点 | 高 |
| **群体围攻** | 多人联合攻击个体 | 高 |
| **人肉搜索** | 挖掘并公开个人信息 | 极高 |
| **现实威胁** | 从线上延伸到线下 | 极高 |

## 应对策略

| 层面 | 策略 |
|------|------|
| **个人** | 冷静回应、避免情绪化、适时退出 |
| **平台** | 内容审核、冲突预警、降温机制 |
| **教育** | 媒介素养、批判性思维培养 |
| **制度** | 网络行为规范、法律约束 |
