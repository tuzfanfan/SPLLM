# 微步骤

## 定义

> **微步骤（Micro-steps）** 指将大目标分解为极小的、几乎不需要意志力就能完成的行动单元。微步骤是[[微习惯]]策略的核心执行方法，通过降低行动门槛来克服拖延和启动困难。

## 核心原理

### 微步骤的特征

| 特征 | 说明 |
|------|------|
| **极小** | 小到不可能失败 |
| **具体** | 明确的行动指令 |
| **即时可执行** | 不需要特殊条件或准备 |
| **低意志力消耗** | 几乎不需要自我控制 |

### 微步骤 vs 传统目标设定

| 维度 | 传统目标 | 微步骤 |
|------|----------|--------|
| **目标大小** | 大而模糊 | 小而具体 |
| **启动难度** | 高 | 极低 |
| **意志力消耗** | 高 | 极低 |
| **失败风险** | 高 | 几乎为零 |
| **心理负担** | 大 | 极小 |

### 微步骤示例

| 大目标 | 微步骤 |
|------|------|
| 每天锻炼30分钟 | 每天做一个俯卧撑 |
| 每天阅读一小时 | 每天读一页书 |
| 每天写作1000字 | 每天写50个字 |
| 学一门外语 | 每天学一个单词 |
| 整理房间 | 每天整理一张桌子 |

## 执行原则

| 原则 | 说明 |
|------|------|
| **唯一标准** | 微步骤必须小到"即使最糟糕的日子也能完成" |
| **不设上限** | 完成微步骤后可以继续做更多 |
| **每日执行** | 每天都要完成，不找借口 |
| **记录追踪** | 记录每天的完成情况 |
