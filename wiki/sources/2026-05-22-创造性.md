# 创造性——发现和发明的心理学

## 基本信息

- **作者**: [[米哈里·契克森米哈赖]] (Mihaly Csikszentmihalyi)

## 核心内容

本书是创造性研究领域的里程碑式著作。[[米哈里·契克森米哈赖]]基于15年的系统研究和对91位杰出创造性人物的深度访谈，提出了[[创造性系统三要素]]模型，从根本上重新定义了我们对创造性的理解。

## 核心理论：创造性系统三要素模型

[[米哈里·契克森米哈赖]]认为，创造性不是个人的特质，而是一个系统现象。创造性发生在三个要素的交汇处：

1. **文化/符号领域**（Culture / Symbolic Domain）：已有的文化知识和符号系统
2. **个人**（Person）：具有特殊天赋和动机的个体
3. **领域/专家圈子**（Field / Expert Gatekeepers）：负责评估和选择创造性成果的专业社群

创造性类似于生物进化中的基因变化：个人产生变异（新想法），专家圈子进行选择（认可或拒绝），被认可的变异进入文化领域（成为新知识）。

## 研究方法

本书的研究基础极为扎实：

1. **大样本访谈**：对91位杰出创造性人物进行深度访谈
2. **跨领域覆盖**：涵盖科学、艺术、商业、政治等多个领域
3. **纵向追踪**：部分研究持续15年
4. **质性分析**：对访谈数据进行系统的质性分析

## 学术价值

本书的学术贡献在于：

1. **系统视角**：将创造性从个人特质重新定义为系统现象
2. **实证基础**：基于大量访谈数据而非理论推演
3. **跨学科整合**：融合了心理学、社会学、人类学和文化研究
4. **实践指导**：为培养创造性提供了科学依据
