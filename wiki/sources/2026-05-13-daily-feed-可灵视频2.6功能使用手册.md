# 可灵视频2.6功能使用手册

## 概述

可灵视频2.6是首个「音画同出」模型，单次生成即可同步产出视频画面与完整音频，涵盖语音、音效及环境音等内容，实现"所见即所闻"的视听体验。

### 核心升级

- **音画协同**：语音节奏、环境音与画面动作紧密呼应，避免"画面一套、声音一套"的割裂感

### 创作路径

| 路径 | 说明 |
|------|------|
| 文生音画 | 从一句话到一条完整音视频，输入文本生成视频同时带有语音、音效、环境音 |
| 图生音画 | 让静态画面开口说话、动起来，上传图片/文本一键直出音视频 |

---

## 支持的音频类型

| 类型 | 说明 |
|------|------|
| 说话叙述 | 角色说话、叙述 |
| 对白 | 多人语音对白 |
| 唱歌/Rap | 角色以歌词形式唱歌或rap |
| 环境音效 | 场景背景音，如风声、海浪、街道人声、车流 |
| 物体/动作音效 | 如玻璃破裂、脚步声、刀切声、机器轰鸣 |
| 混合音效 | 语音+背景音+物效组合，形成沉浸式音画体验 |

## 能力维度

### 3.1 单人独白

**能力定义**：画面中的人物直接对镜头说话，情绪自然、口型同步

**适用场景**：
- 商品展示：展示产品、强调卖点
- 生活Vlog：展现日常生活中轻松自然的碎片
- 新闻播报：强调专业性、正式感、稳定语调
- 演讲表达

### 3.2 旁白解说

**能力定义**：画外声音讲述、解释、评论画面内容

**适用场景**：商品讲解、赛事解说、纪录片、故事叙述

### 3.3 多人对白

**能力定义**：多角色互动对话，角色间语气自然切换

**适用场景**：访谈节目、剧情演绎、生活对话、搞笑短剧

### 3.4 音乐表演

**能力定义**：角色唱歌、乐器演奏等音乐表演

**类型**：歌曲演唱、说唱表演（Rap）、乐队合唱、乐器演奏

### 3.5 创意场景

影视特效等创意场景

## 提示词编写指南

### 基本公式
```
提示词 = 场景（场景描述）+ 主体（主体描述）+ 运动（运动描述）+ 音频（对话/唱歌/音效/纯音乐）+ 其他（风格/情感/镜头）
```

### 多角色对话写法

#### 对话写法
- **单角色**：明确声音属性（【男人说】、"句子" + 低沉+快速）
- **多角色**：使用明确标签区分，如：【A角色，愤怒地说】"句子"【B角色，平静地回答】"句子"

#### 唱歌写法
```
格式："歌词内容" + 演唱风格 + 伴奏描述 + 情绪
风格：流行唱腔（Pop）、美声（Opera）、乡村（Country）等
情绪/技巧：高亢地唱（High-pitched）、颤音（Vibrato）、温柔地唱
```

#### 说唱写法
```
格式："句子（押韵）" + 节奏流派 + 情绪
节奏流派：强烈的Boom Bap节奏、Trap Style Beat、快速的Flow
```

#### 音效写法
```
格式：声音来源（动作/物体）+ 状态 + 专业拟声词
结构：【物体：木门】猛地【动作：关上】+【拟声词：砰】
```

#### 环境音写法
```
格式：场景 + 声音组成元素 + 空间混响
元素：雨声、虫鸣、人群低语、车流
空间感：空旷的礼堂回声（Reverb）、狭小的室内混响（Small Room Acoustic）
```

### 多角色标签技巧

**P1. 多角色标签**：使用[角色名, 声音特质]格式
```
示例：[黑衣特工，低沉冷静]："为什么？"这时候说话人切换[女助手，温和坚定]："因为时间到了。"
```

**P2. 说话人切换**：使用明确的连接词控制说话次序和节奏
```
示例：[黑衣特工]："为什么？"紧接着，[女助手]："因为时间到了。"
```

**P3. 时序控制**：使用明确的连接词控制说话次序和节奏

## 音色控制功能

### 能力简介

选定目标音色后，模型在后续所有该角色的对话中自动使用该音色，让多角色、多轮对话场景保持声音的高度一致与辨识度。

### 创建专属音色

**Web端操作步骤**：
1. 点击「+新建音色」，可通过「本地上传」或「历史选择」创建
2. 上传一段包含目标音色的音频（支持中英文音/视频内容）
3. 设置音色名称并保存

**App端操作步骤**：
1. 打开创作界面的「选择音色」列表
2. 点击「+新建音色」上传音频
3. 设置音色名称并保存

### 调用目标音色

**Web端**：输入@符号，系统自动调起音色下拉列表
**App端**：打开「选择音色」列表，选择目标音色

### 音色控制Prompt教学

**推荐书写范式**：
```
提示词 = 场景 + 【主体@音色名称】+ 运动 + 音频 + 其他
示例：警匪审讯场景下，【警探李@王总的音色】站立质问...
```

**音色生效规则**：
- 指定音色：主体后紧贴添加@音色名称，即「主体@音色名称」
- 多音色：不同角色的「@音色名」相互独立，建议应用于双人对话场景

## FAQ

**Q：当前模型支持哪些语言的语音输出？**
A：当前模型仅支持中文和英文的语音输出。其他语言会自动翻译成英文后再生成相应语音。

**Q：只生成音频，不要视频可以吗？**
A：可以前往平台的【音效生成】模块，选择【文生音效】或【视频生音效】。

**Q：如何提升生成效果？**
- 优化提示词：保持描述清晰具体，避免一次塞太多复杂指令
- 强化图文匹配：确保图片内容与文本描述一致
- 精准设置参数：根据实际需求调整视频时长、分辨率等参数
- 简化创作场景：单次创作聚焦一个核心主题
