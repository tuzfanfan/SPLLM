# 心理画外音

| 属性 | 内容 |
|------|------|
| 作者 | 严文华 |
| 出版信息 | 上海画报出版社 2003年 |
| 类型 | 心理学图解手册 |
| 核心主题 | 通过图画心理学解读每一幅画背后的心理故事，以画为媒促进人与人之间的沟通 |

## 核心观点

1. 每一幅画都是一个故事，图画正成为人与人之间沟通最便捷、最有效的工具之一。
2. 自画像反映的是每个人内心形象的描画，人对自己的评价、优势劣势、个性都在自画像中表现出来。
3. 存在一类"不愿长大的成人"，他们内心真实自我的年龄远小于生理年龄，主要需求是获得他人的关爱。
4. 主题画（如山、路、家；自画像；给矩形添加图形；房屋和人；给十字添加图形）可以限定考察范围，同时保留作画者的想象空间和创造自由。
5. 图画分析可以帮助人们看到内心深处真实自我的样子，是自我探索和心理成长的重要工具。
