# 跟毛泽东学凝聚人心 - 来源摘要

## 概述

本书系统阐述了毛泽东凝聚人心的智慧和方法。作者孟庆春以"成功就是赢得人心凝聚人心"为核心命题，从毛泽东的革命实践出发，分析了他在团结党内、赢得群众、统一战线、凝聚军心等方面的卓越才能。全书以十篇内容，揭示了毛泽东从一个偏僻山村的孩子成长为世纪伟人的成功之道。

## 核心内容

| 主题 | 核心内容 |
|------|----------|
| 凝聚人心 | 赢得人心、团结力量的两大方面："事"上的凝聚和"人"上的凝聚 |
| 长征奇迹 | 将战略退却转变为"斗志昂扬的胜利进军" |
| 延安整风 | 形成团结坚强的党的核心 |
| 农民运动 | 最早认识到农民是革命主力、"谁赢得农民谁就赢得了革命" |
| 军事思想 | 枪杆子里面出政权、农村包围城市 |

## 关键洞察

1. **"成功就是赢得人心凝聚人心"**：海伦·斯诺对毛泽东成功之道的精辟概括。
2. **长征的凝聚力奇迹**：千百万热血青年冲破国民党封锁奔赴延安——这种凝聚人心的成就在近现代中国历史上少见。
3. **安源路矿工人大罢工"硕果仅存"**：1923年"二七"大罢工失败后全国工运陷入低潮，唯有毛泽东领导的安源罢工取得胜利。
4. **"政权是由枪杆子中取得的"**：毛泽东在"八七"会议上提出的著名论断。
