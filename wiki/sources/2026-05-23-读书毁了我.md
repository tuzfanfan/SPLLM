# 读书毁了我
| 属性 | 内容 |
|------|------|
| 作者 | 王强 |
| 出版信息 | 上海人民出版社, 2018, ISBN 978-7-208-15003-4 |
| 类型 | 读书随笔/书话集 |
| 核心主题 | 关于书的热爱、藏书文化、阅读的力量与文字的意义 |

## 核心观点
1. "有力量的文字"蕴含摧毁一切的能量，它们不断摧毁"昨天的我"，型塑出"明天的我"
2. 读书是一种"病症"——书淫、书癖、书虫、书痴，一旦染上便难以自愈
3. 经典是永远占据着书架又永远翻读不完的书
4. 猎书的第一狩猎场是图书馆与学者文集，第二狩猎场是书店
5. 学者文集是"猎书地图"，坦诚的学者（如钱锺书、周作人）的引文注脚是猎书者的指南
6. 阅读是关于力量与自我重塑的过程，文字只可能呈现"有力量的"和"没有力量的"两种存在
7. 藏书不仅是收集，更是与作者跨越时空的精神对话
8. 数字化时代的阅读面临新的挑战，但纸质书的力量不可替代
