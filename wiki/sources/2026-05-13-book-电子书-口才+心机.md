# 口才+心机——最实用的沟通技巧 - 来源摘要

## 概述

《口才+心机》由张焕彬所著，是一部关于沟通技巧和社交智慧的实用指南。全书分为"成功口才"和"交际口才"两大部分，从说话技巧、交际策略、心理分析等多个角度，提供了大量实用的沟通方法和案例。

## 核心内容

### 成功口才篇

| 技巧类别 | 内容要点 |
|---------|---------|
| 对话金钥匙 | 十种有效对话的方法和技巧 |
| 病态心理克服 | 好口才需要克服的心理障碍 |
| 说话小毛病 | 去掉影响表达的不良习惯 |
| 求人办事 | 求人办事的说话技巧和策略 |
| 酒桌技巧 | 酒桌上的说话艺术 |
| 自卖自夸 | 恰当的自我推销方法 |
| 言谈新意 | 如何使言谈富有新意和吸引力 |

### 交际口才篇

- **初次见面**：第一印象的建立和破冰技巧
- **与名人交谈**：如何与地位高的人有效沟通
- **倾听技巧**：两耳一心，主动倾听的艺术
- **冷热水效应**：交际中的心理策略
- **甜言蜜语**：赞美的艺术和时机
- **安慰技巧**：如何有效地安慰他人

## 关键洞察

1. **口才与心机并重**：光有好口才不够，还需要懂得人心和策略
2. **沟通是双向的**：倾听和表达同样重要
3. **场合决定话术**：不同场合需要不同的说话方式
4. **心理因素的关键作用**：克服心理障碍是好口才的前提
5. **实践出真知**：沟通技巧需要在实际场景中不断练习
