# 五千年演义：两宋春秋

## 概述

《五千年演义：两宋春秋》是"五千年演义"丛书之一，由杨世铎编著。本书讲述公元960年到1279年北南两宋的历史，从北宋建国到南宋灭亡，共约320年。全书以赵匡胤起家开篇，通过一系列动人心魄的故事，展现两宋时期的风云变幻。

## 核心内容

### 主要人物

| 人物 | 身份 | 特点 |
|------|------|------|
| 赵匡胤 | 宋太祖 | 雄才大略，从后周禁军将领到开国皇帝 |
| 韩令坤 | 赵匡胤好友 | 磁州人，少年勇敢 |
| 慕容延钊 | 赵匡胤好友 | 太原人，心怀壮志 |
| 郭威 | 后周太祖 | 赵匡胤早期追随的主帅 |
| 柴荣 | 周世宗 | 郭威养子，赵匡胤辅佐的明君 |
| 赵普 | 谋士 | 字则平，赵匡胤的重要谋士 |

### 赵匡胤的成长

1. **少年时期**
   - 后唐天成二年（927年）生于洛阳夹马营
   - 体貌雄伟，性情豪爽
   - 好习武，骑射技艺超群
   - 与韩令坤、慕容延钊结为知己

2. **驯马事件**
   - 骑烈马失控，额头撞城门
   - 倒筋斗坠马却毫发无损
   - 重跨马背，驯服烈马
   - 名声大振

3. **喜鹊救命**
   - 与韩令坤在破土屋赌博
   - 因鸟雀嘈杂外出射雀
   - 房屋随即坍塌
   - "掩埋了自己的童年"

### 从军经历

| 时间 | 事件 | 结果 |
|------|------|------|
| 后汉时期 | 投奔郭威 | 被留帐下，随征河中 |
| 郭威称帝 | 拥立有功 | 成为后周禁卫军之官 |
| 高平之战 | 斩杀北汉大将张元徽 | 扭转战局 |
| 征南唐 | 智取清流关，攻占滁州 | 大败唐军 |
| 六合之战 | 严明军纪，斩退缩将士 | 大败南唐元帅李景达 |

### 关键战役

1. **清流关之战**
   - 皇甫晖、姚凤率十万唐军守清流关
   - 赵匡胤星夜前进，偃旗息鼓
   - 鸡叫时开关突袭
   - 皇甫晖、姚凤被俘，滁州攻克

2. **滁州治理**
   - 翰林学士窦仪登记库藏
   - 赵匡胤欲取绢匹被劝阻
   - 赵普任军事判官，劝谏释放无辜百姓
   - 赢得民心

3. **六合之战**
   - 韩令坤欲弃扬州
   - 赵匡胤激将令其回守
   - 严明军纪：皮笠留剑痕者斩
   - 大败李景达，追至江边

## 关键洞察

1. **将门虎子**：赵匡胤出身将门，父亲赵弘殷为后唐禁军将领，家学渊源。

2. **勇武与智谋并重**：不仅个人武艺高强，更善于用兵和治军。

3. **从谏如流**：接受窦仪、赵普的劝谏，改正错误，赢得民心。

4. **严明军纪**：用皮笠剑痕标记退缩者，斩首示众，震慑全军。

5. **统一战争**：从后周禁军将领到开国皇帝，为统一中原奠定基础。
