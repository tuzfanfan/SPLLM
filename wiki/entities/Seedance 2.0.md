# Seedance 2.0

## 概述

Seedance 2.0 是即梦平台推出的多模态AI视频生成模型，支持图像、视频、音频、文本四种模态输入，实现真正可控的视频创作体验。

## 关键属性

| 属性 | 值 |
|------|-----|
| **所属公司** | 字节跳动（即梦） |
| **产品类型** | AI视频生成模型 |
| **版本** | 2.0 |
| **上线时间** | 2026年 |
| **支持模态** | 文本、图像、视频、音频 |

## 技术规格

### 输入限制

| 模态 | 格式 | 数量限制 | 大小限制 |
|------|------|----------|----------|
| **图片** | jpeg, png, webp, bmp, tiff, gif | ≤ 9张 | < 30MB |
| **视频** | mp4, mov | ≤ 3个，总时长2-15s | < 50MB |
| **音频** | mp3, wav | ≤ 3个，总时长≤15s | < 15MB |
| **文本** | 自然语言 | - | - |

### 输出规格

| 参数 | 规格 |
|------|------|
| **生成时长** | ≤ 15秒（可选4-15s） |
| **声音输出** | 自带音效/配乐 |
| **混合输入上限** | 12个文件 |

## 核心能力

### 1. 多模态参考
- 📷 参考图像可精准还原画面构图、角色细节
- 🎥 参考视频支持镜头语言、复杂动作节奏、创意特效复刻
- ⏱ 视频支持平滑延长与衔接
- ✂️ 编辑能力支持角色更替、删减、增加

### 2. 基础能力增强
- 物理规律更合理
- 动作表现更自然流畅
- 指令理解更精准
- 风格保持更稳定

### 3. 一致性提升
- 人脸一致性
- 服装细节保持
- 字体清晰度
- 场景连贯性

## 交互方式

### 入口选择
- **首尾帧入口**：仅上传首帧图 + prompt
- **全能参考入口**：多模态（图、视频、音频、文本）组合输入

### @引用语法
```
@图片1 作为首帧
@视频1 参考镜头语言
@音频1 用于配乐
```

## 限制说明

⚠️ **合规限制**：暂不支持上传包含写实真人脸部的素材（图片和视频均不行），系统会自动拦截此类素材。
