# 即梦

## 概述
> 即梦（Jimeng）是天昊科技旗下的AI内容创作平台，专注于影视级AI视频和图像生成，强调叙事性、情绪表达和音画一体化，定位专业创作者和影视从业者。

## 平台功能

### 1. 视频生成
- **Seedance 1.5/2.0**：基础视频生成能力
- **Seedance 3.0**：专业级运镜控制和叙事能力
- **Seedance 3.5 Pro**：影视级视频生成 + 音画一体
- **Seedance 4.0/4.5**：最新版本，多镜头组合和复杂场景

### 2. 图像生成
- 支持静态图像生成
- 艺术风格库：胶片、动漫、油画、水墨等
- 分镜式提示词，适合系列图创作

### 3. 音画一体（Seedance 3.5 Pro）
- 视频生成时同步生成匹配的音频
- 音频类型：背景音乐、环境音效、人声配音
- 音频与画面情绪、节奏自动同步

### 4. 数字人生成（OmniHuman 1.5）
- 输入：人物图片 + 音频文件
- 输出：说话/唱歌的数字人视频
- 应用：虚拟主播、数字分身、历史人物复活

## 提示词方法论

### 即梦提示词结构
```
分镜编号 + 画面描述 + 情绪基调 + 艺术风格 + 运镜指令 + 音频描述（可选）
```

### 平台特色
- **分镜式创作**：将长视频拆分为多个分镜，每个分镜单独生成
- **情绪优先**：强调情绪表达，提示词中包含情绪关键词
- **运镜丰富**：支持推、拉、摇、移、跟、环绕等多种运镜
- **音画同步**：提示词中可以同时描述视频和音频
