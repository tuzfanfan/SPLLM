# 联想教父柳传志

**作者**: 彭征、袁丽丽

## 核心观点

本书是第一部详尽记录柳传志精彩人生的倾情力作，生动展现了这位传奇企业家从20万元艰难创业到打造举世瞩目联想集团的荡气回肠历程。

## 关键内容

### 1. 柳传志履历

| 年份 | 事件 |
|------|------|
| 1944年 | 出生在上海的一个律师家里 |
| 1961年 | 考入西安军事电讯工程学院学习 |
| 1970年 | 进入中科院计算所工作 |
| 1984年 | 伙同11人创立中科院计算技术研究所新技术发展公司 |
| 1985年 | 推出第一款具有联想功能的汉卡产品 |
| 1989年 | 联想集团公司正式成立 |
| 1994年 | 联想在香港成功上市 |
| 2004年 | 联想成功收购IBM的PC业务 |
| 2005年 | 联想成为奥运合作伙伴 |

### 2. 管理特色
- 军人气质的管理模式
- 中国特色的经营谋略
- "搭班子、定战略、带队伍"的管理三原则

### 3. 核心理念
- "入模子"
- "退出画面看画"
- "拐大弯"
- "别拿长跑当短跑"
- "鸵鸟理论"
- "把5%的希望变为100%的现实"
