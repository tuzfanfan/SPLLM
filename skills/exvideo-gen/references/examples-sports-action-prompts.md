# Sports Action Prompt Examples

Use this file as the archive for sports-action and high-kinetics prompt cases. Keep original action breakdowns, speed-state designs, camera patterns, and impact-detail language here so the core workflow can reuse them without treating one sport or one venue as the default.

## Usage Rules

- Treat examples as references, not universal defaults.
- Preserve the original time-sliced motion logic when archival fidelity matters.
- Move only generalized action-writing lessons back into reusable templates or modules.
- Separate sport-specific identity from reusable motion grammar.

## Example 01: UFC Fight Combination To Flying Knee Finish

### Status

- Type: original sports-action prompt case
- Purpose: preserve a high-impact combat prompt with clear speed shifts, impact detail, and camera escalation
- Default inheritance: partial
- Replace before reuse: fighter identity, arena specifics, exact strike sequence, and any brand-neutral venue assumptions

### Original Prompt

```text
0-5秒｜开场即白热化
双方中距离疯狂组合拳。A选手前手刺拳连击+右腿低扫B选手前腿。B选手头部摇闪躲开射影，反手连续勾拳反击A选手肋部与头部。拳套高速交错，汗水震碎飞散。A选手摔拳。B选手下潜伺机。正常速度，无慢动作。记录拳拳到肉的叩打声、急促呼吸声。

5-7秒｜穿透重击
B选手在A选手摆拳挥空瞬间，以前脚为轴pivot转身，后手重拳穿透防守，精准击中A选手下颌。进入升格慢动作，汗珠高速飞散，聚光灯下形成闪烁高光颗粒；A选手脸部肌肉明显形变，头部侧方甩动；胸肌、肩部肌肉震颤；拳套挤压皮肤产生冲击波形变。镜头快速推近，聚焦力量传递。慢动作在此段最强。

7-9秒｜施压追击
慢动作结束，恢复实时速度。A选手脚步失衡跌跄后退侧向八角笼边缘，铁网逐渐占据背景。B选手继续向前施压，缩短距离。摄影机横向跟拍。

9-12秒｜飞膝终结
B选手加速冲刺，右腿蹬地，身体腾空跃起，膝盖向上攫发式抬升，一记飞膝。镜头快速推进至近景。膝尖精准撞击A选手面部，头部剧烈后仰撞到铁网，身体被铁网慢慢瘫软倒下地面。摄影机跟拍至对手倒地，画面结束。
```

### What To Preserve

- 明确的时间切片式动作推进
- 从实时速度到升格慢动作再回到实时速度的节奏设计
- 冲击瞬间的可见形变描写
- 运镜跟随打击强度升级
- 呼吸声、叩打声这类动作确认音效

### What To Replace Before Reuse

- `UFC / 八角笼 / 飞膝终结` 这些具体格斗语义
- 具体攻防顺序
- A/B 选手的体型、服装、身份设定
- 任何会把本案例误读成默认 combat workflow 的场地和规则信息

### Reuse Note

Reuse this case when the goal is to model force transfer, escalation, and impact realism in a short combat clip. Keep the timing structure and speed-state logic, but rewrite the strike chain and venue based on the current project.

## Example 02: Three-Step Dunk One-Take Sports Spot

### Status

- Type: original sports-action prompt case
- Purpose: preserve a one-take basketball action prompt with jump-phase slow motion and strong body-mechanics description
- Default inheritance: partial
- Replace before reuse: player identity, sponsor markings, court branding, and any basketball-specific prop assumptions

### Original Prompt

```text
风格：街头篮球纪录片，充满即兴能量与运动张力。
角色：参考（@图片1），右手持标准橙色篮球，动作敏捷，爆发力极强。
场景：封闭式室内篮球场，大地板中央印有黑色大型赛事LOGO及"AI Manager"赞助商标识。观众席虚焦收略。顶光与侧光混合，强化肌肉与球衣质感。球员汗水、球衣飘动细节清晰。
运镜：一镜到底手持跟拍，低机位角度，围绕角色运动轨迹推进，助跑阶段实时速度；起跳后升格慢动作；接近扣篮瞬间恢复正常速度。

0-2秒｜持球酝酿
中央。角色站篮下缓慢运球，身体微前倾，目光锁定篮筐。篮球连续撞击地板，稳定回弹。肩膀下沉，重心前移。正常速度。

2-4秒｜启动突破
镜头推至全景。突然启动，右手加速运球冲刺。球鞋摩擦地板、身体前倾、球衣下摆后翻。最后一次重运球后结球转向右手单击，抱球曲臂。正常速度。

4-8秒｜起跳升格
进入升格慢动作。左脚爆发蹬地，小腿大腿肌肉拉伸，力量向上传导，身体缓慢离地，双腿自然向后展开。镜头同步上移。球衣短袖随风飘动。

8-10秒｜高空滞停
慢动作最强阶段。角色升至最高点，空中滞停。右手控球于身后，右臂向后拉伸，手指发力清晰，篮球旋转。胸腔打开，目光锁定篮筐。

10-12秒｜暴力扣篮
画面渐恢复正常速度。肩背手臂同步发力，右臂高速挥出，篮球砸向篮筐。强烈冲击，篮筐震动，篮网瞬间拉伸后甩动。角色单手抓框短暂停留，身体轻微悬浮，篮网向右摇摆。随后自然下落，双脚先后落地，身体轻扭跟镜头。扣篮余震扩散。
```

### What To Preserve

- 一镜到底的推进逻辑
- 助跑、起跳、滞空、终结、落地的完整动作相位
- 慢动作重点放在起跳和滞空
- 肌肉发力链、球衣飘动、篮网形变等可见细节
- 低机位跟拍与向上跟随的结合

### What To Replace Before Reuse

- `AI Manager`、赛事 LOGO 等案例内品牌或场地字样
- `右手持标准橙色篮球` 这一具体道具设定
- 当前案例中的球场类型、观众席处理和赞助信息
- 任何把“暴力扣篮”误当成所有篮球镜头默认高潮的内容

### Reuse Note

Reuse this case when the project needs a one-take athletic burst with clear launch and hang-time phases. Keep the action-phase structure and camera-speed orchestration, but replace sport-specific props, branding, and finishing move logic.

## Example 03: Bicycle Kick Night Field Sequence

### Status

- Type: original sports-action prompt case
- Purpose: preserve an overhead-kick style football clip with controlled airborne mechanics and recovery landing
- Default inheritance: partial
- Replace before reuse: player identity, field branding, exact kick type, and any football-only action assumptions

### Original Prompt

```text
风格：足球纪录片风格，超写实运动摄影，电影级运动美学，冷暖混合夜景色调，高对比度，中等饱和度，清晰轮廓光。
角色：参考（@图片1），黄黑配色足球。动作舒展，爆发力强。
场景：夜间室外人工草皮足球场，深黑色夜空，球场顶灯照亮场地，翠绿色人造草坪，身后是白色球门网，门柱旁亮黄色广告牌印有红色"AI Manager"字样。四周绿色围网，远处模糊的球场设施、灯光及篮球架轮廓。
运镜：一镜到底手持跟拍，低机位角度，平滑前跟，起跳与落地配合升格慢动作，击球瞬间恢复实时速度。

0-4秒｜控球调整
低机位角度，全景推至中景。角色站足前，右脚轻触调整，足球粘在脚背与地面间轻微弹跳。随后连续颠球，脚背精准控制节奏，身体重心随球微调。镜头平滑前跟。记录触地声、颠球声、球鞋摩擦草坪声。

4-8秒｜腾空蓄力
角色接受足球挑空中，快速后移半步，双臂展开，支撑腿爆发蹬地，身体向后腾空跃起（高帧率慢动作），身体后倒呈弓形，双臂展开，头部自然后仰，长发与衣裤缓慢飘动。镜头向上跟随，身体接近水平。足球从画面上方缓慢下落，目光锁定足球。击球腿充分蓄力，另一腿反方向舒展平衡——标准倒挂金钩姿态。此段慢动作最强。

8-9秒｜击球发力
画面恢复正常速度。足球下落至击球点，击球腿爆发驱动，脚背精准抽中足球中下部，产生明显旋转效应。足球沿画面右上角飞射，以轻微上弧弦线高速射向远端球门，击球声干脆有力。

9-12秒｜落地收尾
足球加速远离镜头，射入球门。身体沿翻转惯性继续运动：上背部先触草坪 → 肩部着地，双臂撑地吸收冲击 → 侧向滚动缓冲 → 臀部与双腿落地，最终侧身躺于草坪，双腿自然弯曲，动作完整收尾。
```

### What To Preserve

- 控球到腾空再到落地缓冲的完整闭环
- 起跳段与落地段都纳入慢动作设计
- 身体弓形、双臂平衡、支撑腿与击球腿分工这些力学细节
- 击球后球体轨迹与旋转效应
- 落地收尾不是省略，而是明确写出缓冲顺序

### What To Replace Before Reuse

- `AI Manager` 广告牌与当前球场识别物
- `倒挂金钩` 这一具体技术动作
- 足球、球门、人工草坪等项目专属元素
- 夜场冷暖混合色调如果不符合当前项目

### Reuse Note

Reuse this case when the project needs airborne sports mechanics with a clearly described recovery phase. Keep the body-balance logic, hit moment timing, and landing sequence, but rewrite the specific prop, field, and sport action.

## Reusable Lessons Across Cases

- Split the motion into phases rather than writing one long paragraph.
- Mark speed-state transitions explicitly: realtime, slow motion, then return to realtime.
- Describe force transfer, not only the final result.
- Pair camera movement with motion phase changes.
- Add visible deformation and sound cues at the impact moment.
- Do not drop the recovery or landing phase when realism matters.
