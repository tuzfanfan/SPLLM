# 七年一辈子

## 定义

> 以七年为一个时间段计算人生，每个"下辈子"就是对"上辈子"的检验。引用李笑来的时间观念。

小野在《自律力》中引用的时间管理理念：如果你在"上辈子"死磕、自律、努力，"下辈子"的起点就会比别人高出好多。

## 核心逻辑

```
自律的7年 → 高起点的新7年 → 更高起点 → 指数级成长
晃荡的7年 → 原地踏步的新7年 → 停滞不前 → 边缘化
```

## 实践要点

- 每一个未来都是对过去生活的检验
- 每一个现在都将成为不可逆转的过去
- 未来过得怎样，取决于现在状态的你
- 时间对每个人都是公平的，每天24小时串联起来就是一生

## 关键引述

> 如何过一天，就如何过一生。
