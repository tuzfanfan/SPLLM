# 假笑识别

## 定义

> **假笑识别（Fake Smile Detection）** 指通过分析面部肌肉运动特征，区分真实微笑（杜兴微笑/Duchenne Smile）和伪装微笑的能力。真实微笑涉及不自主的眼部肌肉收缩，而假笑通常只有嘴部动作。

## 核心原理

### 真笑 vs 假笑

| 特征 | 真笑（杜兴微笑） | 假笑 |
|------|------|------|
| **嘴部** | 嘴角上扬，颧大肌收缩 | 嘴角上扬，颧大肌收缩 |
| **眼部** | 眼轮匝肌收缩，眼角出现皱纹（鱼尾纹） | 眼部无变化或轻微收缩 |
| **对称性** | 通常双侧对称 | 可能不对称 |
| **持续时间** | 自然的起止（0.5-4秒） | 可能过长或过短 |
| **时机** | 与情绪刺激同步 | 可能延迟或提前 |

### 识别关键

```
真笑 = 颧大肌收缩 + 眼轮匝肌收缩（不可控）
假笑 = 颧大肌收缩（可控）+ 眼轮匝肌不收缩（或刻意收缩）
```

| 判断标准 | 说明 |
|------|------|
| **眼角皱纹** | 真笑的必要条件（[[必要形态特征]]） |
| **眉毛微降** | 假笑时可能出现 |
| **表情消退速度** | 假笑消退可能不自然 |

### 实际应用中的注意事项

| 注意事项 | 说明 |
|------|------|
| **个体差异** | 有些人能很好地模拟杜兴微笑 |
| **文化差异** | 不同文化的微笑规范不同 |
| **情境因素** | 礼貌性微笑不等于欺骗 |
| **基线建立** | 需要了解个体的正常微笑模式 |
