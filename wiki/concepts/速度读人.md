# 速度读人

## 定义

> **速度读人（Speed Reading People）** 是指通过快速观察他人的衣着、言行、身体语言等线索，判断其性格类型，从而用对方喜欢的方式进行沟通，提升社交效率。

## 核心技巧

### 观察维度

| 观察维度 | 看什么 | 判断方法 |
|----------|--------|----------|
| **衣着打扮** | 正式/休闲、颜色、整洁度 | 正式→J，休闲→P；鲜艳→E，低调→I |
| **说话方式** | 语速、音量、词汇类型 | 快→E，慢→I；事实→S，概念→N |
| **身体语言** | 姿势、手势、眼神 | 开放→E，封闭→I；放松→P，紧张→J |
| **兴趣爱好** | 具体活动类型 | 动手→S，创意→N；独处→I，社交→E |
| **职业选择** | 工作类型 | 结构化的→J，灵活的→P；人际→F，分析→T |

### 4步读人法

1. **看衣着**：判断SJ/SP/NT/NF的大致方向
2. **听说话**：判断E/I和S/N
3. **观行为**：判断T/F和J/P
4. **验证**：通过提问确认判断

## 应用场景

### 1. 商业社交
- **销售**：快速判断客户类型，用其喜欢的方式推销
- **谈判**：了解对方决策风格，调整策略
- **管理**：根据员工性格，采用不同激励方式

### 2. 日常交往
- **新朋友**：快速找到共同话题
- **冲突处理**：理解对方行为背后的性格原因

### 3. 职场协作

### 快速判断表

| 讲价值、感受、人情 | F（情感） |

| 随性、灵活、迟到 | P（知觉） |

### 沟通匹配

| 对方类型 | 你应该这样做 |
|----------|----------|
| **E型** | 多问开放性问题，让其多说 |

| **S型** | 给具体事实、数据、案例 |
| **N型** | 讲愿景、意义、未来可能性 |
| **T型** | 讲逻辑、利弊分析、效率提升 |
| **F型** | 讲价值、感受、人际关系影响 |
| **J型** | 给明确计划、时间表、结论 |
| **P型** | 给选项、保持灵活、不要逼迫 |
