# 一胜九败：日本新首富柳井正的创业人生与商业哲学

## 概述

本书讲述了优衣库创始人柳井正的创业历程和商业哲学。2009年，柳井正以60亿美元财富位列全球十大CEO第十位，成为日本首富。在全球经济危机中，优衣库逆势而上，成为"最会游泳的人"。

柳井正的核心理念是"一胜九败"——在经营优衣库过程中经历连续失败，但将每次失败转化为下次成功的经验。这种不畏失败、勇于变革的精神，是优衣库从一家小型男士服装店成长为全球服装品牌之星的根本动力。

### 核心经营理念

#### 1. 一胜九败哲学
- **含义**：胜利的机会只有1%，但不怕失败，持续尝试
- **比喻**：像棒球里的盗垒，不怕被触杀，持续去盗垒
- **核心**：让失败变成下次的成功

#### 2. 变革管理
- 唯新不破，唯变不破
- 变革之前先革新自己
- 扫除关键障碍
- 直面失败

#### 3. 管理原则

| 原则 | 内容 |
|------|------|
| 品质第一 | 逆向思维启动"匠计划" |
| 人人发言 | 每个人都有发言权 |
| 即断即决 | 即断，即决，即实行 |
| 实力主义 | 严谨公正地评价每一个人 |
| 扁平管理 | 扁平到一线，人人都是经营者 |

#### 4. 成功观
- 成功是一种积极的感觉
- 越执著越幸运
- 感激磨难
- 不进取，毋宁死
- 勤勉不是意味着要加班
- 管理就是沟通

### 优衣库成功要素

1. **低价优质**：把低价和优质两个看似不对等的概念联系起来
2. **目标客群**：卖给各式各样的人，无典型消费群体
3. **全球扩张**：在各大洲众多国家开设工厂和店铺
4. **电子商务**：2009年与淘宝合作，开设网络旗舰店
5. **持续变革**：不害怕停滞和失败，勇于直面失败

## 关键洞察

1. **失败是成功之母**：柳井正将"一胜九败"作为核心理念，认为失败次数肯定大于成功次数，要在不断揣摩、跌跟头中总结经验教训。

2. **变革的勇气**：优衣库的成功在于不害怕停滞和失败，勇于直面失败，从失败中学习，及时改变方向。

3. **父亲的影子**：父亲柳井等的严格教导和冒险精神深深影响了柳井正，"当第一名"的理念贯穿其创业生涯。

4. **管理创新**：优衣库的管理理念如"人人都是经营者"、"扁平到一线"等，体现了现代企业管理的前沿思想。

5. **逆势增长**：在全球金融危机中，优衣库不仅没有受到影响，反而助推了全球化事业，体现了强大的商业韧性。
