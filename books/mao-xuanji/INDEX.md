- **持久战战略 ↔ 调查研究法**：监测敌我力量对比的变化
- **统一战线策略 ↔ 阶级分析法**：基于阶级分析制定统一战线
- **运动战原则 ↔ 游击战**：游击战是运动战的基础
- **试点推广法 ↔ 调查研究法**：在试点中深入调查

## 使用指南

### 快速选择

| 你的问题 | 推荐技能 |
|----------|----------|
| 问题复杂，不知从何下手 | 矛盾分析法 |
| 对新领域/市场不了解 | 调查研究法 |
| 需要推动变革但阻力大 | 群众路线 |
| 面对强大对手，资源有限 | 持久战战略 |
| 需要建立广泛联盟 | 统一战线策略 |
| 需要分析利益格局 | 阶级分析法 |
| 团队出现问题需要纠正 | 批评与自我批评 |
| 新产品/新流程需要验证 | 试点推广法 |
| 需要灵活机动的策略 | 运动战原则 |
| 需要积小胜为大胜 | 游击战十六字诀 |

### 组合使用

**场景1：创业从0到1**
1. **调查研究法**：深入了解目标用户和市场
2. **阶级分析法**：分析市场中的不同玩家和利益格局
3. **矛盾分析法**：识别用户最痛的痛点（主要矛盾）
4. **群众路线**：让用户参与产品设计
5. **持久战战略**：分阶段推进，先生存再发展

**场景2：产品重大改版**
1. **试点推广法**：先小范围测试新方案
2. **群众路线**：收集用户反馈，了解不满
3. **调查研究法**：深入分析用户行为数据
4. **矛盾分析法**：识别影响体验的主要矛盾
5. **批评与自我批评**：团队复盘，总结经验

**场景3：面对强大竞争对手**
1. **阶级分析法**：分析竞争格局和各方立场
2. **统一战线策略**：寻找可以合作的伙伴
3. **游击战十六字诀**：在细分市场积小胜为大胜
4. **运动战原则**：集中优势资源，逐个击破
