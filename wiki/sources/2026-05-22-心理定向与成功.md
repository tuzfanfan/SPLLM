# 心理定向与成功

| 属性 | 内容 |
|------|------|
| 作者 | 卡罗尔·德韦克（Carol S. Dweck） |
| 出版信息 | 人民邮电出版社 2007年 |
| 类型 | 成功心理学 |
| 核心主题 | 心理定向（固定型vs成长型）如何影响人们在事业、爱情、家庭和生活质量各方面的表现 |

## 核心观点

1. 心理定向是一种信念，即认为自己的能力、成就是由先天命定或自主努力的结果的信念，这种信念渗透于人们生活的方方面面。
2. 固定型心理定向者认为特质是一成不变的，不断需要证明自己；成长型心理定向者认为基本特质可以通过努力而发展。
3. 赞扬孩子的过程（方法、努力、选择）而非天分，才能培养成长型心理定向。
4. 在体育、艺术、商业、教育和人际关系等领域，成长型心理定向都能带来更好的表现和更健康的心态。
5. 心理定向是可以改变的，通过脑科学教育和具体的工作坊，人们可以从固定型转变为成长型。
