# 中医不死！

## 概述

《中医不死！》是罗萌创作的长篇小说，以民国时期为背景，讲述了中国传统医学在西医冲击下的生存与发展。小说通过程少仲、程少伯兄弟的医学实践，展现了中医的博大精深和顽强生命力。

书中详细描写了中医的理论体系、治疗方法、药材知识，以及中医与西医的碰撞与融合，是一部兼具文学性和知识性的历史小说。

## 核心内容

### 主要人物

| 人物 | 身份 | 特点 |
|------|------|------|
| 程少仲 | 中医师，御医后代 | 在美国学习西医，回国推广中医 |
| 程少伯 | 程少仲的孪生哥哥 | 传统中医，坚守回春堂 |
| 布朗 | 美国医生 | 中医的支持者和研究者 |
| 皮特 | 药理学家 | 希望从中药中发现新物质 |
| 内莉夫人 | 美国总统塔夫脱的夫人 | 接受中医治疗的美国患者 |

### 故事背景

**时代背景：**
- 民国时期，西医东渐
- 中医面临生存危机
- 社会动荡，军阀混战

**地理背景：**
- 药王庙镇：程家回春堂所在地
- 美国：程少仲留学和行医的地方
- 闾阳山：土匪赵义卓的势力范围

### 核心情节

#### 中医在美国的传播
- 程少仲在美国为塔夫脱总统夫人内莉治病
- 内莉夫人患中风，西医束手无策
- 程少仲用针灸、推拿、食疗等方法治疗
- 内莉夫人病情显著好转，震惊美国医学界

#### 子午流注理论
- 程少仲向内莉夫人介绍子午流注理论
- 解释人体在不同时刻的自身节律
- 强调根据时辰选择最佳治疗时机
- 内莉夫人被中医的博大精深震撼

#### 中药实验室的建立
- 布朗和皮特计划建立中药实验室
- 内莉夫人承诺筹集资金
- 希望通过科学研究证明中药的价值
- 计划在美国推广中医中药

#### 国内的变故
- 方志武冒充程少仲在美国行医，造成医疗事故
- 程少仲起诉方志武和唐人杰
- 方志武和唐人杰被遣返中国
- 方志武怀恨在心，向程家谎报程少仲死讯

#### 程家的变故
- 何若菡（程少仲之妻）生下儿子杏圃
- 方志武谎报程少仲死讯，程家悲痛
- 程少伯娶何若菡为妻，照顾弟媳和侄子
- 程家决定"罢医归田"，避免灾祸

### 中医理论

#### 子午流注
- 始于唐朝（公元七世纪初）
- 人体在不同时刻有不同的自身节律
- 气血在十二经脉中按时辰流注
- 根据时辰选择最佳治疗时机

#### 治疗方法
| 方法 | 应用 |
|------|------|
| 针灸 | 疏通经络，调和气血 |
| 推拿 | 舒筋活络，缓解疼痛 |
| 食疗 | 通过饮食调理身体 |
| 药酒 | 药物与酒结合，增强疗效 |
| 拔火罐 | 祛除寒湿，活血化瘀 |
| 导引 | 通过呼吸和运动调理身体 |

### 主题探讨

#### 中医与西医
- 中医的整体观与西医的局部观
- 中医的经验传承与西医的实验科学
- 两种医学体系的互补与融合

#### 传统与现代
- 传统医学在现代社会的价值
- 如何在现代社会传承和发展中医
- 文化自信与开放包容

#### 医德与人性
- 程少仲的医德：善待病人，真心同情其疾苦
- 方志武的反面：冒充他人，害人害己
- 真正的医者眼里，没有仇人，也没有恩人，只有病人

## 关键洞察

1. **中医的博大精深**：子午流注理论展现了中医对人体节律的深刻认识，其历史可以追溯到唐朝。

2. **中西医的互补**：小说展现了中医和西医各有所长，应该相互学习、相互补充。

3. **文化传承的重要性**：在全球化背景下，如何保护和传承传统医学文化是一个重要课题。

4. **医德的核心地位**：真正的医者应该以病人为中心，而不是追求名利。

5. **历史的复杂性**：小说通过个人命运折射出民国时期的动荡与变迁。
